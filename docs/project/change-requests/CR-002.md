# CR-002 최근 파일 10개 열기 및 지속성

## Status

Verified

## Source Document

- [COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md](../../COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md)
- Source requirements: `MENU-001`, `VIEW-002`, `TEST-003`, `TEST-004`

## Request

`File > Open` 다음에 `Recent` 캐스케이드 메뉴를 추가하고, 최근 열기에 성공한 파일을 최신순으로 최대 10개까지 프로그램 재실행 후에도 사용할 수 있게 한다.

## Background

반복 테스트와 설계 수정 과정에서 같은 파일을 자주 다시 열어야 하지만 현재 최근 파일 목록이 없다.

## Current Behavior

File 메뉴에서 Open 대화상자를 이용해 파일을 선택한다. 최근 파일 목록 및 전역 지속성은 구현되어 있지 않다.

## Required Behavior

- 최근 열기에 성공한 파일을 최신순으로 최대 10개 저장한다.
- 같은 Windows 경로는 대소문자 차이와 관계없이 중복하지 않고 첫 위치로 이동한다.
- Recent 항목 선택은 일반 Open과 동일한 메타데이터 판별, 일반 DXF Import 확인 및 오류 처리를 사용한다.
- 존재하지 않거나 접근할 수 없는 항목은 오류를 알리고 목록에서 정리할 수 있다.
- 목록은 파일별 설계 데이터가 아니라 프로그램 전역 상태로 저장한다.

## Scope

- `CosmicDesigner/MainWindow.xaml`
- `CosmicDesigner/MainWindow.xaml.cs`
- 사용자별 설정 저장소
- 최근 파일 지속성 및 열기 회귀 테스트

## Implementation Notes

설정 저장소는 Registry 또는 사용자별 설정 파일 중 하나를 선택해야 한다. CR-003의 전역 보기 설정과 동일한 저장소를 재사용하는 방안을 우선 검토한다. 저장소 선택이 장기 호환성 정책으로 확대되면 ADR을 고려한다.

## Acceptance Criteria

1. `File > Open` 바로 다음에 `Recent` 메뉴가 표시된다.
2. 성공적으로 연 파일만 목록에 추가된다.
3. 중복 경로는 하나만 존재하며 다시 열면 최상단으로 이동한다.
4. 목록은 최신순 10개를 초과하지 않는다.
5. 프로그램 재실행 후 경로와 순서가 복원된다.
6. Recent를 통한 열기가 일반 Open과 동일한 결과를 만든다.
7. 누락 파일 처리 후 프로그램이 정상 동작한다.
8. 기존 DXF 열기·Import·저장 기능의 회귀 테스트가 통과한다.
