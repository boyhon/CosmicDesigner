# CR-003 View 메뉴와 전역 표시 상태 지속성

## Status

Verified

## Source Document

- [COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md](../../COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md)
- Source requirements: `MENU-002`, `VIEW-001`, `TEST-003`, `TEST-004`

## Request

Menu Bar에 View 메뉴를 추가하고 Zoom 캐스케이드와 Ruler, Grid, Status Bar 체크 메뉴를 제공한다. Ruler, Grid, Status Bar 상태는 파일과 독립적인 프로그램 전역 설정으로 지속한다.

## Background

Flat Designer의 표시와 탐색 기능을 일관된 메뉴에서 제어하고, 테스트 파일을 바꾸거나 프로그램을 재시작해도 사용자가 선택한 표시 상태를 유지할 필요가 있다.

## Current Behavior

View 메뉴가 없고 Ruler/Grid 표시 기능이 없다. Status Bar는 항상 XAML에 포함되며 전역 표시 설정으로 관리되지 않는다.

## Required Behavior

```text
View
├─ Zoom
│  ├─ Zoom In
│  ├─ Zoom Out
│  └─ Fit to Window
├─ Ruler          [check]
├─ Grid           [check]
└─ Status Bar     [check]
```

- 체크 메뉴와 실제 표시 상태를 항상 동기화한다.
- Ruler, Grid, Status Bar 설정을 파일과 무관한 사용자 전역 상태로 저장한다.
- 설정이 없거나 손상되면 안전한 기본값을 적용한다.
- Zoom 명령은 CR-004의 Flat Designer 화면 변환을 호출한다.

## Scope

- MainWindow 메뉴와 Status Bar
- 전역 사용자 설정 모델 및 저장소
- Flat Designer Ruler/Grid 상태 연결
- 메뉴 및 설정 지속성 테스트

## Implementation Notes

Registry와 사용자별 설정 파일 중 저장소를 결정해야 한다. Ruler/Grid 기본값도 구현 전에 문서화한다. Zoom 구현 자체는 CR-004에 속하며 이 CR은 메뉴 명령 연결을 담당한다.

## Acceptance Criteria

1. 명세와 동일한 View 메뉴 구조가 제공된다.
2. Ruler, Grid, Status Bar 메뉴는 체크형이며 실제 표시 상태와 일치한다.
3. 메뉴 변경이 현재 화면에 즉시 반영된다.
4. 다른 파일을 열어도 표시 상태가 유지된다.
5. 프로그램 재실행 후 상태가 복원된다.
6. 설정 부재 또는 손상 시 프로그램이 기본값으로 정상 실행된다.
7. Zoom 메뉴가 CR-004의 Zoom In, Zoom Out, Fit 동작을 실행한다.
8. 전역 설정과 파일별 Section 상태가 섞이지 않는 저장·재열기 테스트가 통과한다.
