## Request

Flat Designer에 명확한 유휴 상태, 오른쪽 버튼 Pan, 휠/메뉴 Zoom, Fit to Window, 센티미터 눈금자와 격자를 추가하고 중복된 재료 크기 텍스트를 제거한다.

## Background

현재 Flat Designer는 재료를 자동 맞춤으로 표시하지만 사용자가 큰 도면의 세부 위치를 자유롭게 탐색하거나 좌표를 직관적으로 읽기 어렵다. 상단 크기 텍스트는 Material 속성과 중복된다.

## Current Behavior

- Flat Designer 상단에 `Flat W × H cm` 텍스트가 표시된다.
- 렌더링 배율은 창 크기와 재료 크기에서 매번 자동 계산된다.
- 오른쪽 버튼 Pan, 사용자 Zoom 상태, Ruler와 Grid가 없다.
- Hole 도구 상태에 따라 포인터가 변경되지만 명시적인 공통 유휴/화면 변환 체계가 없다.

## Required Behavior

- 도구가 활성화되지 않은 기본 상태는 기본 포인터이며 빈 공간 좌클릭이 데이터를 변경하지 않는다.
- `Flat W × H cm` 텍스트를 제거하고 Material 속성에서만 확인한다.
- 오른쪽 버튼을 누른 동안 grabbing 포인터로 바꾸고 전체 화면을 Pan한다.
- 버튼 해제 또는 캡처 손실 시 Pan과 포인터 상태를 복원한다.
- 휠 Zoom은 가능한 경우 포인터 아래 설계 좌표를 고정한다.
- View 메뉴의 Zoom In, Zoom Out, Fit to Window와 동일한 변환 모델을 사용한다.
- 상단 Ruler/Grid 버튼과 View 메뉴 상태를 동기화한다.
- 눈금 간격은 배율에 따라 읽기 좋게 자동 선택하고 단위는 cm로 표시한다.
- 확대·축소 및 Pan 중에도 눈금자와 도면 사이에 최소 여백을 유지하며 서로 겹치지 않아야 한다.

## Requirement Update — 2026-10-01 User Test

Flat Designer의 눈금자와 격자는 정상 동작했으나 확대 시 눈금자와 도면이 겹치는 현상이 확인되었다. 기존 구현을 보존하면서 도면 표시 영역을 눈금자 영역과 분리하고 최소 간격을 유지하도록 보완한다.

## Scope

- `FlatDesignerView` 화면/설계 좌표 변환
- MainWindow View 명령과 Flat Designer 상단 컨트롤
- Pan/Zoom/Ruler/Grid 렌더링 및 Hit Test 기반 좌표 변환
- 화면 변환 자동 테스트

## Implementation Notes

Zoom 배율 범위와 단계, Ruler/Grid 기본값, 자동 눈금 알고리즘을 구현 전에 정한다. 화면 변환을 단일 모델로 만들어 렌더링, 좌표 표시, Hole 배치, Hit Test, Move와 Resize가 공유해야 한다. 포인터 우선순위에서 오른쪽 Pan은 객체 조작보다 낮다.

## Acceptance Criteria

1. 기본 상태에서 기본 포인터가 표시되고 빈 공간 좌클릭·드래그로 데이터가 변경되지 않는다.
2. 중복 크기 텍스트가 제거되며 Material 속성은 유지된다.
3. 오른쪽 버튼 Pan은 설계 좌표를 변경하지 않고 모든 화면 요소를 함께 이동한다.
4. Pan 종료 시 캡처와 포인터가 정상 복원된다.
5. 휠 및 메뉴 Zoom에 유효한 최소·최대 배율이 적용된다.
6. Fit to Window가 전체 재료와 설계 객체를 화면 안에 배치한다.
7. Ruler/Grid 버튼과 View 메뉴 체크가 양방향 동기화된다.
8. 모든 배율과 Pan 상태에서 눈금, 객체, 생성 좌표와 Hit Test가 허용 오차 내에서 일치한다.
9. 기존 선택, Hole 생성, Delete, Property 편집과 Section/3D 기능의 회귀 테스트가 통과한다.
10. 최대 확대 상태와 Pan 경계에서도 도면 및 선택 표시가 눈금자 영역을 침범하지 않는다.
