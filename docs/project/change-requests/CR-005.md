# CR-005 모든 Hole 객체의 선택, 이동과 Resize 직접 조작

## Request

Hole 생성 모드의 좌표 표시와 선택 동작을 완성하고, 모든 지원 Hole 형상에 PowerPoint 도형 조작과 유사한 Move, 모서리 2축 Resize, 변 단일축 Resize를 제공한다.

## Background

현재 Hole 도구는 클릭으로 Cut Object를 생성하고 Property에서 수치를 편집할 수 있지만, Flat Designer에서 제어점을 이용해 직접 이동하거나 크기를 바꿀 수 없다.

## Current Behavior

- Hole 버튼 선택 시 crosshair로 재료 안을 클릭하여 Cut Object를 생성한다.
- 생성 객체는 선택되고 Property Editor에서 중심·폭·높이를 수정할 수 있다.
- 선택 Cut은 강조되지만 Resize Handle, Hover Hit Test, 직접 Move/Resize와 실시간 포인터 좌표는 없다.

## Required Behavior

- Hole 모드에서 crosshair와 Status Bar 설계 좌표를 실시간 표시한다.
- 생성 직후 객체, Object Tree, Property Editor와 Flat Designer 선택을 동기화한다.
- 선택 객체의 모서리에 원형 제어점을 표시한다.
- 모서리별 NW/NE/SW/SE 커서로 폭과 높이를 동시에 변경한다.
- 경계선별 NS/EW 커서로 높이 또는 폭만 변경한다.
- Resize 영역이 아닌 객체 내부는 Move 커서를 표시하고 드래그로 위치를 변경한다.
- Rectangle뿐 아니라 Circle, Arc, Sector, Ellipse, Triangle, Diamond, Parallelogram, Pentagon, Hexagon과 Polygon에 공통 적용한다.
- 각 드래그는 하나의 Undo/Redo 항목으로 기록한다.
- 포인터 충돌 시 Source Document의 공통 상호작용 우선순위를 따른다.
- Hole 도구와 객체 선택 도구를 명시적으로 전환할 수 있는 토글 또는 선택 모드 컨트롤을 제공한다.
- 선택 모드에서는 Flat Designer의 선택 객체를 이동·Resize할 수 있어야 한다.
- Flat Designer에 키보드 포커스가 있고 객체가 선택되어 있으면 `Delete` 키가 해당 객체를 삭제해야 한다.
- Flat Designer 선택과 OBJECT 트리 선택 강조를 양방향으로 동기화한다.
- 포인터가 Flat Designer 영역을 벗어나 포커스가 해제되면 Hole 천공 모드와 crosshair를 자동 해제한다.

## Requirement Update — 2026-10-01 User Test

Hole 천공 모드가 계속 유지되어 선택 객체의 Move/Resize가 불가능했고, Flat Designer 선택 상태의 Delete 및 OBJECT 트리 선택 동기화가 동작하지 않았다. 또한 Flat Designer를 벗어난 뒤에도 천공 모드가 유지되었다. 이 결과를 기존 직접 조작 CR의 미완료 상호작용으로 등록한다.

## Scope

- Flat Designer 객체 Hit Test와 포인터 상태 머신
- CutOperation Geometry 재생성
- 선택 동기화와 Property Editor 갱신
- Undo/Redo 트랜잭션 경계
- 모든 Hole 형상 Move/Resize 및 저장 회귀 테스트

## Implementation Notes

재료 경계 밖 이동/Resize 정책, 최소 크기, Resize Anchor와 종횡비 보조키는 구현 전에 결정한다. MouseMove마다 history를 쌓지 않고 MouseDown 이전 상태를 한 번 기록해야 한다. CR-004의 단일 화면 좌표 변환을 사용한다.

## Acceptance Criteria

1. Hole 모드의 Status Bar 좌표와 생성 중심 좌표가 Pan/Zoom 상태에서도 일치한다.
2. 생성 즉시 세 UI 영역의 선택 상태가 일치하고 작업이 Undo/Redo된다.
3. 선택 객체의 모서리 제어점과 적절한 대각 Resize 커서가 표시된다.
4. 모서리 드래그가 폭과 높이를 함께 변경한다.
5. 가로/세로 경계 드래그가 각각 높이/폭만 변경한다.
6. 객체 내부 드래그가 형상을 변형하지 않고 위치만 변경한다.
7. 지원하는 모든 Hole 형상에서 Move와 Resize 후 고유 형상 및 폐곡선이 유지된다.
8. 한 번의 드래그가 하나의 Undo/Redo 항목으로 기록된다.
9. Property, Object Tree, L Geometry 및 저장 데이터가 결과와 동기화된다.
10. 저장 후 재열기에서 위치와 크기가 보존된다.
11. 생성, Hit Test, Move와 Resize 좌표 변환 자동 테스트가 통과한다.
12. 기존 DXF, Delete, Section Designer와 3D Preview 회귀 테스트가 통과한다.
13. 선택 모드 토글 후 선택 객체에 Move/Resize 커서와 동작이 복원된다.
14. Flat Designer에 포커스된 선택 객체가 `Delete`로 삭제되고 Undo할 수 있다.
15. Flat Designer와 OBJECT 트리의 선택 강조가 항상 동일 객체를 가리킨다.
16. Flat Designer의 포인터/포커스 이탈 시 Hole 모드와 crosshair가 해제된다.
