# CR-006 Section Designer 치수 편집기의 투명 표시

## Status

Implemented

## Source Document

- [COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md](../../COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md)
- Source requirements: `SECT-001`, `TEST-004`

## Request

Section Designer의 거리 표시·편집 TextBox가 도형과 치수선을 가리지 않도록 기본 배경과 외곽선을 투명하게 하되 편집 가능성과 포커스 상태는 식별 가능하게 유지한다.

## Background

현재 불투명한 TextBox와 테두리가 뒤쪽 치수선 및 정확한 기준 위치를 가려 치수의 의미를 파악하기 어렵다.

## Current Behavior

Flat Mode와 Bent Mode의 치수 위치에 일반 WPF TextBox가 배치되어 길이를 표시하고 편집한다. 기본 TextBox 배경과 테두리가 아래 도면을 가릴 수 있다.

## Required Behavior

- 비포커스 상태에서 TextBox 배경과 테두리를 투명하게 표시한다.
- 치수선, 연장선, 기준점과 절곡 형상이 TextBox 뒤에서도 식별되어야 한다.
- Hover 또는 Keyboard Focus 상태에서는 입력 가능한 영역임을 알 수 있는 최소 시각 피드백을 제공한다.
- 기존 Enter/포커스 이동, 값 검증, Flat/Bent 편집 동작을 유지한다.
- 투명 편집기와 별개로 동일한 길이 값이 옅은 회색 정적 텍스트로 중복 렌더링되지 않아야 한다.

## Requirement Update — 2026-10-01 User Test

투명 TextBox 적용 후 기존 정적 거리 텍스트가 뒤에 남아 동일 값이 이중으로 보이는 현상이 확인되었다. 편집 가능한 표시 하나만 남도록 중복 렌더링을 제거한다.

## Requirement Update — Bent exterior measurement correction

2026-10-01 사용자 테스트 이미지에서 Bent Mode 치수선이 중심축의 색상 절곡점에 연결되는 문제가 확인되었다. 완성품 치수는 측정 가능한 재료 외곽선을 기준으로 해야 하므로 중심축 점 표시는 제거하고, 두께를 가진 닫힌 단면의 외측 모서리를 치수 시작점과 끝점으로 사용한다. 선택된 절곡점이 필요하면 중심점 대신 두께를 가로지르는 외곽 간 절곡 경계로 표시한다.

## Scope

- `SectionDesignerView`의 동적 치수 TextBox 스타일
- Flat/Bent Mode 치수 렌더링
- 키보드 포커스 및 편집 회귀 테스트

## Implementation Notes

공통 Style 또는 코드 기반 Style을 사용해 동적으로 생성되는 모든 편집기에 동일하게 적용한다. 가독성을 위해 텍스트 자체에는 충분한 대비를 유지한다.

## Acceptance Criteria

1. 비포커스 TextBox의 배경과 외곽선이 도형과 치수선을 가리지 않는다.
2. Hover/Focus 시 편집 가능 상태를 식별할 수 있다.
3. Flat Mode와 Bent Mode에서 값 입력과 적용이 정상 동작한다.
4. 잘못된 값 복원, Enter 처리와 Undo/Redo 동작이 유지된다.
5. Section 형상, 거리 배치와 기존 기능 회귀 테스트가 통과한다.
6. 각 구간 길이는 동일 위치에 한 번만 표시되며 옅은 회색의 중복 값이 남지 않는다.
7. Bent Mode에서 중심축 절곡점의 빨강/파랑 점이 표시되지 않는다.
8. Bent Mode 치수 연장선은 중심축이 아니라 실제 두께 다각형의 외측 모서리에서 시작한다.
9. 선택된 절곡은 중심점이 아니라 재료 두께를 가로지르는 외곽 간 경계로 식별된다.
