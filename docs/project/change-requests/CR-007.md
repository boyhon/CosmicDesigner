# CR-007 W/H Section Designer 보기 상태의 파일별 저장

## Status

Implemented

- [COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md](../../COSMIC_DESIGNER_CHANGE_REQUIREMENTS.md)
- Source requirements: `SECT-002`, `TEST-003`, `TEST-004`

- Unresolved source decision: Section 상태를 DXF 메타데이터 또는 CDF 중 어디에 저장할지 결정

## Request

W/H Section Designer 각각의 Dimensions, Bent Mode와 0/90/180/270도 회전 상태를 파일에 저장하고 다시 열 때 복원한다.

## Background

현재 Section 보기 상태는 UI 실행 상태에만 존재한다. 설계를 저장하고 다시 열면 사용자가 선택했던 표현 상태를 재구성해야 한다.

## Current Behavior

- W/H Dimensions와 Bent Mode는 MainWindow CheckBox 상태이다.
- 회전 상태는 각 `SectionDesignerView.ViewRotationQuarterTurns`에만 존재한다.
- CosmicDesigner DXF 메타데이터에는 재료, 구간, 절곡, Cut, Micro Joint와 Geometry가 저장되지만 Section 보기 상태는 저장되지 않는다.

## Required Behavior

각 축에 다음 파일별 상태를 독립적으로 저장한다.

| 영역 | Dimensions | Bent Mode | Rotation |
|---|---|---|---|
| W Section | Boolean | Boolean | `0`, `90`, `180`, `270` |
| H Section | Boolean | Boolean | `0`, `90`, `180`, `270` |

- 파일 저장 후 다시 열면 UI CheckBox와 Section Designer가 동일 상태로 복원되어야 한다.
- 새 문서는 문서화된 기본값으로 시작한다.
- 상태 데이터가 없는 기존 파일은 오류 없이 기본값으로 열린다.
- 이 상태는 CR-003의 파일 독립적 전역 보기 설정과 분리한다.
- View 메뉴에 `H Dimensions`, `H Bent`, `H Rotation`, `W Dimensions`, `W Bent`, `W Rotation` 항목을 제공하고 Section Designer의 버튼/체크 상태와 동기화한다.
- 프로그램 종료 후 재시작할 때 마지막 W/H 상태를 전역 설정에서 복원한다. 파일을 열 때 파일별 상태가 있으면 해당 파일 상태를 우선 적용하고, 파일별 상태가 없거나 새 문서이면 전역 상태를 사용한다.
- Rotation 메뉴는 `0°`, `90°`, `180°`, `270°` 중 현재 각도를 식별하고 선택할 수 있어야 한다.

## Requirement Update — 2026-10-01 User Test

파일 메타데이터 자동 테스트와 달리 프로그램 재시작 후 실제 UI 상태가 기본값으로 돌아가는 현상이 확인되었다. 기존 파일별 저장을 유지하면서 View 메뉴 접근성과 프로그램 전역의 마지막 상태 복원을 추가한다.

## Scope

- CosmicDesigner 문서/보기 상태 모델
- DXF 메타데이터 직렬화 및 역직렬화
- MainWindow와 W/H SectionDesignerView 상태 동기화
- 기존 메타데이터 호환성 및 저장·재열기 테스트

## Implementation Notes

먼저 기존 DXF 메타데이터에서 안전하게 확장 가능한지 분석한다. 가능하면 이전 메타데이터와 하위 호환되는 선택 필드로 저장한다. 불가능해 CDF가 필요하면 CR-001의 분석과 사용자 승인을 거치며 승인 전 임의로 포맷을 전환하지 않는다.

## Acceptance Criteria

1. W/H의 Dimensions, Bent Mode, Rotation을 서로 다른 조합으로 저장할 수 있다.
2. 닫고 다시 열면 각 축의 CheckBox와 실제 렌더링 상태가 동일하게 복원된다.
3. 새 문서가 정의된 기본 상태로 시작한다.
4. 새 필드가 없는 기존 CosmicDesigner 파일이 오류 없이 기본 상태로 열린다.
5. 전역 Ruler/Grid/Status Bar 설정과 파일별 Section 상태가 섞이지 않는다.
6. 저장 포맷 변경이 필요한 경우 호환성 분석과 사용자 승인 기록이 존재한다.
7. DXF 열기·Import·저장, Section 편집, Undo/Redo와 3D Preview 회귀 테스트가 통과한다.
8. View 메뉴의 H/W 항목과 각 Section Designer 컨트롤이 양방향으로 동기화된다.
9. 프로그램 재시작 후 마지막 H/W Dimensions, Bent, Rotation 상태가 복원된다.
10. 파일별 상태가 있는 문서를 열면 전역 기본 상태보다 문서 상태가 우선한다.
