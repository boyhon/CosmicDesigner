# CR-008 W/H Section Designer 마우스 휠 확대·축소

## Status

Implemented

## Source

2026-10-01 user test and change request: H/W Section Designer 영역에서 마우스 휠로 디자인 그림을 확대·축소하되 View 메뉴에는 별도 항목을 추가하지 않는다.

## Request

H Section Designer와 W Section Designer 각각에서 포인터가 해당 영역에 있을 때 마우스 휠로 단면 도형을 확대하거나 축소한다.

## Background

절곡 결과와 치수의 세부 위치를 확인하려면 Section Designer에서도 즉시 확대·축소할 수 있어야 한다.

## Current Behavior

Section Designer는 창 크기에 맞춘 고정 배율로 렌더링되며 마우스 휠 확대·축소를 제공하지 않는다.

## Required Behavior

- H/W Section Designer에 동일한 휠 확대·축소 동작을 제공한다.
- 포인터 위치를 기준으로 확대·축소하여 관찰 지점이 불필요하게 이동하지 않게 한다.
- Flat Mode와 Bent Mode, 회전 상태 및 치수 편집 상태에서 동작한다.
- 유효한 최소·최대 배율을 적용한다.
- View 메뉴에는 Section Zoom 항목을 추가하지 않는다.

## Scope

- `SectionDesignerView` 화면 변환과 마우스 휠 처리
- 형상, 쐐기, 치수선 및 편집기 좌표 동기화
- W/H, Flat/Bent, Rotation 조합 회귀 테스트

## Implementation Notes

렌더링 형상과 동적 치수 TextBox가 동일한 변환을 사용해야 한다. 확대 중 편집기와 치수선이 서로 어긋나지 않도록 단일 좌표 변환 모델을 사용한다.

## Acceptance Criteria

1. H/W 영역의 휠 위·아래 입력으로 확대와 축소가 동작한다.
2. 포인터 아래 단면 좌표가 확대 전후 허용 오차 내에서 유지된다.
3. 최소·최대 배율을 벗어나지 않는다.
4. Flat/Bent 및 0/90/180/270도 회전에서 형상과 치수 표시가 일치한다.
5. 치수 입력, 쐐기 선택과 기존 Flat Designer Zoom 동작에 회귀가 없다.
6. View 메뉴에 Section Zoom 항목이 생기지 않는다.

## Test Result

- Implemented common W/H wheel Zoom with pointer-anchor preservation and a `0.4`–`5.0` scale range.
- Automated anchor-preservation, scale-bound and coordinate-transform tests passed on 2026-10-01.
- Manual Flat/Bent/Rotation visual acceptance remains pending.

## Requirement Update — CR-014

The 2026-10-01 user test found that repeated pointer-anchored Section Zoom accumulated screen Pan and moved the centered geometry toward a corner. CR-014 supersedes the Section pointer-anchor behavior with center-fixed Zoom. Flat Designer pointer-anchored Zoom is unchanged.
