# CR-009 Section Designer 쐐기 생성 클릭 범위 제한

## Status

Implemented

## Source

2026-10-01 user test and change request: 도형 밖 클릭과 길이 편집 클릭으로 V/V1 객체가 생성되는 문제를 막고, 실제 재료 도형 내부 클릭에서만 쐐기를 생성한다.

## Request

Section Designer의 절곡점 생성은 그려진 재료 도형 내부를 직접 클릭한 경우에만 실행되도록 제한한다.

## Background

치수 필드를 편집하거나 도형 주변을 클릭하는 일반 UI 동작이 의도하지 않은 V/V1 객체 생성으로 이어져 설계 데이터가 손상될 수 있다.

## Current Behavior

Section Designer 영역의 폭 또는 높이를 기준으로 위치만 환산하므로 실제 도형 외부나 치수 편집 위치를 클릭해도 Bend 객체가 생성될 수 있다.

## Required Behavior

- Flat Mode에서 실제 재료 사각형 내부 클릭만 쐐기를 생성한다.
- 치수 TextBox, 치수선 주변, 여백과 패널 배경 클릭은 생성 동작에서 제외한다.
- Bent Mode에서는 기존 정책대로 새 절곡점 생성을 허용하지 않는다.
- 유효 클릭 시에만 Undo 항목과 V/V1 객체를 만든다.
- 경계선 클릭 허용 오차는 화면 배율과 무관하게 일관된 픽셀 범위로 정의한다.

## Scope

- `SectionDesignerView` 입력 Hit Test
- 동적 치수 편집기와 생성 이벤트 분리
- W/H 방향 및 위/아래/좌/우 쐐기 회귀 테스트

## Implementation Notes

단순 패널 좌표 범위가 아니라 현재 렌더링된 재료 도형의 Hit Test 결과를 사용한다. TextBox 원본 이벤트는 항상 제외한다.

## Acceptance Criteria

1. W/H Flat Mode의 재료 도형 내부 클릭은 기존과 같이 V/V1 객체를 생성한다.
2. 재료 도형 외부, 여백 및 패널 배경 클릭은 객체를 생성하지 않는다.
3. 길이 편집 필드를 클릭하거나 값을 편집해도 새 객체가 생성되지 않는다.
4. Bent Mode 클릭은 객체를 생성하지 않는다.
5. 무효 클릭은 Undo/Redo 기록을 추가하지 않는다.
6. 유효 클릭 위치와 생성된 Position 값이 허용 오차 내에서 일치한다.
