# CR-010 3D Preview 투명 아크릴 표현

## Status

Implemented

## Source

2026-10-01 user test and change request: 3D 재료를 투명한 아크릴처럼 표현하고 모서리를 회색 윤곽선으로 표시하여 완성품의 공간적 형태를 쉽게 이해하게 한다.

## Request

3D Preview의 재료 표면을 반투명 아크릴 재질로 변경하고 외곽 및 절곡 모서리를 회색 윤곽선으로 표시한다.

## Background

현재의 사실적인 불투명 표현은 뒤쪽 면과 절곡 관계를 가려 완성품의 공간적 구조를 이해하기 어렵다.

## Current Behavior

3D Preview는 재료 면을 비교적 불투명하게 표시하며, 투명 재질을 통한 내부·후면 구조 확인과 명확한 회색 모서리 표현이 부족하다.

## Required Behavior

- 재료 면은 뒤쪽 형상을 식별할 수 있는 반투명 아크릴 느낌으로 표시한다.
- 외곽선과 절곡 경계는 배경 및 면 색상과 구별되는 회색 윤곽선으로 표시한다.
- 면의 앞뒤 순서와 투명도 혼합이 회전 중에도 안정적으로 보인다.
- 기존 드래그 회전, Fit/Reset 및 Semi Transparent 옵션과 충돌하지 않도록 상태를 정리한다.
- 선택 색상이나 V/V1 식별 정보가 있다면 투명 재질에서도 식별 가능해야 한다.
- 배경은 어두운 공간이 아니라 흰색으로 표시한다.
- 방향성 조명, 그늘과 사실적인 명암은 제거하고 골격과 겹친 면의 관계를 읽기 쉬운 단순 조감도로 표현한다.
- 모든 주요 외곽 및 절곡 모서리는 회색이 아닌 검정 실선으로 강조한다.

## Requirement Update — simplified acrylic skeleton view

2026-10-01 사용자 피드백에 따라 기존 어두운 배경, 청색 아크릴 및 회색 모서리 표현을 재검토한다. 뒤쪽 면이 앞쪽 면을 통해 보이는 투명 아크릴 표현은 유지하되 흰 배경과 검정 모서리를 사용하고, 조명과 그늘에 의존하지 않는 단순한 골격 중심 3D 조감도로 변경한다.

## Requirement Update — white-background visibility correction

1.3.2 사용자 테스트에서 아크릴 면이 흰 배경과 구분되지 않고 외곽·절곡선도 보이지 않아 3D 형상을 판별할 수 없는 문제가 확인되었다. 면을 흰색이 아닌 명확한 연회색 반투명 재질로 변경하고, 검정 3D Edge의 최소 굵기와 대비를 높여 모든 시점에서 외곽 및 절곡 골격을 식별할 수 있게 한다.

## Scope

- `ThreeDPreviewView` 재질, 면 및 Edge 렌더링
- 투명도 UI 상태와 기본값
- 회전 시 깊이/혼합 시각 검증

## Implementation Notes

WPF 3D의 알파 블렌딩 한계를 고려해 면 정렬 또는 양면 재질 전략을 검토한다. 정확한 색상과 투명도 값은 구현 중 접근성과 가독성을 기준으로 결정하고 문서화한다.

## Acceptance Criteria

1. 앞쪽 면을 통해 뒤쪽 면과 절곡 구조를 식별할 수 있다.
2. 외곽과 주요 절곡 모서리가 회색 윤곽선으로 선명하게 표시된다.
3. 마우스 드래그 회전 중 투명 면이 심하게 깜박이거나 사라지지 않는다.
4. Fit/Reset과 기존 회전 조작이 유지된다.
5. 배경과 도형 간 대비가 충분하고 전체 공간 형상을 기존보다 쉽게 판별할 수 있다.
6. Flat/Section Designer 및 저장 데이터에는 영향을 주지 않는다.
7. 3D Preview 배경이 흰색이며 방향성 조명에 따른 명암이나 그늘이 나타나지 않는다.
8. 외곽 및 절곡 모서리가 검정 실선으로 표시된다.
9. 기본 투명 상태에서도 연회색 면이 흰 배경과 육안으로 명확히 구별된다.
10. 재료 크기와 관계없이 검정 Edge에 가시적인 최소 화면 굵기가 확보된다.

- The material surface now uses a translucent blue acrylic appearance, with the existing option providing a more transparent variant.
- Opaque gray cylindrical edge geometry is generated for exterior and bend-grid edges and follows the existing drag/zoom camera.

- Reworked the preview for 1.3.2 with a white background, lower-opacity two-sided acrylic surfaces, uniform ambient/emissive rendering without directional lighting, and opaque black exterior/bend edges.
- Release build and the complete CosmicDesigner regression executable passed. Final visual acceptance remains pending.
- Corrected 1.3.2 white-background visibility in 1.3.3: the surface is now a higher-opacity light-gray acrylic (`ARGB 175,185,195,205`, or alpha 105 in the optional more-transparent mode), and black edge cylinders use a substantially larger minimum/model-relative radius.
- Replaced the black emissive edge material with ambient-lit black diffuse material. Release build and the complete regression executable passed; native-app screenshot automation was unavailable, so final visual acceptance remains pending.
