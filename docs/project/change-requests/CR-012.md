# CR-012 Flat Designer H/W 단면 선택선 및 연동

## Status

Implemented

## Source

2026-10-01 user request comparing CosmicDesigner with DXFDrawer X/Y Section Bending Simulation.

## Request

Flat Designer에 H/W 단면 위치를 나타내는 파선을 표시하고, 사용자가 선을 드래그하면 대응하는 H/W Section Designer가 선택 단면 위치를 즉시 반영한다.

## Background

DXFDrawer는 전개도 위 X/Y Section 파선을 이동하여 Bending Simulation의 기준 단면을 선택한다. CosmicDesigner에도 동일한 직접 조작 방식이 필요하다.

## Current Behavior

Flat Designer에는 단면 선택선이 없고 H/W Section Designer가 어느 위치의 단면을 나타내는지 식별할 수 없다.

## Required Behavior

- H Section 선택선은 Flat Designer에 세로 파선으로 표시하고 좌우로 드래그한다.
- W Section 선택선은 Flat Designer에 가로 파선으로 표시하고 상하로 드래그한다.
- 두 선택선은 서로 다른 색과 `H Section`/`W Section` 레이블로 구분한다.
- 드래그 위치는 재료 범위를 벗어나지 않는다.
- 선택 위치가 바뀌면 대응 Section Designer가 즉시 갱신되고 현재 단면 좌표를 표시한다.
- 기존 Hole/객체 선택, Pan, Zoom과 충돌하지 않는다.

## Scope

- Flat Designer 단면선 렌더링, Hit Test와 드래그
- H/W Section Designer 선택 위치 표시와 갱신
- MainWindow 이벤트 연결

## Implementation Notes

기본 위치는 재료 중앙이다. H 단면은 X 위치, W 단면은 Y 위치로 해석한다. 현재 절곡선은 재료 전체를 가로지르는 데이터 모델이므로 선택 위치에 따른 절곡 프로파일은 동일할 수 있으나, 선택 좌표와 대응 뷰의 관계는 명시적으로 표시한다.

## Acceptance Criteria

1. Flat Designer에 H 세로 파선과 W 가로 파선이 표시된다.
2. H 선을 잡으면 좌우 크기 조절 커서가 보이고 좌우 드래그가 된다.
3. W 선을 잡으면 상하 크기 조절 커서가 보이고 상하 드래그가 된다.
4. 선은 재료 경계 안으로 제한된다.
5. H/W Section Designer가 대응 위치를 즉시 표시하고 다시 그린다.
6. 기존 Flat Designer 직접 조작과 Zoom/Pan 회귀가 없다.
