# CR-013 W Section Bent 적응형 화면 배율 교정

## Status

Implemented

## Source

2026-10-01 user test with non-Bent, Bent and 3D Preview screenshots.

## Request

W Section Designer에서 정상 계산된 Bent 형상이 지나치게 작게 렌더링되는 문제를 교정한다.

## Background

약 `150 × 150 cm`의 L형 W 단면은 3D Preview에서 정상이나 높이 약 `210 px`인 W Section Designer에서는 작은 점처럼 표시되었다. H Section은 패널과 형상 비율 차이로 문제가 덜 드러났다.

## Current Behavior

Bent Fit 배율은 뷰의 가로와 세로에서 각각 고정 `190 px`을 제외한다. 높이가 `210 px`이면 형상에 사용할 높이가 `20 px`만 남아 배율이 약 `0.13 px/cm`로 축소된다.

## Required Behavior

- W/H Bent 화면은 패널 크기에 적합한 여백을 사용한다.
- 낮고 넓은 W 패널에서도 L형 단면이 식별 가능한 크기로 표시된다.
- 치수선과 편집기는 형상과 동일한 Fit 배율을 사용한다.
- 기존 최대 배율, 회전, 휠 Zoom과 Pan 동작을 유지한다.

## Scope

- Bent Section Fit 배율 계산
- Bent 형상과 치수 편집기 공통 배율
- W/H 및 패널 종횡비 회귀 검증

## Implementation Notes

고정 `190 px` 차감 대신 가로 `120 px`, 세로 `72 px`의 치수 여백을 적용하고 유효 영역을 최소 1픽셀로 제한한다. 최대 Fit 배율 `1.5`는 유지한다.

## Acceptance Criteria

1. `765 × 210 px` 뷰의 `150 × 150 cm` 형상 Fit 배율이 약 `0.92`이다.
2. 동일 형상이 기존처럼 약 `0.13`으로 축소되지 않는다.
3. Bent 형상, 치수선과 치수 편집기 위치가 일치한다.
4. H Section과 회전 상태에도 동일한 계산이 적용된다.
5. 전체 자동 회귀 테스트가 통과한다.
