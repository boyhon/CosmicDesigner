# CR-014 Section Designer 중앙 고정 Zoom

## Status

Implemented

## Source

2026-10-01 user test and screenshot: repeated Section Designer Zoom appeared to move the shape toward the right corner.

## Request

Section Designer 도형을 상하좌우 중앙에 배치하고 확대·축소를 반복해도 중앙 위치를 유지한다.

## Background

기존 CR-008은 포인터 고정 Zoom을 적용했다. 서로 다른 포인터 위치에서 Zoom을 반복하면 포인터 보존을 위한 Pan 보정이 누적되어, 중앙에 Fit된 형상이 화면 구석으로 이동한다.

## Current Behavior

휠 Zoom마다 포인터 아래 설계 좌표를 유지하기 위한 `_viewPan`이 계산되고 다음 Zoom에 누적된다.

## Required Behavior

- H/W 및 Flat/Bent Section 도형은 뷰의 상하좌우 중앙을 기준으로 확대·축소한다.
- 휠 Zoom 시 이전 포인터 보정 Pan을 제거한다.
- 반복 확대·축소 후에도 뷰 중심이 이동하지 않는다.
- 기존 최소·최대 배율 `0.4`–`5.0`을 유지한다.

## Scope

- Section 휠 Zoom 기준점과 Pan 상태
- 중앙 고정 Zoom 회귀 테스트
- CR-008의 포인터 기준 요구를 이번 사용자 요구로 교체

## Implementation Notes

Flat Designer의 포인터 기준 Zoom은 변경하지 않는다. Section Designer만 중앙 기준 Zoom을 사용한다.

## Acceptance Criteria

1. Section Zoom 후 Pan X/Y가 `0`이다.
2. 서로 다른 포인터 위치에서 반복 Zoom해도 도형 중심이 뷰 중심에 유지된다.
3. H/W, Flat/Bent 및 회전 상태에서 동일하게 동작한다.
4. Zoom 범위가 `0.4`–`5.0`을 벗어나지 않는다.
5. 전체 자동 회귀 테스트가 통과한다.
