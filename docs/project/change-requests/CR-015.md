# CR-015 Outer Contour 경계 천공 병합

## Status

Implemented

## Source

2026-10-01 user request and reference screenshots showing a Rectangle Cut at the material corner and the expected six-LINE Outer Contour.

## Request

천공 객체가 Outer Contour 경계와 겹치면 독립 Cut 객체를 제거하고 잘려 나간 형상을 Outer Contour에 반영한다.

## Background

경계와 연결된 절단은 닫힌 내부 구멍이 아니라 외곽의 개방 노치이다. 예제의 직사각형 재료는 4개 LINE이고, 모서리 사각 노치를 적용한 결과는 6개 LINE의 새 Outer Contour가 되어야 한다.

## Current Behavior

Rectangle Cut이 외곽 경계에 닿아도 Cut 및 Inner Contour 객체로 유지되고 Outer Contour는 변경되지 않는다.

## Required Behavior

- Rectangle Cut이 Outer Contour 경계에 닿으면 드래그 종료 또는 생성 시 외곽 노치로 변환한다.
- 변환 후 Cut과 대응 Inner Contour 객체를 제거한다.
- 모서리 노치는 6개 LINE, 한 변 중앙의 노치는 8개 LINE으로 외곽을 재구성한다.
- 내부에 완전히 포함된 Rectangle은 기존 Cut으로 유지한다.
- 재료를 완전히 분할하는 반대쪽 두 경계 관통 Cut은 자동 병합하지 않는다.
- 동작은 Undo 기록 안에서 수행한다.

## Requirement Update — 2026-10-02 User Test

- 경계 접촉 즉시 자동 병합하지 않는다. Cut은 명시적인 사용자 확정 전까지 이동과 Resize가 가능해야 한다.
- 현재 선택된 Rectangle Cut이 Outer Contour와 안전하게 병합 가능하면 노란색 대신 주황색 선택 표시를 사용하고, 경계에서 떨어지면 노란색으로 복원한다.
- 병합 가능한 Cut을 우클릭하면 `Outer Contour로 통합` 메뉴를 제공하고, 사용자가 해당 명령을 선택한 경우에만 병합한다.
- 최초 병합 후 Outer Contour가 6개 이상의 LINE으로 바뀌어도 이후 모든 Rectangle Cut에 같은 후보 표시와 명시적 병합 기능을 계속 제공한다.
- 병합 결과가 복수 외곽선으로 분리되는 경우에는 병합 명령을 제공하지 않는다.

## Scope

- 직사각형 기본 Outer Contour
- 축 정렬 Rectangle Cut의 경계 노치 변환
- 생성 및 이동 완료 시 병합
- DXF Outer/Inner 메타데이터 일관성

## Implementation Notes

이번 범위는 예제와 동일한 Rectangle Cut에 한정한다. 현재 직교 Outer Contour와 Rectangle의 차집합을 계산하고 결과가 하나의 폐곡선일 때만 병합 후보로 인정한다. 원·호·임의 다각형의 일반 Boolean difference는 별도 CR이 필요하다.

## Acceptance Criteria

1. 모서리에 닿은 Rectangle Cut이 사라지고 Inner Contour도 제거된다.
2. 기존 4-LINE Outer Contour가 6-LINE 노치 외곽으로 바뀐다.
3. 한 변 중앙에 닿은 Rectangle은 8-LINE 외곽이 된다.
4. 내부 Rectangle Cut은 자동 병합되지 않는다.
5. 저장된 DXF의 L 레이어에는 새 Outer Contour가 반영된다.
6. 전체 자동 회귀 테스트가 통과한다.
7. 경계 접촉만으로 자동 병합되지 않고 Cut을 계속 이동·Resize할 수 있다.
8. 병합 가능 상태는 주황색, 불가능하거나 경계에서 떨어진 상태는 노란색으로 표시된다.
9. 우클릭 메뉴 선택 시에만 병합되고 Undo로 이전 상태를 복원할 수 있다.
10. 첫 병합 후 변경된 Outer Contour의 다른 모서리에도 후속 Rectangle Cut을 병합할 수 있다.
