# CR-016 선택 위치의 실제 Outer Contour 단면 표시

## Status

Implemented

## Source

2026-10-02/03 user request and attached screenshot showing the H selector inside a merged boundary notch while H Section Designer retained the previous full profile.

## Request

Flat Designer의 H/W Section 선택선이 Outer Contour의 컷팅된 구간에 있을 때, 대응 Section Designer가 이전 전체 단면이 아니라 그 선택선에서 실제로 남아 있는 재료 단면을 표시한다.

## Background

CR-012 connected selector movement and coordinate display, but the Section Designer geometry continued to use the document-wide H/W segment list. CR-015 made Outer Contour notches possible, exposing the difference between a displayed selector coordinate and its actual local material intersection.

## Current Behavior

H/W selector coordinates refresh, but Flat/Bent section geometry remains the same at every position and can show material that has been removed from the Outer Contour.

## Required Behavior

- Intersect H selections at the selected X coordinate with horizontal Outer Contour edges to obtain the local Y material interval.
- Intersect W selections at the selected Y coordinate with vertical Outer Contour edges to obtain the local X material interval.
- Render Flat and Bent Section views from that local interval.
- Include only bends inside the selected material interval.
- Preserve the existing finished-length calculation and editable dimension behavior when the selected interval is the full section.
- Show clipped local dimensions as read-only values because they are derived from contour geometry rather than the global editable H/W segment model.

> Superseded by CR-018 in release 1.8.0: clipped local dimensions are now editable through coordinated bend and Outer Contour boundary updates.

## Scope

- Rectilinear Outer Contour section intersection
- H/W Flat and Bent Section rendering and dimension display
- Automated regression coverage and release documentation

## Implementation Notes

The contour engine pairs sorted scan-line crossings and selects the longest material interval. This matches the currently supported single connected rectilinear Outer Contour produced by CR-015. Full, uncut sections continue using the stored SectionSegment lengths to avoid changing the established bend allowance policy.

## Acceptance Criteria

1. An H selector outside a notch shows the existing full H profile.
2. Moving H into a merged notch shortens the profile to the actual remaining Y interval.
3. W performs the corresponding operation using its selected Y coordinate.
4. Bends outside the local interval are not rendered in the selected section.
5. Flat and Bent modes use the same selected local interval.
6. Existing full-section dimensions, bend geometry and verification tests continue to pass.
