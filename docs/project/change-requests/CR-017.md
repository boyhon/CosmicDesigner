# CR-017 Flat Designer Outer Contour LINE 직접 편집

## Status

Implemented

## Source

2026-10-03 user request and attached screenshot showing selected Outer Contour object `L008` in Flat Designer.

## Request

Flat Designer에서 Outer Contour LINE을 직접 선택하고, 선 몸체를 드래그하여 위치를 변경하거나 양 끝 원형 핸들을 드래그하여 길이를 변경한다. 변경된 공유 꼭짓점은 양쪽 인접선에도 반영한다.

## Background

OBJECTS 목록에서 선택한 Outer Contour LINE은 Flat Designer에 노란색으로 표시되지만, 캔버스에서 직접 선택하거나 형상을 편집할 수 없었다.

## Current Behavior

Outer Contour LINE은 트리 선택을 통한 강조 표시만 가능하다. Flat Designer의 Hit Test와 드래그 편집은 Cut 객체에만 적용된다.

## Required Behavior

- Flat Designer에서 Outer Contour LINE을 클릭하면 해당 객체를 선택하고 OBJECTS 및 PROPERTIES와 동기화한다.
- 선택된 수직선 몸체에서는 `ew-resize`, 수평선 몸체에서는 `ns-resize` 커서를 표시한다.
- 선 몸체를 드래그하면 선의 수직 방향으로 평행 이동한다.
- 선택된 수직선 양 끝 핸들에서는 `ns-resize`, 수평선 핸들에서는 `ew-resize` 커서를 표시한다.
- 끝점 드래그는 선 길이를 늘리거나 줄인다.
- 이동한 각 공유 꼭짓점은 연결된 인접 LINE에 함께 반영하여 Outer Contour 연결성을 보존한다.
- 편집은 재료 범위와 최소 LINE 길이를 지키고 Undo/Redo 기록에 포함한다.

## Scope

- 축 정렬 Outer Contour LINE의 Hit Test, 커서, 선택과 드래그
- 연결된 인접 LINE의 공유 꼭짓점 갱신
- Undo/Redo 및 기존 OBJECTS/PROPERTIES 동기화
- 자동 회귀 테스트와 릴리스 문서

## Implementation Notes

Outer Contour 편집 엔진은 선택 LINE의 원본 두 끝점을 공유하는 모든 이웃 LINE을 찾아 새 끝점으로 치환한다. UI 드래그는 시작 시점의 contour snapshot을 기준으로 매 프레임 결과를 다시 계산하여 누적 오차를 방지한다. 현재 CR 범위는 기존 Outer Contour와 동일한 축 정렬 LINE이다.

## Acceptance Criteria

1. Flat Designer에서 Outer Contour LINE 클릭 선택이 된다.
2. 수직 선택선 몸체의 커서는 `ew-resize`이고 좌우 드래그가 된다.
3. 수직 선택선 끝점의 커서는 `ns-resize`이고 상하 Resize가 된다.
4. 수평선에는 회전 대칭인 커서와 조작이 적용된다.
5. 몸체 이동 시 양 끝에 연결된 두 인접선이 함께 늘거나 줄어든다.
6. 끝점 이동 시 해당 끝에 연결된 인접선이 함께 변경된다.
7. Outer Contour는 연결 상태와 LINE 개수를 유지한다.
8. 편집 전 상태는 Undo로 복원할 수 있다.
9. 전체 자동 회귀 테스트가 통과한다.
