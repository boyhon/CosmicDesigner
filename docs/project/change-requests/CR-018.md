# CR-018 잘린 Section 치수 편집과 Outer Contour 연쇄 갱신

## Status

Implemented

## Source

2026-10-03 user request and two attached screenshots comparing editable full H Section dimensions with non-editable dimensions at a cut H Section position.

## Request

Cutting으로 단면이 잘린 H/W Section Designer에서도 길이 값을 수정할 수 있어야 하며, 수정 결과에 따라 필요한 절곡 위치와 Outer Contour LINE 명령 및 연결된 LINE 길이가 함께 변경되어야 한다.

## Background

CR-016은 선택 위치의 실제 잘린 단면을 표시했지만 contour에서 파생된 치수는 전역 SectionSegment와 직접 대응하지 않아 읽기 전용으로 두었다. 사용자는 잘린 위치에서도 동일한 치수 기반 설계 편집이 필요하다.

## Current Behavior

전체 단면의 치수는 TextBox로 편집할 수 있지만, Outer Contour에 의해 잘린 단면 치수는 읽기 전용 TextBlock으로 표시된다.

## Required Behavior

- 잘린 Flat/Bent H/W Section의 모든 길이 치수를 편집 가능한 TextBox로 표시한다.
- 입력된 Bent 외곽 치수는 기존 두께 보정 정책에 따라 중심 길이로 환산한다.
- 편집 구간 이후의 절곡 위치를 치수 변화량만큼 이동하여 다른 로컬 구간 길이를 보존한다.
- 잘린 끝 경계의 Outer Contour LINE을 같은 변화량만큼 이동한다.
- 경계 LINE과 공유 꼭짓점을 가진 인접 LINE의 끝점을 함께 변경하여 폐곡선 연결성을 유지한다.
- 반대쪽 시작 경계가 잘린 경우에는 끝쪽을 기준으로 대칭적인 연쇄 갱신을 수행한다.
- 편집은 Undo/Redo 기록에 포함하며 유효하지 않은 길이는 적용하지 않는다.

## Scope

- CR-016의 잘린 로컬 Section 치수 편집
- H/W, Flat/Bent 공통 처리
- Bend 위치, SectionSegment와 Outer Contour 연결 갱신
- 자동 회귀 테스트와 릴리스 문서

## Implementation Notes

로컬 단면은 시작 경계, 포함된 bends, 끝 경계로 이루어진 station chain으로 취급한다. 끝 경계가 잘린 경우 편집 segment의 끝 이후 station을 이동하고, 시작 경계가 잘린 경우 반대 방향으로 앞선 station을 이동한다. Outer Contour 경계 이동은 CR-017의 공유 꼭짓점 갱신 엔진을 재사용한다.

## Acceptance Criteria

1. 잘린 H Section의 Flat 및 Bent 치수 값을 편집할 수 있다.
2. 잘린 W Section에도 같은 기능이 적용된다.
3. Bent 외곽 치수 입력에 재료 두께 보정이 적용된다.
4. 편집 대상 이후의 bend 위치와 잘린 contour 경계가 변화량만큼 이동한다.
5. 변경되지 않아야 할 다른 로컬 segment 길이는 유지된다.
6. 이동한 contour 경계에 연결된 양쪽 LINE 끝점이 함께 갱신된다.
7. Outer Contour 연결성과 LINE 개수가 유지된다.
8. 편집을 Undo로 되돌릴 수 있다.
9. 전체 자동 회귀 테스트가 통과한다.
