# CR-019 3D Preview Outer Contour 컷 형상 반영

## Status

Implemented

## Source

2026-10-03 user request and attached 3D Preview screenshot showing a rectangular preview after part of the material had been removed from Outer Contour.

## Request

재료가 컷팅되어 Outer Contour가 변경되면 3D Preview도 제거된 면과 변경된 외곽선을 실제 형상대로 표시한다.

## Background

기존 3D Preview는 전체 W/H Section point의 직교 곱으로 항상 완전한 직사각형 격자 면을 생성했다. CR-015/017/018에서 Outer Contour가 변경되어도 3D 면 생성에는 사용되지 않았다.

## Current Behavior

Flat Designer와 Section Designer는 컷팅된 contour를 반영하지만 3D Preview는 원래 직사각형 외곽과 면을 계속 표시한다.

## Required Behavior

- 현재 Outer Contour 내부에 해당하는 영역만 3D surface mesh로 생성한다.
- Outer Contour에서 제거된 notch 영역에는 triangle face를 생성하지 않는다.
- 변경된 Outer Contour 경계 전체를 검은 3D Edge로 표시한다.
- W/H bend 위치에서 메시를 분할하여 기존 절곡 형상을 유지한다.
- material surface, 반투명 옵션, 카메라 회전과 Zoom 동작은 유지한다.
- Outer Contour 직접 편집 및 Section 치수 연쇄 편집 후에도 즉시 갱신한다.

## Scope

- 현재 지원하는 단일 연결 rectilinear Outer Contour
- 3D surface triangulation과 exterior/fold Edge 생성
- 자동 회귀 테스트와 릴리스 문서

## Implementation Notes

Outer Contour 꼭짓점과 모든 W/H bend station으로 평면을 셀 분할하고, 셀 중심이 contour 내부인 경우에만 두 triangle을 생성한다. 공유 횟수가 한 번인 셀 edge는 exterior boundary로, bend station 위의 edge는 fold edge로 유지한다. 각 평면 꼭짓점은 기존 W/H Bent Section 경로에 보간하여 3D 좌표로 변환한다.

## Acceptance Criteria

1. 기본 직사각형 재료는 기존과 같은 완전한 3D 면을 표시한다.
2. 모서리 notch가 통합되면 해당 모서리 face가 3D Preview에서 제거된다.
3. notch의 새 경계 LINE이 검은 외곽 Edge로 표시된다.
4. W/H 절곡선은 컷 형상과 함께 올바르게 절곡되고 fold Edge를 유지한다.
5. CR-017/018에 의한 Outer Contour 변경 후 Preview가 즉시 다시 생성된다.
6. 회전, Zoom, Fit/Reset과 Semi Transparent 옵션에 회귀가 없다.
7. 전체 자동 회귀 테스트가 통과한다.
