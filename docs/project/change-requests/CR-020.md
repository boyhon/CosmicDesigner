# CR-020 File 메뉴 New/Open/Save 단축키

## Status

Implemented

## Source

2026-10-03 user request.

## Request

File 메뉴의 New, Open, Save가 각각 `Ctrl+N`, `Ctrl+O`, `Ctrl+S`로 동작하고 단축키가 있는 메뉴 항목에는 단축키를 표시한다.

## Background

Edit 메뉴의 Undo/Redo는 단축키와 메뉴 표시가 있지만 File 메뉴의 기본 문서 명령에는 단축키 연결과 표시가 없었다.

## Current Behavior

New, Open, Save는 메뉴 클릭으로만 실행되며 메뉴 오른쪽에 키 조합이 표시되지 않는다.

## Required Behavior

- `Ctrl+N`은 기존 New 명령을 실행한다.
- `Ctrl+O`는 기존 Open 명령을 실행한다.
- `Ctrl+S`는 기존 Save 명령을 실행하고, 경로가 없을 때의 기존 Save As 흐름을 유지한다.
- File 메뉴의 New, Open, Save 항목 오른쪽에 해당 키 조합을 표시한다.
- 기존 `Ctrl+Z`/`Ctrl+Y`, 텍스트 편집 및 다른 입력 처리에 회귀가 없어야 한다.

## Scope

- MainWindow 전역 키 처리
- File 메뉴 InputGesture 표시
- 단축키 매핑 자동 검증

## Implementation Notes

기존 Click handler를 재사용하여 메뉴와 키보드 실행 경로가 동일한 동작을 수행한다. 정확히 Control modifier만 눌린 경우에 New/Open/Save로 해석한다.

## Acceptance Criteria

1. `Ctrl+N`으로 새 문서가 생성된다.
2. `Ctrl+O`로 Open 대화상자가 열린다.
3. `Ctrl+S`로 현재 문서가 저장된다.
4. 저장 경로가 없으면 `Ctrl+S`가 기존 Save As 대화상자를 연다.
5. New, Open, Save 메뉴에 각각 `Ctrl+N`, `Ctrl+O`, `Ctrl+S`가 표시된다.
6. Undo/Redo 단축키가 계속 동작한다.
7. 전체 자동 회귀 테스트가 통과한다.
