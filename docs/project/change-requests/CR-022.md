# CR-022 Edit Settings 사용자 환경 설정창

## Status

Implemented

## Source

2026-10-03 user request and approved design refinement.

## Request

Edit 메뉴에 Settings를 추가하고, 작업 중 전환하는 View 명령과 중복하지 않으면서 사용자 취향에 맞는 도구 환경을 설정하는 창을 제공한다.

## Background

기존 사용자 설정은 JSON에 저장되지만 Ruler/Grid/Status와 Section 기본 상태를 개별 메뉴에서만 변경할 수 있었고 통합 환경 설정창이 없었다.

## Current Behavior

기본 폴더, Recent 개수, Zoom 단계, 선택 허용 거리, 핸들 크기, 3D 표현과 새 문서 기본 재료값을 사용자가 구성할 수 없다.

## Required Behavior

- Edit > Settings 및 `Ctrl+,`를 제공한다.
- General, Editing, 3D Preview, New Document 탭을 제공한다.
- 기본 열기/저장 폴더와 Recent 표시 개수를 저장한다.
- Zoom 단계, 선택 허용 거리와 선택 핸들 크기를 저장하고 즉시 적용한다.
- 3D 반투명/불투명 opacity와 외곽선 굵기 배율을 저장하고 즉시 적용한다.
- 새 문서 기본 폭, 높이, 두께와 단위를 저장한다.
- Restore Defaults, OK, Cancel을 제공한다.
- View 메뉴의 작업 중 표시 전환 명령과 안전 확인 정책은 Settings로 이동하지 않는다.

## Scope

- 사용자 설정 모델과 JSON 호환
- Settings Window와 MainWindow 연결
- Flat/Section/3D 환경값 적용

## Implementation Notes

기존 설정 JSON에 새 필드를 선택적으로 추가하여 이전 설정 파일을 그대로 읽는다. 범위를 벗어난 값은 로딩 또는 입력 확인에서 안전한 범위로 제한한다.

## Acceptance Criteria

1. Edit > Settings와 Ctrl+,로 창이 열린다.
2. 설정값은 재시작 후 유지된다.
3. Zoom, 선택 허용 거리, 핸들 크기와 3D 표현 설정이 현재 화면에 적용된다.
4. New는 설정된 기본 크기, 두께와 단위로 문서를 만든다.
5. Cancel은 변경을 저장하지 않는다.
6. Restore Defaults가 기본값을 입력한다.
7. 전체 자동 회귀 테스트가 통과한다.
