# CR-023 문서 단위와 두 가지 단위 변경 방식

## Status

Implemented

## Source

2026-10-03 user request and approved unit-change design.

## Request

mm, cm, m 문서 단위를 지원하고, 단위 변경 시 숫자를 유지하여 물리 크기를 바꾸거나 실제 크기를 유지하도록 모든 숫자를 자동 환산하는 두 방식을 제공한다.

## Background

기존 문서는 내부와 표시 모두 cm로 고정되었으며 DXF `$INSUNITS`도 항상 centimeters였다.

## Current Behavior

CAM 장비 단위에 맞추거나 기존 도면의 물리 배율을 단위 재해석으로 변경할 수 없다.

## Required Behavior

- Edit > Document Units 창에서 mm/cm/m를 선택한다.
- 실제 크기 유지 방식은 모든 길이, 좌표, 두께, 반지름, Section, Cut, Micro Joint와 Outer Contour 값을 환산한다.
- 숫자 유지 방식은 숫자를 바꾸지 않고 문서 단위와 물리적 해석만 변경한다.
- 변경 전후 폭 예시와 결과 설명을 표시한다.
- 단위를 문서 메타데이터와 DXF `$INSUNITS`에 저장하고 다시 연다.
- 단위 변경은 미저장 변경 및 Undo/Redo 대상이다.
- 기존 cm 문서와 단위 표식 없는 레거시 문서의 호환성을 유지한다.

## Scope

- 문서 단위 모델과 두 변환 정책
- DXF 저장/복원 단위
- 표시 단위 레이블
- 새 문서 및 일반 DXF import의 기본 단위 적용

## Implementation Notes

문서 숫자는 선택 단위의 값으로 보관한다. 실제 크기 유지 변환 계수는 이전 단위의 meter factor를 새 단위 factor로 나눈 값이다. 숫자 유지 방식은 geometry 값을 변경하지 않는다.

## Acceptance Criteria

1. cm 300을 실제 크기 유지로 mm로 바꾸면 3000 mm가 된다.
2. cm 300을 숫자 유지로 mm로 바꾸면 300 mm가 된다.
3. 모든 geometry 및 제조 관련 길이값이 실제 크기 유지 방식에서 같은 비율로 변환된다.
4. DXF `$INSUNITS`와 메타데이터가 문서 단위를 기록한다.
5. 저장 후 다시 열면 단위와 숫자가 동일하다.
6. Undo/Redo가 단위와 숫자를 함께 복원한다.
7. 전체 자동 회귀 테스트가 통과한다.
