# CR-024 문서명 우선 Window Title

## Status
Implemented

## Request
2026-10-03 사용자 요청: Window Title을 `Filename.dxf - CosmicDesigner` 형식으로 개선한다.

## Background
문서 기반 Windows 프로그램은 작업 중인 문서를 먼저 식별할 수 있도록 문서명을 애플리케이션명보다 앞에 두는 것이 일반적이다.

## Current Behavior
파일을 열거나 저장하면 `CosmicDesigner — Filename.dxf`로 표시되고 새 문서는 `CosmicDesigner`만 표시된다.

## Required Behavior
- 열린 파일과 저장된 파일은 `Filename.dxf - CosmicDesigner`로 표시한다.
- 새 문서는 `Untitled - CosmicDesigner`로 표시한다.
- 시작, New, Open, Save/Save As에서 같은 규칙을 사용한다.
- 저장되지 않은 변경이 있으면 문서명 앞에 `*`를 붙이고 저장하면 제거한다.

## Scope
Main Window Title 문자열 구성만 변경한다.

## Implementation Notes
공통 `WindowTitleFormatter`를 사용한다.

## Acceptance Criteria
- 새 문서 제목은 `Untitled - CosmicDesigner`이다.
- `Sample.dxf`를 열거나 저장하면 `Sample.dxf - CosmicDesigner`이다.
- 전체 경로가 아닌 파일명만 표시된다.
- 변경 후에는 `*Sample.dxf - CosmicDesigner`, 저장 후에는 `Sample.dxf - CosmicDesigner`가 표시된다.
