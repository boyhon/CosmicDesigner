# CR-025 Ruler 및 Grid 간격 설정

## Status
Implemented

## Request
2026-10-03 사용자 요청: Settings에서 가로 Ruler 눈금 간격, 세로 Ruler 눈금 간격, Grid 간격을 설정할 수 있게 한다. 검토 후 제안된 Auto 기본값, 물리 간격 유지 및 축소 시 안전한 자동 생략 방식을 승인받아 구현한다.

## Background
기존 Flat Designer는 가로 Ruler, 세로 Ruler와 Grid가 화면 배율에서 계산한 하나의 자동 간격을 공유한다.

## Current Behavior
Ruler와 Grid 표시 여부만 설정할 수 있고 각 간격은 사용자가 지정할 수 없다.

## Required Behavior
- Settings에 `Ruler & Grid` 탭을 제공한다.
- 가로 Ruler, 세로 Ruler 및 Grid 기본 간격을 독립 설정한다.
- 각 값은 `Auto` 또는 현재 문서 단위의 양수다.
- 사용자 지정 간격은 물리 길이로 저장해 문서 단위가 바뀌어도 실제 간격을 유지한다.
- 축소 시 1·2·5 배수로 선과 숫자를 생략해 과밀 렌더링을 방지한다.
- 표시 설정은 문서 수정 상태와 Undo/Redo에 영향을 주지 않는다.

## Scope
Flat Designer의 Ruler/Grid 렌더링과 사용자 설정 저장에 한정한다.

## Implementation Notes
- 설정에는 간격을 metre 기준으로 저장하고 Settings UI에서 현재 문서 단위로 환산한다.
- `0`은 Auto로 취급해 기존 자동 간격 계산을 유지한다.
- Grid는 최소 8px, Ruler 표시는 최소 45px를 기준으로 1·2·5 배수 간격을 선택한다.

## Acceptance Criteria
- 세 가지 간격을 독립적으로 저장하고 재시작 후 복원한다.
- Auto에서는 기존 자동 간격을 사용한다.
- 단위 변경 전후의 사용자 지정 물리 간격이 동일하다.
- 과도하게 축소해도 조밀한 선이나 중첩 숫자를 무제한 렌더링하지 않는다.
- Settings 적용 직후 Flat Designer가 갱신되고 문서 제목에 `*`가 추가되지 않는다.
