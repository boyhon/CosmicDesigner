# CR-026 Flat Designer 절삭 영역 흰색 표시

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: Cut Object의 안쪽과 Outer Contour의 바깥쪽은 잘려 나가는 영역이므로 바탕색인 흰색으로 표시한다.

## Background
Flat Designer는 재료 전체 바운딩 사각형에 재료색과 Grid를 그린 뒤 실제 Outer/Cut 윤곽선만 덧그렸다.

## Current Behavior
Cut 내부와 Outer Contour에서 제거된 노치 영역에도 재료색과 Grid가 남아 있어 실제 잔존 재료로 오인될 수 있다.

## Required Behavior
- 실제 Outer Contour 내부에서 Cut Object 내부를 제외한 영역만 재료로 채운다.
- Cut 내부와 Outer Contour 외부는 흰색 바탕으로 표시한다.
- Grid와 절곡선은 실제 재료 영역에서만 표시한다.
- Outer Contour와 Cut 경계선 및 H/W Section 선택선은 계속 식별할 수 있어야 한다.

## Scope
Flat Designer의 2D 렌더링에 한정하며 설계 형상과 DXF 데이터는 변경하지 않는다.

## Implementation Notes
Outer Contour와 Cut 윤곽을 Even-Odd FillRule의 렌더링 마스크로 만들고 재료 채움, Grid 및 절곡선을 이 마스크로 제한한다.

## Acceptance Criteria
- 원형과 다각형 Cut 내부가 흰색으로 표시된다.
- Outer Contour 병합으로 제거된 노치가 흰색으로 표시된다.
- 절삭 영역에 Grid 및 절곡선이 표시되지 않는다.
- 재료 윤곽선과 선택 표시는 기존처럼 보인다.
