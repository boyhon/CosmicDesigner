# CR-027 3D Preview 내부 Cut 투명 표시

## Status
Implemented

## Request
2026-10-03 사용자 요청: Flat Designer와 마찬가지로 3D Preview에서도 잘려 나간 영역을 투명하게 표시한다.

## Background
CR-019는 변경된 Outer Contour와 병합 노치를 3D 메시에서 제거했지만 독립적인 내부 Cut Object는 면 생성에서 제외하지 않았다.

## Current Behavior
Flat Designer에서 흰색 구멍으로 보이는 Cut Object 위치에도 3D Preview의 재료 면이 남는다.

## Required Behavior
- 모든 내부 Cut Object 영역에 3D triangle face를 생성하지 않는다.
- Cut 경계는 검은 외곽 Edge로 표시한다.
- Outer Contour 노치, 절곡 형상, 투명도, 회전과 Zoom 동작을 유지한다.
- Cut 이동 및 크기 변경 후 Preview를 즉시 다시 계산한다.

## Scope
현재 지원되는 Circle 및 선분 기반 Cut 형상의 3D surface mesh 생성에 한정한다.

## Implementation Notes
Cut 윤곽의 좌표를 메시 셀 분할 station에 포함하고 셀 중심이 Cut 다각형 내부이면 해당 triangle을 생성하지 않는다. Circle은 24개 경계점으로 근사한다.

## Acceptance Criteria
- Circle Cut 중심에 3D face가 존재하지 않는다.
- 다각형 Cut 내부에 3D face가 존재하지 않는다.
- Cut 둘레가 3D Edge로 식별된다.
- 기존 Outer Contour 노치와 절곡 메시 검증이 계속 통과한다.

- 기존 직사각형, Outer Contour 노치와 절곡 메시 회귀 검증을 포함한 전체 테스트를 통과했다.
