# CR-028 3D Preview 내부 절곡 Edge 제거

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: Circle Cut 부근을 가로지르는 가로 3개와 세로 1개의 불필요한 직선을 제거한다.

## Background
3D surface mesh는 실제 외곽 Edge 외에도 W/H 절곡 station의 내부 공유 Edge를 검은 선으로 강제 표시했다.

## Current Behavior
절곡 위치의 내부 선들이 재료와 구멍을 가로질러 나타나 3D 형상 이해를 방해한다.

## Required Behavior
- 3D Preview는 Outer Contour와 Cut 경계 Edge만 표시한다.
- 내부 절곡선과 메시 분할선은 표시하지 않는다.
- 절곡된 면의 실제 각도와 형상은 유지한다.

## Scope
3D Preview Edge 추출 정책에 한정한다.

## Implementation Notes
두 triangle이 공유하는 Edge는 내부선으로 제외하고 한 triangle만 사용하는 경계 Edge만 출력한다. 절곡 station은 surface 분할과 좌표 변환에는 계속 사용한다.

## Acceptance Criteria
- 재료 중앙을 가로지르는 내부 절곡 Edge가 표시되지 않는다.
- Outer Contour와 Cut 둘레 Edge는 유지된다.
- 절곡 후 면의 3D 위치와 각도는 바뀌지 않는다.
- 기존 Cut 투명 영역과 노치가 유지된다.
