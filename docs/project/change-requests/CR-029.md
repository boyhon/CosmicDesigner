# CR-029 3D Preview V/V1 절곡선 색상 표시

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: 3D Preview에서 접힌 모서리를 인식할 수 있도록 V Line은 적색, V1 Line은 청색으로 표시한다.

## Background
CR-028에서 불필요한 검은 내부 메시 선을 제거한 결과 접힌 모서리의 절곡 종류를 시각적으로 구분하기 어려워졌다.

## Current Behavior
3D 면의 절곡 형상은 유지되지만 V/V1 위치를 나타내는 색상 Edge가 없다.

## Required Behavior
- 실제 V 절곡 위치를 적색 Edge로 표시한다.
- 실제 V1 절곡 위치를 청색 Edge로 표시한다.
- 절곡선은 남아 있는 재료 구간에만 표시하고 Cut 영역을 가로지르지 않는다.
- Outer Contour와 Cut 경계는 검은색으로 유지한다.
- 메시 분할선이나 임의의 내부선은 표시하지 않는다.

## Scope
3D Preview의 실제 절곡 Edge 데이터 및 색상 렌더링에 한정한다.

## Implementation Notes
3D surface 분할에 사용하는 W/H 절곡 station에서 실제 재료가 존재하는 구간만 `SurfaceBendEdge`로 생성한다. Preview는 Layer가 V이면 Red, V1이면 DodgerBlue 재질을 사용한다.

## Acceptance Criteria
- V 절곡선은 적색이다.
- V1 절곡선은 청색이다.
- Cut과 노치 구간에서는 색상 절곡선이 끊긴다.
- 검은 Edge는 실제 Outer/Cut 윤곽에만 남는다.
- 절곡된 면의 형상, 투명도, 회전과 Zoom 기능은 유지된다.
