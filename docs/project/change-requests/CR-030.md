# CR-030 삼각형 Cut 꼭짓점 직접 편집

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: 삼각형을 하나의 고정 Triangle 명령처럼 다루지 않고 세 직선의 이음으로 표시하며, PowerPoint처럼 각 꼭짓점을 직접 이동하여 일반 삼각형, 직각삼각형과 이등변삼각형 등을 쉽게 만들 수 있게 한다.

## Background
Triangle Cut은 내부적으로 이미 세 LINE으로 생성되지만 Flat Designer에서는 다른 Cut과 동일한 사각 바운딩 핸들만 제공했다.

## Current Behavior
삼각형의 바운딩 사각형 모서리와 변 중앙을 움직이면 정규 삼각형을 다시 생성하므로 각 꼭짓점을 독립적으로 배치할 수 없다.

## Required Behavior
- 선택된 Triangle Cut에 세 꼭짓점 핸들을 표시한다.
- 각 꼭짓점 핸들을 독립적으로 드래그해 임의의 삼각형을 만든다.
- 삼각형 내부를 드래그하면 현재 꼭짓점 관계를 유지한 채 전체 도형을 이동한다.
- 삼각형은 폐합된 세 LINE으로 유지되고 Flat 절삭 마스크, 저장 및 3D Preview에 동일하게 반영된다.

## Scope
Triangle Cut의 모델 갱신, Flat Designer 선택/Hit Testing/드래그 UI, DXF 메타데이터 왕복 및 관련 검증에 한정한다.

## Implementation Notes
Triangle Cut의 Geometry에 저장된 세 LINE의 시작점을 꼭짓점으로 사용한다. 꼭짓점 이동 시 세 LINE을 폐합 순서로 다시 연결하고 Cut의 중심과 바운딩 치수를 갱신한다. 일반 크기 핸들 대신 세 꼭짓점 핸들을 표시하며 몸체 선택은 실제 삼각형 내부로 제한한다.

## Acceptance Criteria
- Triangle Cut 선택 시 정확히 세 꼭짓점 편집 핸들이 표시된다.
- 어느 꼭짓점도 독립적으로 이동할 수 있고 세 LINE은 항상 폐합된다.
- 삼각형 내부 드래그는 변형 없이 전체 도형을 이동한다.
- 꼭짓점은 재료 범위 밖으로 이동하지 않는다.
- 편집한 임의 삼각형이 저장 후 다시 열어도 보존된다.
- 기존 Cut, Flat 절삭 영역 및 3D Preview 회귀 검증이 통과한다.
