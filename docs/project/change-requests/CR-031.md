# CR-031 원·삼각형·사각형 Cut 드래그 생성

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: 천공 도구에서 한 번 클릭하면 작고 식별하기 어려운 기본 도형이 생기고 Resize하려다 같은 객체가 반복 생성되는 문제를 해결한다. PowerPoint처럼 기준점을 누르고 드래그한 범위에 따라 원, 삼각형과 사각형의 최초 크기를 정한다.

## Background
기존 Hole 도구는 Flat Designer의 클릭 위치에 항상 5 × 5 기본 Cut을 즉시 생성하며 생성 도구도 계속 활성화했다.

## Current Behavior
작은 기본 Cut은 선택 핸들을 잡기 어렵고, 사용자가 크기를 조절하려고 다시 클릭하면 새로운 Cut이 계속 추가될 수 있다.

## Required Behavior
- Circle, Triangle, Rectangle 도구는 Mouse Down 위치를 기준점으로 사용한다.
- 드래그 중 최종 형상을 점선으로 미리 표시한다.
- Mouse Up 시 드래그 범위의 위치와 크기로 Cut을 한 개 생성한다.
- 짧은 단순 클릭은 Cut을 생성하지 않는다.
- 생성 후 자동으로 Select 모드로 돌아가 반복 생성을 방지한다.
- Circle은 드래그 범위 안에서 가로·세로가 같은 원으로 생성한다.

## Scope
Circle, Triangle, Rectangle의 Flat Designer 최초 생성 상호작용에 한정한다. 다른 Hole 도구의 형상 계산은 변경하지 않는다.

## Implementation Notes
화면상 4픽셀 이상 드래그한 경우에만 설계 좌표의 생성 바운드를 계산한다. 시작점과 끝점은 재료 범위로 제한하고, Circle은 두 축 중 짧은 길이를 지름으로 사용한다. 임시 Cut Geometry를 사용해 실제 생성 결과와 같은 점선 미리보기를 그린다.

## Acceptance Criteria
- Circle, Triangle, Rectangle은 드래그 완료 전까지 문서에 추가되지 않는다.
- 드래그 중 실제 생성될 크기의 미리보기가 보인다.
- 생성된 Cut의 중심, 너비와 높이는 드래그 범위와 일치한다.
- Circle의 너비와 높이는 같다.
- 단순 클릭이나 너무 짧은 드래그로 Cut이 생성되지 않는다.
- 한 개 생성 후 Select 모드로 복귀한다.
- Undo는 생성 작업 전체를 한 번의 편집으로 처리한다.
