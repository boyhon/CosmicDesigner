# CR-032 Triangle Cut Outer Contour 명시적 통합

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: Triangle Cut이 Outer Contour와 겹치면 선택 표시가 노란색에서 주황색으로 바뀌고, 우측 버튼의 통합 명령으로 Outer Contour에 반영되도록 한다.

## Background
CR-015의 병합 후보 표시와 명시적 우클릭 통합 절차는 Rectangle Cut에만 구현되어 있었다.

## Current Behavior
삼각형의 꼭짓점 또는 변이 Outer Contour와 겹쳐 실제 외곽 노치로 변환할 수 있어도 후보로 판정되지 않고 노란색으로 남는다.

## Required Behavior
- Triangle Cut과 현재 Outer Contour의 차집합이 하나의 폐곡선이면 병합 후보로 판정한다.
- 선택된 후보 Triangle을 기존과 같은 주황색으로 표시한다.
- 우클릭 `Outer Contour로 통합` 명령을 제공한다.
- 확정하면 Triangle Cut과 대응 Inner Contour를 제거하고 삼각형의 사선을 포함한 새 Outer Contour LINE들을 만든다.
- 완전히 내부에 있어 독립 Hole이 되는 Triangle이나 결과가 복수 외곽으로 나뉘는 경우에는 후보로 판정하지 않는다.
- Undo와 저장/3D/Section 갱신은 기존 병합 절차를 재사용한다.

## Scope
LINE 세 개로 폐합된 Triangle Cut과 LINE 기반 Outer Contour의 명시적 통합에 한정한다.

## Implementation Notes
WPF의 벡터 Geometry Exclude 연산으로 현재 Outer Contour에서 Triangle polygon을 제외한다. 결과가 정확히 하나의 닫힌 PathFigure이며 실제 면적이 감소한 경우에만 LINE contour로 변환한다. 기존 `CanMergeBoundaryCut`, 주황색 표시, 컨텍스트 메뉴 및 Undo 경로를 그대로 사용한다.

## Acceptance Criteria
- 좌상·우상·좌하·우하 모서리에 겹친 Triangle이 병합 후보가 된다.
- 후보 선택 표시는 주황색이며 떨어지면 노란색으로 복원된다.
- 우클릭 통합 후 Cut과 Inner Contour가 제거된다.
- 새 Outer Contour는 Triangle의 비직교 사선을 보존한다.
- 완전히 내부인 Triangle은 병합 후보가 아니다.
- 기존 Rectangle 반복 병합 검증이 계속 통과한다.
