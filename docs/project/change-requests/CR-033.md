# CR-033 Outer Contour 직각 모서리 Fillet

## Status
Implemented

## Request
2026-10-03 사용자 요청과 후속 승인: Outer Contour의 각진 모서리를 4분원 호로 둥글게 다듬는 Fillet 기능을 구현한다. 3D Preview는 직관적인 대략 형상 확인용이므로 완전한 원호가 아니라 현을 사용한 각진 근사로 남아도 된다.

## Background
Outer Contour는 LINE/ARC 저장과 Flat 렌더링을 지원하지만 사용자가 연결된 두 LINE을 접선 ARC로 변환하는 설계 도구는 없었다.

## Current Behavior
외곽 모서리를 둥글게 하려면 DXF를 외부에서 직접 편집해야 하며 CosmicDesigner UI에서는 생성할 수 없다.

## Required Behavior
- Flat Designer 하단에 Fillet 반지름 입력과 Fillet 도구를 제공한다.
- 초기 범위는 두 LINE이 직각으로 연결된 볼록 Outer Contour 모서리이다.
- Fillet 모드에서 적용 가능한 모서리에 마우스를 올리면 주황색 점선 결과를 미리 표시한다.
- 클릭하면 인접 LINE 두 개를 반지름만큼 줄이고 그 사이에 접하는 4분원 ARC를 삽입한다.
- 반지름이 인접 LINE보다 크거나 오목/비직각 모서리에는 적용하지 않는다.
- 작업은 Undo할 수 있고 DXF에는 ARC로 저장한다.
- 3D Preview는 ARC의 두 접점을 직선으로 연결한 현으로 근사한다.

## Scope
LINE으로 구성된 CCW Outer Contour의 직각 볼록 꼭짓점과 단일 반지름 Fillet에 한정한다. 임의 각도, 오목 Fillet 및 3D 곡면 세분화는 제외한다.

## Implementation Notes
선택 꼭짓점의 이전/다음 LINE 방향, 직교성, polygon 방향과 볼록성을 검사한다. 두 접점을 계산해 기존 LINE 끝점을 교체하고 수학 좌표계의 90도 `ArcSegment`를 사이에 삽입한다. 3D polygon 생성에서는 ARC 시작점과 다음 LINE 시작점을 연속 꼭짓점으로 사용해 현으로 근사한다.

## Acceptance Criteria
- 기본 사각 재료의 네 볼록 모서리에 유효한 Fillet 미리보기가 나타난다.
- R10 적용 시 두 접점이 원래 꼭짓점에서 각각 10만큼 떨어지고 ARC 반지름이 10이다.
- 결과 Outer Contour는 연결된 LINE/ARC 폐곡선을 유지한다.
- 너무 큰 반지름과 오목/비직각 모서리는 거부한다.
- Undo로 적용 전 Outer Contour를 복원할 수 있다.
- 저장된 DXF와 CosmicDesigner 메타데이터에 ARC가 보존된다.
- 3D Preview가 비어 있거나 끊어지지 않고 현 근사 외곽을 표시한다.
