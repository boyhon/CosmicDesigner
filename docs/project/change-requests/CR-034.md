# CR-034 다중 모서리 연속 Fillet 교정

## Status
Implemented

## Request
2026-10-03 사용자 시험 및 첨부 화면: 좌상 코너에는 Fillet이 적용되지만 그 후 우상, 좌하, 우하 코너에는 적용되지 않는 오류를 개선한다.

## Background
CR-033은 첫 번째 직각 볼록 모서리를 LINE–ARC–LINE으로 변환했다.

## Current Behavior
Fillet 계산기는 Outer Contour 전체가 LINE으로만 이루어졌을 때만 작동하므로 첫 ARC가 삽입된 직후 다른 모든 모서리를 거부한다.

## Required Behavior
- 기존 Fillet ARC가 포함된 Outer Contour에서도 남은 LINE–LINE 볼록 직각 코너를 계속 찾는다.
- 좌상, 우상, 좌하, 우하 네 기본 모서리에 순서와 관계없이 각각 Fillet을 적용할 수 있다.
- 기존 ARC와 접점은 변경하지 않는다.
- 과대 반지름, ARC에 직접 인접한 이미 가공된 코너와 유효하지 않은 모서리는 계속 거부한다.

## Scope
CR-033 Fillet 후보 판정과 다중 ARC Outer Contour의 방향 계산 교정에 한정한다.

## Implementation Notes
전체 contour의 LINE 전용 조건을 제거하고 선택 꼭짓점의 이전/현재 segment만 LINE인지 검사한다. polygon 방향 계산에는 LINE 시작점과 기존 ARC 시작점을 함께 사용한다.

## Acceptance Criteria
- 기본 사각형의 네 모서리에 R10 Fillet을 연속 적용할 수 있다.
- 결과는 네 LINE과 네 ARC로 이루어진 하나의 폐곡선이다.
- 각 ARC의 반지름이 10으로 유지된다.
- DXF 저장·재열기 후 네 ARC가 모두 보존된다.
- 3D 현 근사와 기존 회귀 검증이 통과한다.
