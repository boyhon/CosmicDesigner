# CR-035 Fillet ARC 선택 표시 및 반지름 편집

## Status
Implemented

## Request
2026-10-03 사용자 요청 및 첨부 화면: OBJECTS에서 `L ARC`를 선택해도 Flat Designer에서 선택 여부를 확인할 수 없는 문제를 해결하고, Selected object 속성에 Fillet의 `R` 값을 추가하여 더 큰 코너 라운드로 수정할 수 있게 한다.

## Background
기존 Outer Contour 선택 강조는 LINE에만 구현되어 있으며 GeometryObject ARC 속성에는 Layer와 Entity만 표시했다.

## Current Behavior
- Object Tree에서 ARC를 선택해도 Flat Designer의 시각적 피드백이 없다.
- 생성 시 지정한 Fillet 반지름을 나중에 변경할 수 없다.

## Required Behavior
- 선택된 Outer Contour ARC를 Flat Designer에서 노란색 강조선으로 표시한다.
- ARC의 두 접점에 선택 핸들을 표시한다.
- Selected object에 현재 문서 단위의 `Radius R` 편집 속성을 제공한다.
- 반지름 변경 시 원래 직각 꼭짓점을 기준으로 인접 LINE 두 개와 접선 ARC를 함께 다시 계산한다.
- 폐곡선 연결, Undo, DXF 저장과 3D 근사를 유지한다.
- 인접 LINE보다 큰 유효하지 않은 반지름은 적용하지 않는다.

## Scope
CR-033/CR-034로 생성된 Outer Contour Fillet `ArcSegment`의 선택 표시와 반지름 편집에 한정한다.

## Implementation Notes
선택 ARC 앞뒤의 LINE을 무한 직선으로 연장해 원래 꼭짓점을 구한 후 ARC를 제거한 임시 LINE–LINE contour를 복원하고 기존 Fillet 계산을 새 반지름으로 다시 적용한다. 성공 후 새 ARC GeometryObject를 다시 선택한다.

## Acceptance Criteria
- Object Tree의 `L ARC` 선택 시 해당 호만 굵은 노란색으로 표시된다.
- 호 양 끝에 흰색/노란색 접점 핸들이 보인다.
- Selected object에서 `Radius R`을 편집할 수 있다.
- R10을 R20으로 변경하면 ARC 중심과 두 LINE 접점이 함께 이동한다.
- 변경 후 Outer Contour가 연결된 폐곡선을 유지한다.
- 과도한 반지름은 거부되고 Undo/Redo 및 DXF 왕복이 유지된다.
