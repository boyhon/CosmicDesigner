# CR-036 임의 각도 및 내부 Hole Fillet

## Status
Implemented

## Request
2026-10-03 사용자 요청: 직각이 아닌 임의 각도의 Fillet을 지원하고 내부 Hole을 펀칭한 도형에도 Fillet을 적용한다.

## Background
CR-033~CR-035의 Fillet은 Outer Contour의 볼록 직각 LINE–LINE 코너에 한정되어 있었다.

## Current Behavior
- 경사 LINE과 수평/수직 LINE이 만나는 예각·둔각 코너는 Fillet 후보가 아니다.
- 내부 Triangle, Rectangle, Polygon Cut의 꼭짓점에는 Fillet을 적용할 수 없다.

## Required Behavior
- 평행하지 않은 두 LINE의 실제 내각으로 접선 거리와 ARC 중심을 계산한다.
- 유효한 볼록 예각, 직각과 둔각 코너에 지정 반지름 Fillet을 적용한다.
- Outer Contour와 LINE 기반 내부 Hole contour에 동일한 미리보기 및 클릭 적용을 제공한다.
- Cut Geometry와 대응 Inner Contour를 함께 갱신한다.
- Object Tree에서 Cut을 펼치면 하위 LINE/ARC를 선택할 수 있고 Hole ARC의 `Radius R`도 편집할 수 있다.
- Circle처럼 꼭짓점이 없는 도형은 Fillet 대상에서 제외한다.
- 3D Preview에서는 Outer/Hole ARC를 모두 접점 사이의 직선 현으로 근사한다.

## Scope
CCW 방향의 LINE 기반 폐합 Outer/Cut contour의 볼록 LINE–LINE 코너에 한정한다. 오목 코너와 ARC–LINE 직접 Fillet은 제외한다.

## Implementation Notes
내각 `θ`와 반지름 `R`에 대해 각 LINE을 `R / tan(θ/2)`만큼 절단하고, 진행 방향의 좌측 법선으로 반지름만큼 이동한 점을 ARC 중심으로 사용한다. contour 대상 ID를 Fillet 이벤트에 포함하여 Outer와 Cut을 공통 처리한다.

## Acceptance Criteria
- 예각 Triangle 코너에 정확한 접선 ARC를 삽입할 수 있다.
- 직각과 둔각의 기존 동작이 유지된다.
- Rectangle, Triangle 및 LINE 기반 Polygon Hole에 Fillet을 적용할 수 있다.
- Cut과 대응 Inner Contour의 segment 목록이 일치한다.
- Hole ARC를 Object Tree에서 선택하고 Radius R을 변경할 수 있다.
- 과도한 반지름과 평행/퇴화 코너는 거부한다.
- DXF 저장·재열기 및 3D 현 근사에서 Hole ARC가 유지된다.
