## Status
Implemented

## Request
2026-10-04 사용자 요청: “Arc Sector Ellipse Pentagon Hexagon Polygon 버튼은 일단 모두 삭제하세요. 이들은 향후 개별적 요청이 있을 경우 하나씩 처리해서 구현합시다.” 남은 도형 이름 버튼은 첨부한 원, 삼각형, 사각형, 마름모, 평행사변형 그림처럼 작은 아이콘 버튼으로 배치한다.
출처: 대화 및 첨부 이미지 5개 (codex-clipboard-8b188d86, 414d2555, 1a2c60f2, c8f64216, f7474789).

## Background
모든 천공 도구를 한 번에 완성하는 대신 현재 UI 범위를 줄이고 향후 개별 요청으로 확장한다.

## Current Behavior
Flat Designer에는 11개 도형 이름이 텍스트 버튼으로 표시된다.

## Required Behavior
- Arc, Sector, Ellipse, Pentagon, Hexagon, Polygon 버튼을 제거한다.
- Circle, Triangle, Rectangle, Diamond, Parallelogram은 첨부 그림에 대응하는 작은 윤곽 아이콘으로 표시한다.
- 도형 이름은 Tooltip 및 접근성 이름으로 제공한다.
- 제거한 도구는 향후 개별 요청으로 구현한다.

## Scope
천공 도구 UI만 변경한다. 기존 문서의 도형 모델 및 저장/읽기 호환성을 유지한다.

## Implementation Notes
기존 WPF 벡터 요소를 사용하여 첨부 그림의 어두운 청록색 윤곽을 재현한다. 각 버튼의 Tag와 기존 클릭 핸들러를 유지한다. 작은 UI 변경이므로 ADR은 추가하지 않는다.

## Acceptance Criteria
- 제거 대상 여섯 도구 버튼이 없다.
- 남은 다섯 도구는 텍스트 대신 각 도형 아이콘을 표시한다.
- 각 아이콘의 Tooltip과 접근성 이름으로 도형을 식별할 수 있다.
- 기존 클릭 핸들러를 통해 동일한 도형 도구가 선택된다.
- Release 빌드 및 기존 자동 검증이 통과한다.
