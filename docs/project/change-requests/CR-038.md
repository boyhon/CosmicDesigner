# CR-038 다이아몬드·평행사변형 드래그 생성

## Status
Implemented

## Request
2026-10-04 대화 사용자 요청: “다이아몬드, 평행사변형 ... 앞의 세개의 도형처럼 클릭 후 드래그 하면 그에 맞는 크기의 도형을 생성하도록 해 주세요.”

## Background
CR-031은 원·삼각형·사각형의 드래그 생성만 구현했고 CR-037은 천공 버튼 표시만 변경했다.

## Current Behavior
Diamond와 Parallelogram은 클릭 즉시 기본 크기로 생성된다.

## Required Behavior
두 도구도 누른 위치부터 드래그한 크기로 점선 미리보기를 표시하고 Mouse Up에서 한 개 생성한다. 단순 클릭은 생성하지 않으며 완료 후 Select 모드로 돌아간다.

## Scope
Diamond와 Parallelogram의 최초 생성 상호작용. 기존 도형 및 DXF 저장 형식은 유지한다.

## Implementation Notes
공통 HoleDragEngine 지원 도형을 확장하여 기존 미리보기, 최소 드래그 거리, 재료 경계 제한, 생성 이벤트 및 Undo 경로를 그대로 사용한다. CR-031/CR-037의 기록은 유지한다. ADR은 불필요하다.

## Acceptance Criteria
- 두 도형 모두 Mouse Down에서 생성되지 않고 드래그 중 실제 형상의 점선 미리보기가 보인다.
- Mouse Up에서 드래그 범위의 중심과 가로·세로 크기로 한 개 생성된다.
- 역방향 드래그도 동작하며 재료 경계로 제한한다.
- 단순 클릭 또는 너무 작은 드래그로 생성되지 않는다.
- 생성 후 Select 모드로 돌아가며 Undo 한 번으로 생성 작업을 되돌린다.
- 기존 원·삼각형·사각형 검증과 전체 Release 빌드가 통과한다.
