# CR-039 3D 천공 면과 윤곽선 정합성 교정

## Status
Implemented

## Request
2026-10-04 사용자 보고: “3D Preview에 펀치된 공간이 하얗게 보이는데 ... 선과 색의 영역이 일치하지 않는다.”

## Background
CR-027/CR-028의 면 제거와 윤곽선 생성 방식이 서로 다른 경계를 사용한다.

## Current Behavior
격자 삼각형의 중심만 검사하여 전체 면을 삭제하므로 사선/곡선 근사 윤곽 부근의 재료 면이 과다 삭제되거나 구멍 안으로 침범한다.

## Required Behavior
3D 천공 공간과 표시 윤곽선이 동일한 경계에 맞도록 재료 면을 잘라 생성한다. 절곡된 면에도 동일하게 적용한다.

## Scope
3D 면 분할 교정. 기존 Circle 24각형 및 Fillet ARC 현 근사 정책과 DXF 형식은 유지한다.

## Implementation Notes
각 절곡 격자 셀을 실제 Outer/Cut 윤곽선과 교차하는 직선으로 분할한 후 재료에 속하는 볼록 조각만 삼각화한다. 선과 면에 동일한 근사 윤곽을 사용한다. 새로운 아키텍처 도입 없이 기존 엔진을 교정하므로 ADR은 추가하지 않는다.

## Acceptance Criteria
- 원·삼각형·사각형·마름모·평행사변형의 면 제거 영역과 윤곽선이 일치한다.
- 실제 면적이 외곽 면적에서 천공 근사 윤곽 면적을 뺀 값과 일치한다.
- 겹친 천공, 비직교 외곽 및 절곡 교차에서도 재료 면이 경계를 넘지 않는다.
- 기존 자동 검증 및 Release 빌드 통과.
