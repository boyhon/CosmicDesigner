# CR-040 평행사변형 Cut Outer Contour 통합

## Status
Implemented

## Request
2026-10-04 사용자 요청: “평행사변형은 Outer Contour에 겹치는 선을 가지고 있으므로 삼각형이나 사각형처럼 outer contour에 통합시킬 수 있어야 합니다. 주황색 선택 표시를 하고 통합 작업을 진행해 주세요.”

## Background
CR-032의 다각형 차집합 통합은 Triangle만 지원한다.

## Current Behavior
외곽 경계에 닿은 평행사변형은 병합 후보로 표시되지 않는다.

## Required Behavior
- 안전하게 하나의 폐합 외곽으로 통합할 수 있는 평행사변형은 주황색 선택 표시한다.
- 우클릭 Outer Contour로 통합 명령을 제공한다.
- 통합 시 Cut 및 대응 Inner Contour를 제거하고 사선을 보존한 Outer Contour를 갱신한다.
- Undo, 저장/읽기 및 Section/3D 갱신은 기존 통합 흐름을 사용한다.

## Scope
LINE 기반 평행사변형과 Outer Contour의 통합. 내부 Hole, 복수 재료 조각을 만드는 차집합은 통합하지 않는다. 다른 도형 지원 범위는 유지한다.

## Implementation Notes
Parallelogram을 기존 Triangle의 다각형 차집합 후보 판정 경로에 추가한다. 선택색, 우클릭 명령 및 이벤트 처리기를 재사용한다. ADR 불필요.

## Acceptance Criteria
- 상하 경계 및 모서리에 겹친 평행사변형이 후보가 된다.
- 후보 선택색은 주황색이고 외곽에서 떨어지면 일반 선택색으로 돌아간다.
- 명시적 통합만 Cut/Inner Contour를 제거하며 새 외곽은 폐합 및 사선을 유지한다.
- 내부 Hole과 재료를 분리하는 Cut은 후보가 아니다.
- Undo/Redo 및 DXF 왕복 검증과 전체 자동 검증 통과.
