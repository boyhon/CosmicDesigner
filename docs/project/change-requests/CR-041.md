# CR-041 삼각형 천공 드래그 방향 반영

## Status
Implemented

## Request
2026-10-04 사용자 요청: “클릭한 후 아래로 드래그 하면 역삼각형을 위로 드래그 하면 바로 선 삼각형을 그리도록 개선하라.”

## Background
CR-031의 드래그 생성에서 삼각형 방향이 고정되어 있다.

## Current Behavior
드래그 방향과 관계없이 역삼각형이 생성된다.

## Required Behavior
- 아래 방향 드래그는 꼭짓점이 아래를 향한 역삼각형을 생성한다.
- 위 방향 드래그는 꼭짓점이 위를 향한 삼각형을 생성한다.
- 드래그 중 점선 미리보기와 생성 결과가 일치한다.
- 기존 선택 복귀, 최소 크기 거부, 꼭짓점 편집, Undo 및 저장 동작을 유지한다.

## Scope
삼각형 최초 생성만 변경하며 다른 천공 도구 및 기존 저장된 삼각형은 유지한다.

## Implementation Notes
설계 좌표는 화면과 반대로 Y가 증가하므로 시작/끝 설계 Y를 기준으로 밑변과 꼭짓점을 정한다. 드래그 바운드를 채우는 이등변 삼각형의 명시적 세 꼭짓점을 미리보기와 생성 이벤트에 공통 전달하고 기존 UpdateTriangleVertices 경로로 저장한다. ADR 불필요.

## Acceptance Criteria
- 상하 드래그 및 좌우 반대 방향에서 요구한 방향의 삼각형이 생성된다.
- 미리보기와 생성된 세 LINE의 꼭짓점이 일치한다.
- 재료 경계 제한 및 단순 클릭/작은 드래그 거부가 유지된다.
- 방향은 이동·Undo/Redo·DXF 저장/재열기에서도 유지된다.
- Release 빌드 및 전체 자동 검증 통과.
