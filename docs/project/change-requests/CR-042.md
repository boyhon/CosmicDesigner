# CR-042 Outer Contour LINE 삭제 후 폐합 및 재료 영역 정합성

## Status
Implemented

## Request
2026-10-04 사용자 요청 및 첨부 codex-clipboard-06f82d38-d9fd-42cc-b749-e9bf17452719.png: 통합된 사각형의 한 변 삭제 후 흰색 영역은 변하지만 원래 LINE이 영역 변경을 따라가지 않는다. 외곽 바깥은 흰색, 안쪽은 회색을 유지하도록 개선한다.

## Background
CR-017의 연결 편집과 달리 LINE 삭제는 해당 엔티티만 제거하여 열린 Outer Contour를 만들었다.

## Current Behavior
재료 채움은 누락된 변의 틈을 암묵적으로 이어 채우지만 실제 LINE은 연결되지 않아 선과 재료 영역이 어긋난다.

## Required Behavior
- 선택 LINE 삭제 시 후속 LINE 시작점을 삭제 LINE 시작점으로 연결하여 폐합을 유지한다.
- 생성된 실제 경계와 회색 재료/흰색 외부 영역을 일치시킨다.
- Object Tree, Section, 3D, 저장 및 Undo/Redo가 같은 외곽을 사용한다.

## Scope
Outer Contour LINE 삭제. Cut 전체 삭제는 유지한다. 최소 삼각형 외곽, 퇴화/자기 교차를 만드는 삭제, 후속 ARC의 끝점 재구성이 필요한 삭제는 거부한다.

## Implementation Notes
삭제 변 A→B 뒤의 B→C를 A→C로 갱신하여 기존 채움 영역의 암묵적 연결을 실제 LINE에 반영한다. 첫/마지막 LINE 삭제도 순환 인덱스로 처리한다. 열린 외곽을 방지하므로 ARC 단독 삭제는 지원하지 않는다. 기존 렌더러 및 재계산을 재사용한다. ADR 불필요.

## Acceptance Criteria
- 경계 통합된 사각형 노치의 한 변 삭제 후 모든 인접 LINE 끝점이 연결된다.
- 새 경계 외부는 흰색이고 내부는 회색이며 실제 LINE과 채움 경계가 일치한다.
- 첫/마지막 LINE 삭제와 Undo/Redo 및 DXF 왕복이 통과한다.
- 최소 외곽 또는 무효 결과 삭제는 원본을 유지한다.
- 전체 자동 검증 및 Release 빌드 통과.
