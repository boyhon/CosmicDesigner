# CR-043 사선 Outer Contour의 사각형 통합 복구

## Status
Implemented

## Request
2026-10-04 사용자 요청: “왜 사각형이 갑자기 Outer Contour로 통합 기능이 사라졌나? 확인하고 기능을 다시 넣어라.”

## Background
CR-042 LINE 삭제 및 Triangle/Parallelogram 통합으로 사선 외곽이 생길 수 있으나 사각형 통합은 직교 외곽만 지원했다.

## Current Behavior
현재 외곽에 사선이 하나라도 있으면 사각형 병합 후보 판정이 실패하여 주황색 및 통합 메뉴가 나오지 않는다.

## Required Behavior
사선 LINE 기반 외곽에서도 안전하게 통합 가능한 사각형에 주황색 선택 및 우클릭 통합 명령을 제공한다. 기존 직교 외곽 통합 및 내부 Hole/복수 재료 조각 제외를 유지한다.

## Scope
사각형과 LINE 기반 Outer Contour의 차집합 통합. ARC 기반 외곽 지원은 변경하지 않는다.

## Implementation Notes
기존 직교 외곽 경로는 유지하고 비직교/삼각형 외곽에서는 TrySubtractPolygon으로 사각형 차집합을 계산한다. 기존 공통 UI 및 Undo 경로를 재사용한다. ADR 불필요.

## Acceptance Criteria
- LINE 삭제 후 사선 외곽에서 사각형 후보 및 통합이 동작한다.
- 삼각형·평행사변형 통합 후 사각형도 순차 통합된다.
- 내부 사각형과 재료 분리 사각형은 통합되지 않는다.
- 사선/폐합 유지, Undo/Redo, DXF 왕복 및 기존 사각형 통합 검증이 통과한다.
