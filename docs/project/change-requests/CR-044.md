# CR-044 3D Preview Fillet 곡선 표시

## Status
Implemented

## Request
2026-10-04 사용자 요청 및 첨부 codex-clipboard-2580a5fa-ecc7-4245-9ecd-82f62c52bccc.png, codex-clipboard-242852b6-1171-4f36-b6ce-5bd7475d3134.png: Fillet로 둥글게 마무리한 코너가 3D에서는 직선으로 잘려 보인다. 3D도 둥글게 보이도록 조정한다.

## Background
CR-033/CR-036은 3D ARC를 접점 사이 직선 chord로 표시했다.

## Current Behavior
둥근 코너의 면과 Edge가 하나의 사선으로 나타난다.

## Required Behavior
외곽 및 내부 Hole Fillet의 3D 면과 Edge를 동일한 곡선 근사로 둥글게 표시한다. 절곡 및 반지름 변경에도 적용하며 정확한 DXF ARC는 유지한다.

## Scope
3D ARC tessellation. Circle 기존 24각형, Flat 및 DXF ARC는 유지한다.

## Implementation Notes
각 ARC의 시작~끝 각도를 최대 5도 간격으로 샘플링한다. 면 분할 및 윤곽 Edge에 공통 샘플을 사용하고 기존 절곡 station 분할을 유지한다. 문서 단위와 무관하게 동일한 각도 품질을 유지한다. 현 미리보기 엔진의 국소 변경이므로 ADR 불필요.

## Acceptance Criteria
- 네 모서리 Fillet이 3D에서 단일 사선 대신 곡선에 가까운 여러 선분으로 보인다.
- 내부 Hole Fillet에도 동일한 샘플링을 사용한다.
- 면과 윤곽이 같은 곡선 근사 경계를 사용한다.
- 반지름 변경 및 절곡 후에도 곡선이 유지된다.
- Release 빌드 및 기존 검증/DXF ARC 왕복 통과.
