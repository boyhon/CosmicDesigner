## Background
CR-043은 사선 LINE만 지원했고 ARC가 포함되면 모든 통합 후보를 제외했다.

## Current Behavior
Fillet 적용 후 Rectangle/Triangle/Parallelogram 통합 명령이 사라진다.

## Required Behavior
- ARC 외곽에서도 세 도형의 안전한 경계 통합을 지원한다.
- 주황색 후보 선택 및 명시적 우클릭 통합을 유지한다.
- 기존 Fillet ARC는 정확하게 보존한다.
- ARC와 천공이 직접 교차하면 교점에서 ARC를 정확히 잘라 남은 곡선을 보존한다.
- 내부 Hole, 복수 재료 조각, 퇴화 결과는 통합하지 않는다.

## Scope
LINE/ARC 외곽과 LINE 다각형 Cut의 차집합. Circle 통합 지원은 추가하지 않는다.

## Implementation Notes
LINE–LINE 및 LINE–ARC 교점을 계산하고 원본 경계를 교점에서 분할한다. Cut 밖의 외곽 조각과 외곽 안의 역방향 Cut 조각을 연결하여 하나의 폐곡선인 경우만 승인한다. ARC를 선분으로 변환하지 않는다. 기존 LINE 전용 알고리즘 및 공통 UI/Undo 경로는 유지한다. 현 경계 엔진 확장이므로 ADR 불필요.

## Acceptance Criteria
- Fillet 네 코너 적용 후 세 도형을 순차 통합할 수 있다.
- 관련 없는 ARC 형상/반지름이 그대로 유지된다.
- ARC 직접 교차에서도 남은 ARC의 원/반지름과 정확한 교점이 유지된다.
- 내부/분리 Cut 거부, 폐합, Undo/Redo 및 DXF ARC 왕복 검증 통과.
- 전체 자동 검증 및 Release 빌드 통과.
