# CR-046 Outer Contour 편집 후 틈 자동 LINE 연결

## Status
Implemented

## Request
2026-10-05 사용자 요청: Outer contour의 object 이동/삭제 또는 한 점 이동 후 연결점이 사라진다. 빈자리를 새로운 선으로 연결하여 전체 외곽을 폐곡선으로 유지한다.
출처: 대화와 첨부 codex-clipboard-54e7d87c-8ab1-4915-b4e2-a2450a7eaf7d.png 및 codex-clipboard-5b98de5d-c7e7-4a91-9958-e57b95353ff3.png.

## Background
CR-017의 공유 끝점 갱신은 이웃 LINE만 변경한다. Fillet ARC 옆 LINE 이동은 ARC 끝점과 틈을 만든다. CR-042는 일부 삭제만 폐합한다.

## Current Behavior
Flat 채움과 3D는 열린 경계를 암묵적으로 닫지만 실제 LINE/ARC에는 연결이 없다.

## Required Behavior
- 순서대로 인접한 외곽 객체의 끝/시작 사이에 틈이 있으면 실제 LINE을 추가한다.
- 마지막/첫 객체 사이도 동일하게 연결한다.
- ARC는 기존 중심/반지름/각도를 유지한다.
- 이동, 끝점 편집, LINE/ARC 삭제 및 재계산 후 실제 외곽 폐합을 유지한다.
- Flat, Object Tree, Section, 3D와 저장/Undo가 같은 경계를 사용한다.

## Scope
기존 LINE/ARC Outer Contour의 연결 보완. 새로운 ARC 드래그 도구는 추가하지 않는다. 기존 LINE 이웃 편집/삭제 규칙은 유지한다.

## Implementation Notes
공통 CloseGaps에서 LINE/ARC의 정확한 시작/끝 좌표를 비교하고 틈에 연결 LINE을 삽입한다. 업데이트와 재계산 경로에 적용한다. 삭제한 ARC는 접점 사이 LINE으로 연결한다. 드래그 중 추가된 LINE으로 인덱스가 바뀔 수 있으므로 선택 ID를 최종 contour 인덱스에서 계산한다. ADR 불필요.

## Acceptance Criteria
- 양 끝이 Fillet ARC와 연결된 LINE 몸체 이동 시 두 틈에 LINE이 추가된다.
- 한 끝점 이동은 해당 틈만 연결하며 기존 ARC를 변경하지 않는다.
- ARC 삭제 및 첫/마지막 틈도 실제 LINE으로 폐합된다.
- 재계산과 반복 편집은 연결 LINE을 중복 생성하지 않는다.
- Undo/Redo, 저장/재열기 및 전체 자동 검증 통과.
