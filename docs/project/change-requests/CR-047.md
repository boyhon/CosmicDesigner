# CR-047 Triangle Cut 좌하단 위치 속성

## Status
Implemented

## Request
2026-10-05 사용자 요청과 첨부 Selected object 화면: 삼각형 Cut 전체 선택 시 Center X/Y 대신 가상 외접 사각형의 좌하 좌표를 직접 입력하여 위치를 변경하도록 수정.

## Background
중심은 사용자가 도면에서 정확히 판단하기 어렵다.

## Current Behavior
Center X/Y 입력은 UpdateCut을 호출하여 삼각형을 재생성한다.

## Required Behavior
Triangle 전체 선택의 위치는 Lower-left X/Y로 표시한다. 설계 좌표에서 X/Y 최솟값이며 현재 문서 단위를 사용한다. 입력은 기존 윤곽을 평행 이동하고 재료 경계에 제한한다. 다른 Cut 위치 속성은 유지한다.

## Scope
Triangle 위치 속성, 윤곽 이동, 회귀 검사. 파일 포맷은 유지한다.

## Implementation Notes
중심 기반 저장 모델을 유지하고 좌하 좌표를 파생한다. LINE/ARC를 함께 이동하여 임의 삼각형과 Fillet을 보존한다. 동일 Width/Height의 focus loss는 재생성하지 않는다. ADR 불필요.

## Impact Analysis
MainWindow 속성 UI와 Models 이동, Inner Contour 동기화 영향. 관련 CR-030/041 꼭짓점 및 방향, CR-023 단위, CR-005 Undo, CR-007 저장, CR-036 Fillet. 기존 기대값 변경 없음.

## Acceptance Criteria
- 전체 Triangle 선택에서 Center X/Y 대신 Lower-left X/Y를 표시한다.
- 각 좌표 입력은 다른 축과 모양/크기/방향을 유지하여 이동한다.
- 경계 제한, Undo/Redo, DXF 저장 재열기와 문서 단위가 일관된다.
- 신규/영향/전체 자동 검증 통과; 실제 UI는 사용자 판정 기록 후 완료한다.
