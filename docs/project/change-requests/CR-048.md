# CR-048 Circle 반지름 속성

## Status
Implemented

## Request
2026-10-05 사용자 요청과 첨부 Selected object 화면: 원의 Width/Height는 항상 함께 변경되므로 “원에서는 이 두개의 값을 하나로 합쳐서 반지름 속성을 표시하도록 하라.”

## Background
두 값이 동일한 지름을 중복 표현한다.

## Current Behavior
Circle 전체 선택에 Width/Height 두 입력을 표시한다.

## Required Behavior
Circle에는 현재 문서 단위의 Radius R 하나만 표시/편집한다. 반지름의 두 배를 Width/Height에 저장하고 중심을 유지한다. 최소 반지름 .05와 재료 경계를 만족하지 않는 값 및 비유한 값은 거부한다. 다른 도형의 Width/Height는 유지한다.

## Scope
Circle 속성 UI와 모델 반지름 편집. 저장 모델/DXF 포맷 유지.

## Implementation Notes
CanResizeCircleRadius/TryResizeCircleRadius 검증 후 UpdateCut으로 윤곽 동기화. 유효한 변경에만 Undo 기록. ADR 불필요.

## Impact Analysis
MainWindow 속성 UI, Models 크기/Inner Contour, Undo/Redo, DXF, 단위. CR-005/007/023/031/047 관련. 기존 TC 기대 유지.

## Acceptance Criteria
지름 47.18은 Radius R 23.59로 표시한다. 편집 시 중심 유지 및 동일 지름, 윤곽/Undo/Redo/DXF/단위 일치. 부적합 입력 원복. 다른 도형 크기 UI 유지.
