# CR-049 드래그 방향별 반원 천공

## Status
Implemented

## Request
2026-10-05 사용자 요청: 첨부 그림처럼 반원 윤곽 아이콘을 원 천공 다음에 추가하고, 첫 클릭 후 상/하/우/좌 드래그 방향으로 원호가 향하는 반원 천공을 생성한다. 출처: 대화 및 codex-clipboard-b102e2a8-3cb8-4bbb-bbe3-15acc95e92a4.png.

## Background
기존 도구에는 반원이 없다.

## Current Behavior
Circle 다음은 Triangle 버튼이다.

## Required Behavior
Circle 다음에 Semicircle 버튼을 배치한다. 네 방향 드래그는 해당 방향으로 볼록한 180도 ARC와 지름 LINE을 생성한다. 미리보기와 생성 결과는 같다.

## Scope
버튼, 드래그 계산, 정확한 반원 형상, 편집 및 기존 DXF/Undo 경로.

## Implementation Notes
첫 클릭은 지름 중심, 주축 드래그 길이는 반지름이다. 대각선은 절대 이동량이 큰 축(동률은 세로)을 선택한다. 반지름은 전체 반원이 재료 안에 있도록 제한한다. 방향은 기존 ARC 각도로 보존하여 메타데이터 형식을 변경하지 않는다.

## Acceptance Criteria
- Circle 바로 다음의 왼쪽 반원 아이콘, tooltip/accessibility 이름.
- 네 방향 및 축에 정확히 평행한 드래그가 해당 원호를 생성한다.
- 짧은 클릭 거부, 점선 미리보기, 한 개 생성 후 Select, Undo/Redo.
- 이동/크기 편집/DXF 재열기에서 방향 및 원형 유지.

## Impact Analysis
FlatViewport, HoleGeometryEngine, MainWindow toolbar/placement, UpdateCut 영향을 받는다. 기존 ARC/LINE 표현을 재사용하며 기존 형상 계산은 유지한다. 관련 CR: 005, 007, 023, 026, 027, 031, 038, 039, 041, 048. 새 ADR 불필요.
