# CR-050 반원 지름과 Outer Contour 통합
## Status
Implemented
## Request
2026-10-05 대화: “반원의 지금이 Outer Contour에 겹치면 통합할 수 있게 해 주세요.” 문맥상 지금은 지름으로 해석한다. CR-049 후속 요청.
## Background
반원 Cut은 ARC/LINE으로 생성되지만 통합 대상은 아니다.
## Current Behavior
반원 지름이 외곽 LINE과 겹쳐도 우클릭 통합이 없다.
## Required Behavior
지름이 외곽 LINE과 양의 길이로 겹치고 차집합이 하나의 폐합 재료 경계를 이루면 주황 후보 및 명시적 우클릭 통합을 제공한다. 지름 중복 부분을 제거하고 정확한 반원 ARC를 외곽 홈으로 유지하며 Cut/Inner Contour를 제거한다.
## Scope
반원 후보/통합, LINE/ARC 차집합, 방향 있는 ARC 렌더링 및 DXF 출력. 통합 원호와 사선 LINE의 정확한 단면 교점을 계산하여 홈 깊이를 단면에 반영한다.
## Implementation Notes
기존 공통 UI/Undo 경로 재사용. 원호를 직선으로 근사하지 않는다. 내부/점 접촉/재료 외부/복수 폐곡선/퇴화 결과는 거부. 새 ADR 불필요.
## Acceptance Criteria
네 외곽 방향, 부분/연속 LINE 겹침, Fillet 외곽에서도 정확한 후보/폐합/면 제거. Undo/Redo/DXF 및 기존 통합 회귀 유지.
