# CR-051 반원 실제 중심과 반지름 속성
## Status
Implemented
## Request
2026-10-05 사용자: 반원도 Width/Height 대신 반지름 속성을 사용하고 우측 외곽선에 접한 반원의 Center X가 300이 아닌 이유를 검토해 개선한다. 첨부 codex-clipboard-66a0eef0-1366-4335-8a4f-1d453c24d434.png: Center X=279.209, Width=41.582, Height=83.164.
## Background
현재 Center X/Y는 반원의 외접 사각형 중심이다. 왼쪽 반원에서 원호 중심 X는 279.209+41.582/2=300. 반원 중심으로 표시하는 것은 혼동을 유발한다.
## Current Behavior
반원은 외접 중심과 Width/Height 편집기를 제공한다.
## Required Behavior
반원 전체 선택은 현재 문서 단위의 원호 실제 Center X/Y와 Radius R만 제공한다. 반지름 변경은 원호 중심/방향과 지름 위치를 유지한다. 중심 편집은 반원을 평행 이동한다. 부적합/재료 범위 초과 값은 이동/축소 없이 거부한다.
## Scope
반원 Cut 속성 및 모델 편집 API. 기존 외접 중심의 저장/핸들/드래그 의미는 호환 유지한다.
## Implementation Notes
ARC 중심을 속성의 기준으로 사용하고 외접 중심은 내부 표현으로 유지한다. Radius minimum .1은 CR-049 반원 최소 크기와 일치한다. 기존 ARC/LINE, Inner Contour, Undo 및 DXF 경로 재사용. ADR 불필요.
## Acceptance Criteria
우측 접촉 반원 X=300; 네 방향에서 실제 원호 중심/반지름 표시. 크기 편집 중 지름 및 중심 유지, 범위 초과 거부, 방향/통합 후보/Undo/DXF/단위 보존.
