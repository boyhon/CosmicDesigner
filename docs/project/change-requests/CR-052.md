# CR-052 사분면 방향 4분원 천공
## Status
Implemented
## Request
2026-10-05 대화: 반원 다음에 첨부 그림 같은 4분원 아이콘을 배치하고 첫 클릭 후 1/2/3/4사분면 드래그로 해당 방향 원호를 생성한다. 두 반지름 중 하나라도 Outer Contour와 겹치면 통합 가능하게 하고 Width/Height 대신 반지름을 편집한다. 현재 대화에 첨부 이미지 데이터가 없어 기존 윤곽 스타일의 4분원 아이콘으로 구현한다.
## Background
반원 생성/통합/반지름 속성 경로를 4분원에 확장한다.
## Current Behavior
4분원 도구 없음.
## Required Behavior
반원 바로 다음 4분원 버튼. 첫 클릭=원호 중심, 설계 좌표 X/Y 부호로 사분면 선택. 정확한 90도 ARC+두 반지름 LINE. 어느 반지름이든 외곽 LINE과 양의 길이로 겹치고 단일 폐합 차집합이면 주황 후보/명시적 우클릭 통합. 현재 문서 단위의 Radius R 및 실제 Center X/Y 속성.
## Scope
툴바, 생성/미리보기, 모델 편집, 경계 통합, DXF/Undo/3D, 누적 회귀.
## Implementation Notes
반지름=min(abs(dx),abs(dy)); 재료로 드래그 좌표 제한. 축상/짧은 드래그는 거부. 각도 0/90/180/270에 90도 sweep. 기존 optional geometry 메타데이터 사용. 반지름 편집은 실제 중심/방향 보존, 비유한/.1 미만/재료 초과 입력 거부. MOVE/핸들 resize는 원형과 방향 보존. 신규 ADR 불필요.
