# CR-053 Section 구간 합계와 Flat W/H 계산 일치

## Status

Implemented

## Request

2026-10-05 사용자 요청: Material W/H 직접 편집 제안은 취소한다. H Section Designer non-Bent 구간을 `199 / 1998 / 199`로 변경했을 때 합계 `2396`이 아니라 Flat H `2394`가 되는 계산 결함을 검토하고 개선한다.

## Background

Section Designer의 non-Bent 길이는 이미 전개된 재료의 각 구간 길이이다. 기존 총 길이 계산은 이 합계에서 절곡 수마다 재료 두께의 절반을 추가 차감하여 두께 보정을 두 번 적용했다.

## Current Behavior

두께 `2`, H 절곡 두 개, non-Bent 구간 `199 / 1998 / 199`에서 합계 `2396`에 절곡 보정 `2 × 2 / 2 = 2`를 다시 빼 Flat H가 `2394`가 된다.

## Required Behavior

- Flat W/H는 해당 축의 non-Bent SectionSegment 길이 합계와 정확히 같아야 한다.
- 절곡 개수 또는 재료 두께 변경이 동일한 non-Bent 구간 합계에서 Flat W/H를 다시 감소시키지 않아야 한다.
- 재료 두께 보정은 Bent 외곽 측정 치수 변환에만 유지한다.
- Material W/H 직접 편집 기능은 추가하지 않는다.

## Scope

- W/H 총 전개 길이 계산
- Section 길이 편집 후 Material W/H 및 기본 Outer Contour 재계산
- Bent 외곽 치수 보정 회귀

## Implementation Notes

`BendCalculationEngine.FlatLength`는 `SectionSegment.Length`의 합만 반환한다. `ExteriorSegmentLength`와 `CenterSegmentLengthFromExterior`의 두께 기반 외곽 치수 변환은 변경하지 않는다.

## Impact Analysis

- 직접 변경: `BendCalculationEngine`, Material W/H, 기본 사각 Outer Contour 크기, Flat/Section/3D viewport 범위.
- 관련 CR: CR-006, CR-011, CR-012, CR-013, CR-016, CR-018, CR-019, CR-023.
- 영향 회귀: TC-006-001, TC-011-001, TC-012-001, TC-016-001, TC-018-001, TC-019-001, TC-023-001, BASE-Bends, BASE-SegmentsAndBentGeometry, BASE-EditableAxisDistances, BASE-GeneralDxfImport.
- 저장된 사용자 편집 Outer Contour는 기존 보존 정책을 유지하며 임의 비례 변형하지 않는다.

## Acceptance Criteria

1. 두께 `2`, H non-Bent 구간 `199 / 1998 / 199`의 Flat H가 `2396`이다.
2. 같은 W 구간의 Flat W도 `2396`이다.
3. 절곡이 존재해도 Flat W/H는 non-Bent 구간 합계와 같다.
4. 두께 변경만으로 Flat W/H가 바뀌지 않는다.
5. Bent 외곽 구간 치수에는 기존 두께 보정이 계속 적용된다.
6. 관련 자동 회귀와 전체 자동 회귀가 통과한다.
