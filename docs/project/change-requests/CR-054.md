# CR-054 직선·원호·연결선 절개 도구
## Status
Implemented
## Request
2026-10-05 사용자 대화: “천공 기능 외에 선으로 절개할 경우가 필요하다. 첨부한 그림을 아이콘으로 사용해서 … 직선, 원호, 연결선 세가지를 그릴 수 있는 버튼을 만드시오.” 첨부한 세 PNG를 Resources/slit-line.png, slit-arc.png, slit-polyline.png로 보존하여 그대로 사용한다.
## Background
열린 절개 경로를 천공 도구와 구별하여 작성해야 한다.
## Current Behavior
폐합된 천공과 외곽 편집만 제공하며 열린 절개 작성 버튼이 없다.
## Required Behavior
첨부 이미지의 직선·원호·연결선 버튼, 도구 이름 tooltip/accessibility, 열린 L 절개 경로 작성 및 미리보기. 면적 제거나 암묵적 폐합 없이 저장한다.
## Scope
Flat UI/모델/선택/삭제/Undo/Redo/단위/DXF 및 3D 절개선 표시, 누적 회귀.
## Implementation Notes
직선 두 점 클릭; 원호 시작점/통과점/끝점 세 점 클릭; 연결선 연속 클릭 후 Enter 완료. Esc는 전체 미완성 경로 취소. 완료 후 Select. 겹친 점/일직선 원호/재료 사각 범위 초과 거부. 개별 SlitOperation 컬렉션과 optional DXF JSON Slits 필드, 정확한 LINE/ARC L 엔티티를 사용한다. 기존 DXF는 Slits 누락 시 빈 컬렉션. 신규 포맷 불필요. 3D 곡선은 5도 간격 샘플 및 절곡 위치 분할. 폭 0의 절개는 면적을 제거하지 않는다.
## Acceptance Criteria
- 제공한 세 PNG가 버튼에 표시되고 도구 이름을 확인할 수 있다.
- 세 경로의 미리보기/완료/Esc/Select 전환이 정확하다.
- 열린 경로는 면적과 외곽/천공을 변경하지 않고 선택/삭제할 수 있다.
- DXF LINE/ARC와 메타데이터, 단위 변환 및 Undo/Redo에서 보존한다.
