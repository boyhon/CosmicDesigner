# CR-055 객체 속성 영역의 OBJECTS / PROPERTIES 순서
## Status
Implemented
## Request
2026-10-05 사용자 대화: 좌측 영역을 “객체 속성 영역”이라 부르며 “PROPERTIES 와 OBJECTS 의 순서를 바꿔서 OBJECTS / PROPERTIES 영역으로 개선하세요.”
## Background
객체를 먼저 선택하고 아래에서 속성을 확인하도록 배치한다.
## Current Behavior
PROPERTIES(Material 및 Selected object) 아래에 OBJECTS 트리가 있다.
## Required Behavior
OBJECTS 제목과 트리가 상단, PROPERTIES 제목과 Material 및 Selected object가 하단에 있다.
## Scope
좌측 XAML 자식 순서와 그룹 간격, 버전/관리 기록.
## Implementation Notes
기존 트리 높이/속성 컨트롤/이벤트/ScrollViewer를 유지하며 OBJECTS 블록을 이동한다. 두 그룹 사이 10px 간격. 단순 배치 변경으로 별도 ADR/구현을 반복하는 자동 테스트 불필요; 실제 시각 수용은 MANUAL로 등록한다.
## Acceptance Criteria
- 좌측 OBJECTS가 PROPERTIES보다 위에 있다.
- 객체 선택 시 하단 Selected object가 갱신되고 기존 편집/스크롤이 동작한다.
