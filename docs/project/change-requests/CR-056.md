# CR-056 Section 치수 변경 시 기본 사각 외곽 갱신

## Status
Implemented

## Request
2026-10-05 사용자 요청 및 첨부 화면 두 장: H Section 높이를 300에서 100으로 변경하면 Flat Designer 그림은 그대로이고 H 표시만 줄어드는 문제를 개선한다. 3D에서는 재료가 줄어든다.

## Background
DXF load와 Undo/Redo는 모든 외곽을 보존 대상으로 복구한다.

## Current Behavior
기본 사각형까지 보존되어 Material W/H와 Outer Contour가 달라질 수 있다.

## Required Behavior
현재 Material 범위와 일치하는 기본 사각형은 H/W Section 길이 편집 시 새 W/H로 재생성한다. 사용자 편집 외곽은 기존 보존 정책을 유지한다.

## Scope
Section 길이 편집, 기본 사각 외곽, Flat 마스크, 저장 및 Undo/Redo.

## Implementation Notes
변경 전 재료 크기와 네 사각 LINE을 방향/순서 독립적으로 대조한다. 기본 사각형이면 보존 플래그를 해제한 뒤 기존 재계산을 수행한다.

## Impact Analysis
Models.UpdateSegment, Material W/H, Flat/Section/3D, DXF와 Undo/Redo. CR-007/012/018/023/026/053 영향. 사용자 외곽을 비례 변형하지 않는다.

## Acceptance Criteria
1. 불러온 기본 300×300에서 H=100이면 Flat 외곽도 300×100이다.
2. W 편집과 반복 저장/불러오기에서도 일치한다.
3. Undo/Redo는 치수와 외곽을 함께 복구한다.
4. 편집한 외곽은 보존한다.
5. 전체 자동 회귀를 통과한다.
