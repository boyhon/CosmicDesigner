# CR-057 Hole/Slit 아이콘 굵기와 표시 크기 통일
## Status
Implemented
## Request
2026-10-05 사용자 대화와 첨부 화면: Slit 선을 Hole과 같은 굵기로 통일하고, 아래가 잘리는 Hole 아이콘을 조금 줄여 전체가 보이게 한다.
## Background
Slit PNG의 가는 선과 Hole 1.8 DIP 벡터 선이 다르다. 버튼 높이 30, padding 4에서 22px 이상 콘텐츠는 테마 내부 공간을 초과한다.
## Current Behavior
Slit은 가늘고 Hole 하단이 잘린다.
## Required Behavior
모든 아이콘에 동일한 1.8 DIP 선과 색을 적용하며 Hole 높이를 최대 18 DIP로 줄여 전체 표시한다.
## Scope
MainWindow toolbar XAML; tool 동작은 유지.
## Implementation Notes
Slit의 직선/원호/연결선 도안을 같은 형태의 XAML Path로 표현한다. 기존 PNG 자산은 보존한다. Hole 높이 18 이하, 가로 비율 조정. 버튼 36×30 유지.
## Impact Analysis
MainWindow.xaml 표시만 변경. CR-037/049/052/054 관련; 도구 선택과 클릭 handler 유지. 계산/저장 변화 없음.
## Acceptance Criteria
- Slit 3개와 Hole 7개 선 굵기가 같다.
- Hole 전체 윤곽이 잘리지 않고 보인다.
- 모든 도구 선택 및 생성이 유지된다.
