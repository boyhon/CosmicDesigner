# CR-058 Bent Section 실제 두께 축척 정합성
## Status
Implemented
## Request
2026-10-05 사용자 요청 및 첨부 H Section/3D 화면: Section이 실제 도면과 다르게 보이며 재료 두께 관계의 혼선을 재검토하고 개선한다.
## Background
CR-011은 얇은 재료를 위해 최소 화면 두께를 허용했다. 좁은 개구부에서는 최소 10px 두께가 실제 틈과 외곽을 왜곡한다.
## Current Behavior
Bent 윤곽과 치수 기준점에 Math.Max(5, thickness*scale/2)를 적용한다. 3D는 같은 중심 경로를 사용하지만 이 화면 두께 과장이 없다.
## Required Behavior
H/W Bent 윤곽과 치수 배치는 실제 thickness*scale을 사용한다. 회전/Zoom에서도 같은 축척을 적용한다. 실제 데이터와 Bent 외곽 길이 계산 정책은 유지한다.
## Scope
Bent H/W 화면 두께, 윤곽, 치수 editor/measurement 공통 기준.
## Implementation Notes
SectionProfileEngine으로 실제 화면 반두께와 공통 miter offset 계산을 추출한다. 기존 최소 화면 두께 정책을 이 CR로 대체한다. Flat non-Bent의 schematic strip은 기존 표시를 유지한다.
## Impact Analysis
DesignViews/FlatViewport. CR-006/011/013/014/018 관련. DXF 데이터/3D 및 전개 길이는 변경하지 않는다.
## Acceptance Criteria
1. Bent 표시 두께는 실제 두께와 동일한 scale을 사용한다.
2. 좁은 개구부는 최소 10px 두께로 과장되지 않는다.
3. 윤곽/치수/editor가 같은 두께 기준을 사용한다.
4. H/W 대칭, 회전, Zoom, 기존 외곽 치수 정책 유지.
5. 자동 회귀 통과.
