## Background
Bent labels always shift up 25px; all same-side dimensions share one baseline.
## Current Behavior
Vertical labels are off-center and nested 10/20 labels overlap.
## Required Behavior
Bent H/W labels are centered along their line. Overlapping parallel dimensions on the same side place larger dimensions farther outside. Editors and drawn lines use the same layout.
## Scope
Bent dimension layout and editor positioning, preserving length calculation and edit handlers.
## Implementation Notes
Shared SectionDimensionEngine sorts measurable spans ascending; same-side overlapping projected spans occupy outward lanes 30 DIP apart. Non-overlapping spans share a lane. Label centers transform before fixed editor half-size offsets so Zoom remains centered.
## Impact Analysis
DesignViews/FlatViewport; CR-006/011/013/014/018/058. No document/storage changes.
## Acceptance Criteria
1. Every value is centered along the dimension line.
2. Nested 10/20 lines use separate lanes, larger farther out.
3. Non-overlapping dimensions share baseline.
4. H/W, rotation, Zoom and editing retained.
