# CR-060 Flat V/V1 절곡선 생성과 평행 이동
## Status
Implemented
## Request
2026-10-05 사용자 대화: Slit 다음 V/V1 버튼. 오른쪽 드래그 수평: H 왼쪽(V)/오른쪽(V1) 쐐기. 아래쪽 드래그 수직: W 위쪽(V)/아래쪽(V1) 쐐기. Flat 클릭 선택과 재료 외관 사각 범위의 평행 이동, Y/X Position 갱신.
## Background
Flat 절곡선은 표시/트리 선택만 가능하고 직접 생성/이동 경로가 없다.
## Current Behavior
Section 클릭으로만 쐐기를 만든다.
## Required Behavior
두 새 버튼과 네 방향/레이어 조합, 점선 미리보기, 클릭 선택 및 수직방향 위치 이동. Section/3D/속성/DXF/Undo 연동.
## Scope
Flat 입력/toolbar 및 기존 BendObject 사용.
## Implementation Notes
드래그 주축으로 H 수평/W 수직 결정; 오른쪽/아래쪽만 생성. 시작 Y/X를 위치로 사용하고 기존 재료 전체 폭/높이를 가로지르는 절곡 객체 생성. 경계/무효/짧은 드래그 거부. 이동은 해당 위치축만 갱신하며 재료 범위 안쪽 .01의 최소 구간 길이를 유지하는 clamp (끝에 정확히 겹치는 zero-length 절곡 방지). Esc 취소와 다른 도구 전환, capture cleanup. 생성/이동은 기존 Undo 기록. 별도 선 객체/파일 포맷 없음.
## Impact Analysis
FlatDesignerView/MainWindow 및 새 FlatBendDrawing. CR-005/009/012/023/029/054 관련. 기존 slit/hole/section selectors/3D와 모드 충돌 회귀 확인.

4. 수평은 Y만, 수직은 X만 이동; 사각 범위 제한.
