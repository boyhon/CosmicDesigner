# CR-061 홈 사이 절곡축을 기준으로 날개 3D 회전
## Status
Implemented
## Request
2026-10-05 사용자 요청 및 첨부 screenshot: 홈 사이 빨간 절곡선을 따라 앞으로, 파란 절곡선을 따라 뒤로 꺾일 때 나비 날개가 뒤로 접힌 실제 재료 형상을 3D Preview에 표시한다.
## Background
기존 W/H 단면 좌표의 Z 합산은 복합 절곡의 회전과 재료 길이를 보존하지 못한다. 중앙 단면의 잘린 구간을 전체 3D 좌표에 적용하는 문제도 있다.
## Current Behavior
직교 단면의 높이를 더하여 날개의 방향을 잘못 계산한다.
## Required Behavior
현재 외곽/천공 안에 남은 절곡축을 사용하여 이미 접힌 면을 포함한 재료를 회전한다. 홈과 구멍, 외곽과 V/V1 색, 카메라 동작을 유지한다.
## Scope
BentSurfaceEngine 좌표 변환, 자동 검증, 회귀 기록. 파일 포맷 변경 없음.
## Implementation Notes
재료를 가로지르는 힌지의 비율이 큰 축부터, 같은 축 안에서는 station 순서로 적용한다. 원래 Flat 좌표로 이동측을 판정하고 실제 남은 재료에서 선택한 힌지의 현재 3D 축에 Rodrigues 회전을 적용한다. 도면의 두 측면 홈은 중앙 연결부만 H 힌지로 남긴다.
## Impact Analysis
3D face/outline/slit/bend 좌표 공유. CR-010/019/027/028/029/039/044/054/060 관련. Section 치수 계산은 변경하지 않는다.
## Acceptance Criteria
1. 첨부 형상과 같은 중앙 연결부+양쪽 홈+V/V1 절곡에서 날개가 함께 회전한다.
2. 해당 형상의 모든 삼각형 변 길이를 보존한다.
3. 단일 W/H의 V/V1 방향, 홈 제거, 절곡 색을 보존한다.
4. 신규/영향/전체 자동 회귀 통과.
