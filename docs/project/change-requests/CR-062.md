# CR-062 Section의 모든 재료 구간과 빈 공간 표시
## Status
Implemented
## Request
2026-10-05 사용자 요청 및 첨부 화면: H Section 선택선이 Outer Contour에 통합된 홈을 가로지를 때 H Section Designer에도 빈 공간을 반영한다. 단면의 개념에 맞게 검토·개선한다.
## Background
연결된 한 장의 재료라도 선택 단면은 여러 떨어진 구간일 수 있다.
## Current Behavior
스캔 교점 중 가장 긴 재료 구간 하나만 선택하여 다른 구간과 홈을 누락한다.
## Required Behavior
H/W 선택선의 모든 Outer Contour 내부 구간을 공통 좌표·축척으로 표시한다. Flat/Bent에서 빈 공간을 연결하지 않고 구간별 치수와 해당 구간 안의 절곡만 표시한다. 빈 공간 클릭으로 절곡을 생성하지 않는다.
## Scope
Outer Contour LINE/ARC 교점, SectionGeometryEngine, SectionDesignerView. 기존 단일 구간 편집/3D/DXF 호환 유지.
## Implementation Notes
다중 구간 조회 API 추가. 기존 단일 구간 API는 3D fallback 호환용으로 유지. 다중 단면은 구간별 독립 경로로 렌더링한다. Bent는 분리 구간을 로컬 단면 기준으로 표시하며 빈 공간을 절곡 연결부로 해석하지 않는다.
## Impact Analysis
CR-006/008/009/012/016/018/050/058/059/061. 단면 선택, 치수 편집, 절곡 hit testing, 빈 교점, ARC, 3D 기존 호출 영향. 파일 포맷 변경 없음.
## Acceptance Criteria
1. 첨부와 같은 H 단면은 아래/위 두 재료 구간과 실제 홈 간격을 표시한다.
2. W도 같은 정책, 여러 홈과 빈 단면 처리.
3. Flat/Bent 구간별 치수와 절곡 표시; 홈에 절곡 생성 금지.
4. 기존 단일 구간 편집과 전체 회귀 통과.
