# CR-063 Cut 이동 중 인접 선 사이 중앙 정렬 안내
## Status
Implemented
## Request
2026-10-06 사용자 요청 및 첨부 PowerPoint 화면: Cut object를 마우스로 이동할 때 중심이 가까운 선과 선 사이 중앙에 있음을 점선으로 알려준다.
## Background
선택 핸들만으로 Cut 중심과 주변 선 사이 중앙 위치를 판단하기 어렵다.
## Current Behavior
Cut 이동 시 중앙 위치 안내가 없다.
## Required Behavior
Cut 몸체를 이동하는 동안 인접한 평행 외곽 LINE/절곡선 사이 중앙에 가까워지면 가로/세로 빨간 점선을 표시한다. 두 축이 맞으면 십자 안내를 표시한다. Mouse Up/취소/선택 변경 시 안내 제거.
## Scope
Flat Cut 이동 시 시각 안내. 위치 자동 흡착은 추가하지 않고 기존 이동/resize/Undo/DXF 정책 유지.
## Implementation Notes
Cut 중심을 가로지르는 외곽 수직/수평 LINE 및 V/V1 station 중 중심 양쪽의 가장 가까운 선을 선택. 중앙과의 거리 1.5 DIP 이내에서 표시. 확대/Pan을 적용한 화면 거리 사용. 곡선/사선은 평행 중앙 후보에서 제외. Semicircle/QuarterCircle은 속성에서 사용하는 실제 ARC 중심, 다른 Cut은 기존 외접 중심 사용.
## Impact Analysis
FlatDesignerView render/EndDrag, 새 순수 alignment engine. CR-005/030/031/047/048/051/052/060. 데이터/3D/파일 포맷 변경 없음.
## Acceptance Criteria
1. 외곽-외곽, 외곽-절곡, 절곡-절곡 중앙 안내.
2. 가장 가까운 양쪽 선만 사용하며 두 축 독립, 배율과 무관한 감지 거리.
3. 이동 중에만 표시; resize/Mouse Up/취소 뒤 제거.
4. 실제 Cut 좌표/형상을 안내 때문에 변경하지 않는다.
