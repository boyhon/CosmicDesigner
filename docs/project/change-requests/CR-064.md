## Background
CosmicDesigner_help.html은 placeholder다. 다른 DXF 앱의 기존 HTML과 공통 배포 경로가 있으므로 이를 재사용한다.

## Current Behavior
Help 메뉴는 대표 placeholder 파일만 열며 CosmicDesigner용 사용자 절차와 문서 영향 추적이 없다. Installer는 CosmicDesigner 실행 파일을 게시하지 않는다.

## Required Behavior
현재 소스를 기준으로 한국어 사용자 HTML, 기능·업무·오류·용어·단축키를 작성한다. 모든 페이지는 로컬 상대 링크/공통 CSS/이전·다음·관련 페이지를 제공한다. 기존 대표 파일은 새 help/index.html로 연결한다. 메뉴에 User Manual, Getting Started, Keyboard Shortcuts, Troubleshooting, 기존 About을 제공한다. 게시 및 설치에 도움말과 CosmicDesigner를 포함한다. 내부 추적과 Gap은 사용자 탐색에서 분리한다. 매 CR의 문서 영향 평가와 문서 갱신을 완료 기준으로 관리한다.

## Scope
도움말, 해당 메뉴/배포 및 관리 정책. 도형·계산·파일 형식 동작 변경 없음. 기존 미커밋 변경 보존. 확인되지 않은 기능/이미지/설치 결과는 주장하지 않는다.

## Implementation Notes
공식 원본 위치 help-content/help. Directory.Build.props의 기존 실행파일 옆 help 복사 규칙 재사용. 내부 Markdown은 배포에서 제외. 현재 소스가 과거 CR보다 우선한다. 이미지 확보 여부와 UI/실설치 검증은 별도 기록한다.

## Impact Analysis
MainWindow Help 메뉴와 launcher, HTML, Directory.Build.props, installer 게시 목록/검증/바로가기. 관련 CR-020/021/022/023/024/055 및 기존 Help. 모델/계산/직렬화는 변경하지 않는다.

2. 링크/앵커/이미지/배포 원본 동일성 자동 검사, 외부 서버 불필요.
