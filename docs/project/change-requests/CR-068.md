# CR-068 다음 설치 빌드의 기본 디렉토리 VCutting

## Status
Implemented — CR-069 candidate

Verification Status: WAITING FOR USER VERIFICATION

## Request
2026-10-06 사용자: “다음에 설치 파일을 다시 만들 때에는 기본 디렉토리를 "C:\Program Files\VCutting"으로 바꿔 주세요. 기억해 주세요.”
사용자는 기존 프로그램을 uninstall 후 다시 설치하는 방법에 동의했다. 지금 재빌드 요청은 아니다.

## Background
기존 설치 경로는 DXFExplorer였고 CR-066 소스의 새 기본값은 CosmicDesigner이다. 사용자가 다음 빌드의 기본 경로를 VCutting으로 지정했다.

## Current Behavior
installer/DXFExplorer.iss: DefaultDirName={autopf}\CosmicDesigner. 기존 설치 업데이트는 UsePreviousAppDir=yes로 기존 경로 사용.

## Required Behavior
다음 설치 파일을 만들기 전에 DefaultDirName={autopf}\VCutting 적용. x64 새 설치 또는 기존 제거 후 재설치 기본 경로 C:\Program Files\VCutting. 제품명 CosmicDesigner, 출력 CosmicDesignerSetup.exe 및 다른 식별자는 유지한다. 업데이트의 이전 경로 재사용은 유지한다.

## Scope
다음 설치 빌드의 새 기본 폴더만 변경. 지금 설치 파일 재빌드 또는 기존 설치 이동/제거 없음.

## Implementation Notes
다음 빌드에서 CR-066 테스트의 기본 폴더 기대값을 이 승인된 요구 변경으로 갱신하고 변경 근거를 기록한다. 기존 TC ID/목적 및 다른 기대값은 보존한다. installer README/getting-started.html/요구사항도 함께 갱신. ADR 불필요.

## Impact Analysis
Installer default folder, TC-066-001 및 설치 도움말. 모델/계산/앱 이름 영향 없음.

## Acceptance Criteria
다음 빌드의 새 설치 기본 폴더 C:\Program Files\VCutting; 제거 후 재설치도 해당 기본값; 업데이트 기존 경로 유지; 제품/파일명 유지.

## Documentation Impact
