## Request

## Background
CosmicDesigner 주 편집기와 DXFExplorer 공통 Viewer, DXFFileExplorer 탐색기, DXFSimulater 및 DXFDrawer 보조 앱이 공존한다. CR-068은 다음 설치 기본 폴더만 승인했으며 이번 구현에 함께 적용한다.

## Current Behavior
DXFViewer.sln 및 5개 앱/3개 검증 프로젝트에 과거 이름이 혼재한다.

## Required Behavior
주 편집기 VCutting, 보조 앱 VCutting.Viewer/Explorer/Simulator/Drawer, 검증 프로젝트에 같은 접두어를 적용한다. 공식 관리 이름은 VCutting 개발. 설치 출력 VCuttingSetup.exe. 기존 설정 저장 경로, COSMIC_DESIGNER_JSON 표식, 설치 AppId 및 업그레이드 경로 재사용은 보존한다.

## Scope
소스/프로젝트/솔루션/참조/활성 빌드 스크립트/사용자 HTML/현행 문서. 기존 릴리스 Freeze 산출물과 과거 CR/기록/원본 요구서 및 파생 PDF/Word는 역사 자료로 보존한다.

## Implementation Notes
DXFExplorer 프로젝트는 실제로 DXFViewer.exe를 출력하므로 VCutting.Viewer로 변경하고 DXFFileExplorer는 VCutting.Explorer로 변경한다. 기존 metadata 및 사용자 경로를 이름 변경 대상으로 취급하지 않는다. 기존 테스트의 브랜딩 기대값은 CR-069 승인, 기본 폴더 기대값은 CR-068 승인에 따라 갱신하며 TC ID/목적/다른 기대값은 보존한다. 신규 Freeze를 주장하지 않고 독립 검증 패키지를 만든다. ADR 불필요: 새 데이터 정책 도입 없이 기존 호환 계약 유지.
