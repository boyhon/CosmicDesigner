## Background / Current Behavior
CR-037에서 개별 요청 전까지 Ellipse 버튼을 제외했다. 기존 Ellipse 데이터와 48 LINE 윤곽은 지원하지만 방향 드래그 생성은 없다.

## Required Behavior / Scope
원 바로 다음 Ellipse 버튼. 시작/끝점은 장축 양 끝, 최초 장축:단축 2:1. 수평/수직/모든 사선 방향을 반영한다. 경계 가까이는 중심/방향/비율을 보존하여 축소한다. 점선 미리보기와 생성 일치, 단순 클릭/퇴화 거부, Mouse Up 단일 생성 및 Select 복귀. 이동/크기 편집/DXF/단위/Undo/3D는 형상을 유지한다. 다른 도구/명칭/버전 정책은 유지한다.

## Implementation Notes
기존 48 LINE 및 Geometry 저장 구조를 재사용하여 새 파일 필드 없이 호환한다. 외접 bounds 기반 크기 편집은 기존 타원 윤곽을 affine 변환한다. 첨부 윤곽은 기존 버튼과 같은 WPF vector ellipse로 구현한다. 장기 아키텍처 변경 없음; ADR 불필요.
