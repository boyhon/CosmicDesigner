## Request
2026-10-07 사용자: “그렇다면 타원 object의 속성에서 추가적인 속성들이 더해져야 한다. 타원의 속성 처리 방식을 개선하라.” 직전 DXF ELLIPSE 설명과 CR-074의 LINE 자식 표시 문제에 대한 후속 요청.
## Background
CR-074 방향 타원은 48 LINE 표시/저장과 외접 Width/Height 속성만 제공한다.
## Current Behavior
장축/단축/회전각을 직접 편집할 수 없으며 트리가 수많은 LINE 자식으로 나타난다.
## Required Behavior
타원 전체 선택은 중심 X/Y, 장축 전체 길이, 단축 전체 길이, 회전각(도)을 제공한다. 회전각은 설계 +X축 기준 반시계, 0~180 미만으로 정규화한다. 장축 >= 단축 > 최소 .1, 유한 값 및 정확한 타원 외접 범위로 재료 포함 여부를 확인한다. 크기/회전 편집은 중심과 미편집 축/각을 유지한다. invalid 입력은 문서/Undo 변경 없이 거부한다. 정상 타원은 트리 한 객체로 다루며 생성/이동/resize/history/units/DXF 호환을 유지한다.
## Scope
타원 고유 속성/기하 조회·편집 및 객체 트리. 기존 LINE 저장을 유지하고 native DXF ELLIPSE 쓰기/공유 파서 확장은 별도 미구현 후속 항목으로 기록한다. 기능을 저장 형식 변경까지 확대하지 않는다. 잘못된/변형 legacy 타원은 안전하게 기존 일반 편집을 유지하며 임의로 새 타원으로 복원하지 않는다.
## Implementation Notes
48 equally-spaced points covariance eigenvalues/eigenvectors로 실제 affine 타원의 주축을 복원하고 모든 점과 폐합을 검증한다. 표시 샘플은 기존 LINE 캐시/저장으로 유지한다. 원에 가까운 축 동률은 첫 점 방향으로 정한다. 동일 값 입력은 no-op. 기존 저장 필드 변경 없음, ADR 불필요.
