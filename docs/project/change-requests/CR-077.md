# CR-077 내부 Cut 객체 합집합 통합
## Status
Implemented / WAITING FOR USER VERIFICATION
## Request
2026-10-07 사용자: 내부 Cut object끼리 겹치면 선택 표시를 주황색으로 바꾸고 겹친 모든 object를 하나의 복잡한 Inner Contour처럼 Merge한다. 기존 Outer Contour 후보/명시적 Merge 흐름과 동일하다. 첨부: assets/cr077-overlapping-cuts.png.
## Background / Current Behavior
Outer 경계와 일부 Cut의 통합만 제공한다. 내부 겹침은 별개 객체와 중복 윤곽으로 남고 Flat EvenOdd mask는 겹친 부분을 잘못 재료로 표시할 수 있다.
## Required Behavior
내부에서 면적이 겹치거나 양의 길이로 변이 공유되는 Cut의 연결 그룹을 찾아 주황색 후보 표시/우클릭 내부 통합 명령을 제공한다. 한 점 접촉/분리/재료 외부/비폐합은 통합하지 않는다. 연쇄 연결과 포함/동일 객체 중복도 합집합 처리한다. 중복 내부 경계를 제거하고 한 Cut/Inner Contour로 관리한다. 실제 LINE/ARC를 유지하고 합집합 안에 남는 재료 섬도 유지한다. 자동 통합 없음. Outer 통합은 유지한다. Delete/이동/resize/Undo/Redo/DXF/단위/Flat/3D 일관성.
## Scope
내부 통합 및 직접 관련 표시/복합 도형 편집과 회귀. VCutting 프로젝트/CosmicDesigner.exe/기존 설정/AppId/버전 유지. Native ELLIPSE 저장 후속 항목과 외부 포맷 확장은 별개.
## Implementation Notes
교점을 기준으로 analytic segments 분할, 합집합 양쪽 내부 판정으로 외부 경계만 유지, 중복 제거/폐합 루프 정렬. Circle을 정확한 두 180도 ARC로 정규화한다. Compound shape 및 기존 Geometry 배열 안의 폐합 루프 순서 재사용, 새 JSON 필드 불필요. 다중 루프는 even-odd로 재료 섬을 보존한다. 원호가 있는 Compound는 uniform resize, LINE만 있으면 축별 resize. 선택 객체의 ID/sequence 유지, 합친 다른 객체 삭제, 새 Hole ID 충돌 방지. 장기 결정 ADR-003.
