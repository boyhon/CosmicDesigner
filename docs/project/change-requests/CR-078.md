## Background / Current Behavior
Legacy Polygon/Pentagon/Hexagon sampled LINE geometry exists; their toolbar buttons removed under CR-037. No logical regular polygon radius/rotation tool. Current cuts use layer L, closed inner contours, derived Geometry and JSON in DXF. Current plain DXF parser lacks LWPOLYLINE. CR-078 explicitly supersedes only regular polygon exclusion in CR-037, legacy Polygon remains unchanged.
## Required Behavior
RegularPolygon Cut entity with center, sides (integer 3..512, default6), positive finite radius and normalized first-vertex angle0..360 CCW from+X; read-only L layer and Closed=true. Parameter source authoritative, LINE geometry only derived cache inside same logical object. Center then first vertex click; preview/mouse/sides share vertex calculator; invalid input rejected before mutation/history. Radius/center/sides/angle property edit regenerates all vertices. Select any edge/body as whole, no child LINE selection or vertex deformation. Body move keeps radius/sides/angle; radius property controls size. Whole delete, one edit Undo/Redo. DXF closed LWPOLYLINE with exactly N vertices and L layer; optional additive metadata parameters restore logical entity. Generic imported straight LWPOLYLINE stays generic contour, no inferred regular entity. Existing contour union/boundary algorithms consume derived geometry. Regular polygon fillet transitions to Compound so edited shape is no longer falsely regular. Existing numeric culture/units/identity/settings/Freeze policy maintained.
## Scope
New tool/model/preview/property/history/DXF and straight LWPOLYLINE parser support required to reopen exported geometry without metadata. No arbitrary layer UI or bend-layer semantics changes: existing Hole objects always L. No conversion of legacy Polygon/Ellipse or generic polylines.
## Implementation Notes
Sides max512 bounds quadratic contour/mesh work without a small fixed-shape limit. Invalid/outside-material creation/property values rejected, no silent first-vertex clamp. ESC/right-click cancels; toolbar sides can update live preview without mouse-leave cancellation. Geometry cache retained for existing Contour algorithms. Optional Radius/Rotation metadata and snapshots only for RegularPolygon. ADR-004 records durable parameter/cache/DXF compatibility.
