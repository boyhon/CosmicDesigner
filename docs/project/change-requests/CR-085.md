## Background
Apple SVG has 45 cubic intervals and 3 closed subpaths; existing saved DXF expands into 846 shape LINEs plus 4 material edges. Selection performance is a separate concern; entity reduction is not proof of UI speedup.

## Current Behavior
CR-084 provides integrated SVG import with nominal .01mm LINE flattening. No standalone converter exists. CR-085 is independent, preserving CR-084 implementation/history.

## Required Behavior / Scope
Standalone WPF executable, reusable SVG reader/optimizer/DXF writer, quiet literal suffix path handling and documented exit codes, asynchronous GUI Open preview / Save conversion / safe exit, mm/96dpi/Y/viewBox/transforms/use mapping, secure bounded data-only XML, unsupported geometry failure, .05mm overall curve error, exact circles/arcs and certified fitted arcs or adaptive lines, atomic output and read-back. No viewport cutting rectangle. Source path grouping retained. Nested simple filled rings honor fill rule; intersecting/touching fill requires explicit error rather than uncertified Boolean output. This limitation must be disclosed and covered by tests.

## Implementation Notes
Bezier convex-hull chord bound and elliptic second-derivative interpolation bound; fitted circle certification recursively compares both parameterized curves through the circle chord. Same-t distance bounds provide a conservative two-way curve distance bound; reserve numeric margin. No sampled deviation represented as a proof. G17 output. Same-directory temporary write/read-back before atomic replacement. WPF data-only path parsing; no network or scripts. Development identity inherited from common authority.
