# CR-089 H/W Section Designer Fit/Reset

## Status
Implemented
Verification Status: WAITING FOR USER VERIFICATION

## Request
2026-10-08 user conversation: H Section Designer와 W Section Designer에서 도형이 화면을 벗어나면 중앙에 상하좌우 높이와 폭을 맞추는 버튼 "Fit/Reset" 추가.

## Background
확대된 단면을 한 번의 조작으로 전체 보기로 복원해야 한다.

## Current Behavior
기본 렌더링은 패널에 맞추지만 휠 확대 후 맞춤 복원 버튼이 없다.

## Required Behavior
각 Section 도구 모음에 Fit/Reset을 제공한다. 해당 화면의 zoom/pan을 초기화하고 현재 패널 크기의 기본 중앙 맞춤 배율로 복원한다. Flat/Bent, H/W 모두 지원하며 현재 회전, 치수 표시, 검사 위치 및 문서 형상은 유지한다.

## Scope
SectionDesignerView, H/W toolbar, external language catalogs, tests and HTML help.

## Implementation Notes
기존 Flat 배치와 BentFitScale을 재사용한다. Refresh로 형상과 치수 입력란을 함께 갱신한다. 다른 단면 및 Flat/3D 화면은 변경하지 않는다. 기존 Fit의 최대 배율과 치수 여백은 유지한다. Routine UI change: 새 ADR 불필요.

## Acceptance Criteria
1. H/W 각각 Fit/Reset 버튼을 표시하고 해당 화면만 복원한다.
2. 확대 후 전체 단면을 중앙에 기본 맞춤 배율로 표시한다.
3. Flat/Bent 및 회전 상태를 유지하고 치수 입력란이 원래 위치로 복원된다.
4. 반복 클릭과 문서 없는 상태에서도 안전하며 문서/Undo 내용은 변경하지 않는다.
