## Impact Analysis and implementation

SectionSelectionEngine uses the existing section interval engine, keeping a valid guide or trying the center and midpoint candidates between contour extrema. MainWindow synchronizes the three views on refresh. Guide coordinates are optional DXF view metadata, scale with units, and participate in Undo/Redo snapshots. Legacy files without coordinates initialize from the current contour.
