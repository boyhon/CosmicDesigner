## Impact Analysis and implementation

Classify contacts of the existing axis-aligned bend model after clipping against outer contour and holes. Distinguish interior crossings, endpoint touches, shared endpoints and overlap. Orange markers are screen overlays. Hover is informational, click opens existing straight L slit and rectangle hole tools. Existing rectangle preview is committed on mouse release and outer-boundary merging remains an explicit existing operation. Recalculate contacts on document changes. Keep 3D rendering available with a review warning.

The current bend model stores axis and station. Original finite DXF bend endpoints cannot be recovered from documents that have already normalized them. This implementation compares finite effective material spans. Retaining original DXF source extents and validating fabrication infeasibility remain separate requirements. No automatic relief geometry is generated.
