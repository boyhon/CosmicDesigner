# CosmicDesigner 변경 요구사항(CR) 구현 지시서

## 1. 작업 목표

GitHub 저장소 `boyhon/CosmicDesigner`의 최신 개발 소스를 기준으로 다음 세 가지 변경 요구사항을 구현하라.

1. **Section 기준선 자동 위치 보정:** 재료 치수 변경으로 H/W Section 기준선이 재료 밖으로 벗어나면 적절한 재료 중앙 위치로 자동 이동한다.
2. **3D Preview 연속 회전:** 마우스 상하 드래그에 적용된 약 180도 회전 제한을 제거하여 좌우 회전과 마찬가지로 연속 회전할 수 있도록 한다.
3. **교차 V-Cut 탐지 및 수정 안내:** V/V1 절곡선의 교차점을 탐지하여 경고하고, 사용자가 Cut 또는 Hole 작업을 선택하여 직접 수정하도록 지원한다.

이 작업은 기존 프로그램의 구조, 기능, UI 스타일, 설계 데이터 모델을 최대한 유지하면서 수행해야 한다.

### 절대 준수사항

- 기존 기능을 임의로 삭제하거나 축소하지 않는다.
- 변경사항은 현재 프로젝트의 CR 관리 규칙에 따라 등록한다.
- 기존 테스트와 신규 테스트를 모두 수행한다.
- 변경된 기능과 관련된 사용자 도움말을 갱신한다.
- 특히 CR-03에서는 **프로그램이 사용자 승인 없이 절개선 또는 천공 영역을 생성·삭제·변경해서는 안 된다.**
- 기존에 정상 작동하던 기능이 손상되는 Regression을 방지한다.

## 2. 작업 착수 및 기존 구조 분석

구현에 앞서 다음 사항을 확인하라.

1. `AGENTS.md` 및 관련 개발 규칙
2. 기존 CR 목록과 번호 부여 규칙
3. Regression Test Suite와 테스트 케이스 관리 체계
4. Flat Designer, W Section Designer, H Section Designer, 3D Preview 관련 코드
5. L/V/V1 레이어의 데이터 모델 및 편집 기능
6. Outer Contour, Inner Contour, Cut Object의 기하 처리 로직
7. 도형 변경 시 모델 갱신과 화면 동기화 처리 방식
8. Undo/Redo 및 사용자 도움말 구조

현재 저장소에서 사용되는 실제 클래스, 함수, 모듈 및 파일 이름을 확인하고 이를 재사용하라.

본 지시서에 사용한 명칭이 실제 소스의 명칭과 다르면 기존 소스의 명칭을 우선한다.

기존 CR과 요구사항이 중복되면 신규 CR을 무조건 만들지 말고 기존 항목을 확장하거나 연결하라.

작업 전 현재 브랜치와 Git 상태를 확인하고, 기존 미커밋 작업을 보존하라.

# CR-01. Section 기준선 자동 위치 보정

## 3. 현상 및 문제점

W Section Designer에서 재료의 길이를 축소하면 Flat Designer에 존재하는 H Section 기준선이 재료 영역 밖으로 벗어날 수 있다.

그 결과 H Section Designer에는 단면 형상이 표시되지 않고 화면이 하얀 공백으로 나타난다.

이는 원칙적으로 단면 기준선이 재료와 교차하지 않아서 발생하는 정상적인 계산 결과이지만, 사용자는 프로그램이 오작동한 것으로 오해할 수 있다.

동일한 문제는 H Section Designer의 치수 변경으로 W Section 기준선이 재료 범위를 벗어나는 경우에도 발생할 수 있다.

## 4. 구현 요구사항

### CR-01-01. 기준선 유효성 자동 검사

다음 작업이 발생할 때 H/W Section 기준선의 유효성을 검사한다.

- W Section Designer에서 재료의 길이 또는 형상 변경
- H Section Designer에서 재료의 길이 또는 형상 변경
- Flat Designer에서 재료 외곽 형상 변경
- 기존 설계 데이터 로딩 또는 복원
- 기타 재료 외곽 형상을 변경하는 작업

기준선의 유효성은 기존 프로젝트의 좌표계와 기준선 표현 방식을 기준으로 판단한다.

단순히 Bounding Box 범위 안에 있는지만 검사하지 말고, 실제 재료 영역과 기준선이 유효하게 교차하는지 확인한다.

### CR-01-02. 기준선 자동 위치 조정

기준선이 유효하면 기존 위치를 유지한다.

기준선이 재료 영역 밖에 있거나 유효한 단면을 생성할 수 없는 위치에 있으면, 기준선을 해당 방향의 재료 중앙으로 이동시킨다.

예를 들어 재료 폭이 400mm에서 150mm로 변경되고 기존 기준선이 200mm에 있다면 새로운 기준선을 75mm로 보정한다.

단, 비정형 재료에서는 Bounding Box 중앙이 실제 재료 내부에 존재하지 않을 수 있으므로 다음 원칙을 적용한다.

1. 우선 해당 축의 중앙을 후보로 계산한다.
2. 해당 위치에서 유효한 Section을 얻을 수 있는지 확인한다.
3. 유효하지 않으면 재료 내부에서 가장 적절한 유효 위치를 계산한다.
4. 유효한 위치가 전혀 없으면 임의의 위치로 이동시키지 않고 기존 오류·경고 처리 체계를 사용한다.

기존에 유효했던 기준선을 단지 재료 치수가 바뀌었다는 이유만으로 무조건 중앙으로 이동시켜서는 안 된다.

### CR-01-03. 화면 동기화

기준선이 자동 이동되면 다음 사항을 동시에 갱신한다.

- Flat Designer의 H Section 기준선
- Flat Designer의 W Section 기준선
- H Section Designer의 단면 표시
- W Section Designer의 단면 표시
- Section 기준선의 내부 상태 및 저장 데이터

불필요한 반복 갱신이나 무한 이벤트 루프가 발생하지 않도록 한다.

### CR-01-04. 사용자 알림

기준선이 자동 보정된 경우에만 기존 UI 스타일과 일치하는 비차단 알림을 표시한다.

예시:

"H Section 기준선이 재료 범위를 벗어나 재료 중앙으로 자동 이동되었습니다."

모달 확인창은 사용하지 않는다.

### CR-01 검증 항목

- TC-01: 재료 축소 후 H 기준선이 외부에 있으면 자동 보정된다.
- TC-02: 재료 축소 후 W 기준선이 외부에 있으면 자동 보정된다.
- TC-03: 기준선이 유효하면 위치가 변경되지 않는다.
- TC-04: 비정형 재료에서도 유효한 위치가 계산된다.
- TC-05: 자동 보정 후 Section 화면이 정상 갱신된다.
- TC-06: 기준선 저장 및 재로딩 결과가 일관된다.
- TC-07: Undo/Redo 이후에도 기준선과 단면 화면의 일관성이 유지된다.
- TC-08: 유효 단면을 찾을 수 없는 경우에도 프로그램이 안정적으로 동작한다.

# CR-02. 3D Preview 상하 연속 회전 기능

## 5. 현상 및 문제점

현재 3D Preview는 마우스를 드래그하여 3D 형상을 회전할 수 있다.

좌우 드래그는 수직축을 중심으로 연속 회전할 수 있다.

그러나 상하 드래그는 수평축을 중심으로 약 180도 범위까지만 회전한다.

이는 사용자가 재료의 모든 방향을 자유롭게 관찰하는 데 불편을 초래한다.

## 6. 구현 요구사항

### CR-02-01. 상하 회전 제한 제거

마우스 드래그에 의한 상하 회전 제한을 제거한다.

| 마우스 이동 | 동작 |
|---|---|
| 좌 → 우 | 수직축 중심 시계 방향 회전 |
| 우 → 좌 | 수직축 중심 반시계 방향 회전 |
| 위 → 아래 | 수평축 중심 Down Pitch 회전 |
| 아래 → 위 | 수평축 중심 Up Pitch 회전 |

상하 방향 모두 360도 이상 연속 회전이 가능해야 한다.

회전 방향을 반대로 드래그하면 회전 방향도 자연스럽게 반전되어야 한다.

마우스 이동량과 회전량의 관계는 기존 조작 감도를 최대한 유지한다.

### CR-02-02. 3D 회전 안정성

기존 회전 구현을 조사하여 Pitch Clamp 또는 이에 준하는 회전 제한의 원인을 확인한다.

필요하면 Quaternion 기반 회전 등 적합한 방식을 적용한다.

다음 현상이 발생하지 않도록 한다.

- 90도 부근에서 갑자기 회전 방향이 반전되는 현상
- 180도 부근에서 회전이 멈추는 현상
- 도형이 갑자기 초기 위치로 이동하는 현상
- 회전 중 형상이 뒤집히거나 불안정하게 흔들리는 현상
- 회전 누적에 따른 수치적 불안정성

기존 Orbit 동작과 좌표계의 의미를 보존한다.

### CR-02-03. 기존 기능 보존

다음 기능은 영향을 받지 않아야 한다.

- 좌우 연속 회전
- Zoom In / Zoom Out
- Pan 기능이 존재하는 경우 해당 동작
- Reset View
- 기본 카메라 시점
- 재료 모델의 좌표 및 기하 데이터
- 3D Preview의 렌더링 결과

회전은 관찰 시점만 변경해야 하며 실제 설계 데이터나 재료의 기하 좌표를 변경하지 않아야 한다.

### CR-02 검증 항목

- TC-01: 상하 360도 이상 연속 회전
- TC-02: 상하 720도 이상 반복 회전
- TC-03: 좌우 360도 이상 연속 회전
- TC-04: 상하 회전 후 좌우 회전의 정상 동작
- TC-05: 좌우 회전 후 상하 회전의 정상 동작
- TC-06: 90도·180도·270도 부근의 안정성
- TC-07: 회전 방향 반전
- TC-08: Reset View 동작
- TC-09: Zoom 및 기존 카메라 조작 기능 유지
- TC-10: 회전 작업 전후 설계 데이터 불변

# CR-03. V/V1 절곡선 교차점 탐지 및 사용자 선택형 수정 안내

## 7. 배경 및 목적

Flat Designer에서는 V 레이어와 V1 레이어의 LINE을 이용하여 절곡 위치를 표현한다.

복수의 V-Cut LINE이 서로 교차하면 실제 절곡 작업에서 기하학적 충돌이나 가공상의 문제가 발생할 수 있다.

특히 교차점에 여러 절곡선 분기가 모이는 경우, 재료를 절개하거나 특정 영역을 천공해야 절곡이 가능한 형상으로 변경할 수 있는 경우가 있다.

그러나 절개할 선분이나 제거할 영역을 프로그램이 임의로 결정하는 것은 설계자의 의도와 다를 수 있다.

따라서 이번 CR의 목적은 자동 수정이 아니다.

**교차점을 자동 탐지하고, 사용자가 교차점에서 적절한 수정 작업을 직접 선택할 수 있도록 안내하는 기능을 구현하는 것이다.**

## 8. 구현 범위와 핵심 원칙

### CR-03-01. 교차점 자동 탐지

Flat Designer의 다음 LINE 조합을 검사한다.

- V 레이어와 V 레이어
- V1 레이어와 V1 레이어
- V 레이어와 V1 레이어

가능하면 기존 Geometry Engine 또는 Line Intersection 계산 기능을 재사용한다.

다음 항목을 구분하여 처리한다.

1. 두 LINE이 내부에서 교차하는 경우
2. 한 LINE의 끝점이 다른 LINE에 접하는 경우
3. 두 LINE이 동일한 끝점을 공유하는 경우
4. LINE이 서로 겹치는 경우
5. 실제 절곡 영역 밖에서 연장선만 교차하는 경우

교차점 탐지는 무한 직선이 아니라 실제 유효 LINE 구간을 기준으로 한다.

교차점 좌표는 기존 Geometry Tolerance 정책을 사용하여 비교하고, 동일 위치에서 중복 경고가 발생하지 않도록 한다.

모든 교차가 실제 절곡 불가능을 의미하는 것은 아니다.

따라서 이 기능에서는 우선 절곡 가능성 검토가 필요한 교차점을 탐지하고 경고하는 것을 기본으로 한다.

### CR-03-02. 교차점 표시

교차점이 발견되면 Flat Designer에서 해당 위치를 시각적으로 강조한다.

권장 표현:

- 주황색 또는 노란색 경고 마커
- 교차점 주변의 작은 원형 강조 영역
- 기존 LINE 색상 규칙 유지
  - L: 검정색
  - V: 빨간색
  - V1: 파란색

경고 마커는 설계 데이터가 아니라 UI Overlay로 관리한다.

DXF 저장 시 경고 마커가 실제 LINE 또는 객체로 저장되어서는 안 된다.

확대·축소 및 화면 이동 시에도 정확한 위치에 표시되도록 한다.

### CR-03-03. Mouse Hover 안내 기능

사용자가 경고 마커에 마우스를 올리면 다음과 같은 안내를 표시한다.

**교차 V-Cut 발견**

"이 위치에서 절곡선이 교차합니다. 실제 제작 가능성을 검토하고 필요한 수정 방법을 선택하십시오."

수정 작업 선택 항목:

- Cut — 절개선 작성
- Hole — 천공 영역 지정

Hover만으로 편집 모드가 변경되거나 실제 설계 데이터가 수정되어서는 안 된다.

Hover 영역에서 UI가 깜빡이거나 메뉴가 즉시 사라지지 않도록 포인터 진입·이탈 동작을 적절히 설계한다.

경고 위치를 클릭하면 수정 메뉴를 고정하거나 기존 프로그램의 컨텍스트 메뉴 체계를 활용할 수 있다.

### CR-03-04. Cut 선택 시 동작

사용자가 Cut을 선택하면 기존 L 레이어의 LINE 작성 도구를 활성화한다.

이후 사용자가 직접 절개선의 시작점과 끝점을 지정한다.

다음 원칙을 준수한다.

1. 절개 방향을 자동으로 결정하지 않는다.
2. 절개할 방사선이나 선분을 자동으로 선택하지 않는다.
3. 절개 길이를 프로그램이 임의로 결정하지 않는다.
4. 교차점 스냅 기능이 존재하면 재사용한다.
5. 사용자가 명시적으로 작성한 절개선만 설계 데이터에 반영한다.
6. 기존 LINE 편집 규칙과 Undo/Redo 동작을 유지한다.

교차점에서 시작하는 네 개의 방사선 중 특정 방사선을 프로그램이 자동으로 L 레이어로 변환해서는 안 된다.

사용자가 Cut을 선택한 것은 절개선 작성 도구를 선택한 것이지, 임의의 절개선 생성을 승인한 것이 아니다.

### CR-03-05. Hole 선택 시 동작

사용자가 Hole을 선택하면 기존의 폐곡선 선택 또는 천공·차집합 편집 기능을 활성화한다.

사용자가 제거하려는 영역을 직접 지정하도록 한다.

다음 원칙을 준수한다.

1. 제거 영역을 자동 선택하지 않는다.
2. 교차점 주변의 네 영역 중 특정 영역을 자동 제거하지 않는다.
3. 제거할 폐곡선은 사용자가 명시적으로 지정한다.
4. 사용자가 선택한 영역을 시각적으로 강조한다.
5. 실제 적용 전 제거 결과를 확인할 수 있도록 기존 Preview 기능을 활용한다.
6. 사용자가 확정한 경우에만 기존 Boolean Subtraction 및 Contour 재구성 기능으로 반영한다.

제거 영역이 재료 외곽과 연결되면 Outer Contour를 재구성하고, 내부에 존재하면 적절한 Inner Contour를 생성해야 한다.

다만 이 단계에서 기존 기하 처리 엔진을 새로 작성하거나 기존 Boolean 동작을 변경해서는 안 된다.

기존 기능으로 처리할 수 없는 선택 영역은 잘못된 결과를 생성하는 대신 사용자에게 한계를 안내한다.

### CR-03-06. 수정 취소와 Undo/Redo

사용자가 Cut 또는 Hole을 선택한 후 Esc를 누르면 작업을 취소하고 기존 화면 상태로 돌아간다.

확정되지 않은 임시 객체는 설계 데이터에 반영하지 않는다.

확정된 수정 작업은 기존 Undo/Redo 시스템에서 정상 복구되어야 한다.

자동 교차점 검사나 경고 표시 자체가 Undo History를 오염시켜서는 안 된다.

### CR-03-07. 수정 후 교차점 재검증

사용자가 Cut 또는 Hole 작업을 완료하면 변경된 모델의 교차점을 다시 검사한다.

- 교차 조건이 사라졌으면 해당 경고를 제거한다.
- 교차 조건이 남아 있으면 경고를 유지한다.
- 새로운 교차점이 발생했으면 해당 위치에 경고를 추가한다.

단순히 L 레이어에 LINE을 추가했다는 이유만으로 교차 경고를 제거해서는 안 된다.

실제 절곡선의 유효 구간과 재료 형상이 변경되어 문제가 해결되었는지 검사해야 한다.

### CR-03-08. 3D Preview 연동

교차 V-Cut에 대한 검증 상태를 3D Preview에 전달할 수 있도록 한다.

다음 상태를 구분한다.

- 정상: 교차에 따른 문제가 발견되지 않음
- 경고: 교차가 발견되었으나 실제 절곡 불가능 여부는 확정되지 않음
- 오류: 현재 모델의 절곡 규칙상 구현 불가능한 기하학적 모순이 확인됨

경고 상태에서는 사용자가 검토용 3D Preview임을 인지할 수 있도록 한다.

오류 상태에서는 잘못된 절곡 3D 형상을 정상 결과처럼 생성하거나 표시하지 않는다.

오류 상태의 경우 다음 메시지를 표시한다.

"절곡이 불가능한 형상이 발견되었습니다. Flat Designer의 경고 위치에서 절개 또는 천공 작업을 검토하십시오."

다만 교차점이 있다는 이유만으로 무조건 오류로 판정하지 않는다.

현재 프로그램에 실제 절곡 가능성을 확정할 수 있는 검증 로직이 없다면, 이번 CR에서 불완전한 규칙을 이용해 절곡 불가능 판정을 만들어내지 않는다.

이 경우 교차 검출은 경고로 처리하고, 기하학적 절곡 불가능성 판정을 별도 구현 과제로 명확히 구분하여 보고한다.

## 9. CR-03에서 금지되는 구현

다음 기능은 구현하지 않는다.

- 교차점 발견 시 자동 Cut Line 생성
- 네 방사선 중 하나를 자동으로 선택하여 절개
- 교차점 주변 폐곡선의 자동 천공
- 자동 Boolean Subtraction 실행
- 사용자의 명시적인 선택 없이 Outer Contour 수정
- 사용자의 명시적인 선택 없이 Inner Contour 추가 또는 삭제
- 단순 교차만을 이유로 모든 3D Preview 생성 차단

**이번 CR의 핵심은 자동 수정이 아니라 사용자에게 수정 방법을 안내하고 기존 편집 기능으로 연결하는 것이다.**

자동 테스트만 통과한 경우에는 실제 마우스 조작을 검증한 것으로 보고하지 않는다.

# 15. Git 관리 및 최종 보고

기존 브랜치와 변경 관리 정책을 준수하라.

- 작업 시작 시 Git 상태를 확인한다.
- 기존의 미커밋 변경사항을 보존한다.
- 신규 변경은 추적 가능한 단위로 관리한다.
- 관련 소스, 테스트, 도움말 및 CR 문서를 함께 관리한다.
- 검증이 완료된 변경사항을 논리적인 단위로 Commit한다.
- 기존 정책에 따라 작업 브랜치를 Push하고 PR을 준비한다.
- 명시적으로 승인되지 않은 기존 PR의 Merge는 실행하지 않는다.

최종 보고에는 다음 사항을 반드시 포함한다.

1. 구현한 CR 번호 및 제목
2. CR별 변경 내용
3. 변경된 소스 파일
4. 신규·수정 테스트 케이스
5. 자동 테스트 통과/실패/미실행 현황
6. 수동 검증이 필요한 항목
7. 도움말 변경 내용
8. 기존 기능과의 호환성 검토 결과
9. 남아 있는 문제 및 후속 권고사항
10. Commit Hash 및 PR 정보(생성된 경우)

## 최종 강조사항

이번 작업의 주요 목표는 사용자 경험을 개선하면서 설계 데이터의 무결성과 기존 기능을 보존하는 것이다.

CR-01에서는 필요한 경우에만 기준선을 자동 보정한다.

CR-02에서는 상하 회전의 자유도를 확대하되 기존 카메라 조작의 일관성을 유지한다.

CR-03에서는 교차점을 자동 탐지하되 **절개나 천공을 임의로 수행하지 않는다.** 사용자가 수정 방법과 위치를 직접 결정하며, 프로그램은 이를 안내하고 기존 편집 기능을 제공한다.

구현 중 요구사항의 의미가 불명확한 부분은 기존 동작을 보존하는 방향으로 판단하라. 기존 설계 모델의 의미를 변경하거나 데이터 손실 가능성이 있는 자동 수정은 진행하지 말고 최종 보고서에 별도 검토 사항으로 기록하라.

이제 현재 저장소 구조를 분석한 뒤 위 변경사항을 실제 코드와 테스트에 반영하라.
