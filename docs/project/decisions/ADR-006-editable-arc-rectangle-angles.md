# ADR-006 — Editable ARC and Rectangle angles
Status Accepted — user CR081/082, 2026-10-07.

ARC stores start plus signed unwrapped end; +X0, CCW positive. UI edits raw degrees, displays signed sweep;0<abs(end−start)<360.350→370 is CCW20;350→10 is CW340. Normalize start modulo360 and retain signed span. Existing clockwise DXF export swaps endpoint order to equivalent native CCW path; metadata retains signed direction. Keep center/radius constant during angle edits. Reconnect adjacent LINE endpoints; retain adjacent non-LINE geometry and add connector LINE only if needed. Validate exact extrema, loop closure/orientation, nonadjacent intersections before mutation; reject invalid geometry. Edited Cut primitives become Compound; independent slits remain open and remove no area. Editing a connected Fillet angle can remove tangency, so it is then an ordinary ARC; original radius-rebuild may reject incompatible tangent geometry safely.

Rectangle uses center, localWidth/localHeight and normalized CCW rotation. Local dimensions remain independent of axis-aligned bounds. Shared rotated corners drive cache/render/selection/extent/move/validation. UI resizes rotated rectangle via local width/height; body moves center only; original angle0 mouse handles unchanged. Rotation optional metadata/history: missing=0, legacy nonparametric/filleted geometry not reconstructed. Altering rectangle topology by fillet/merge becomes Compound. Native DXF4 rotated LINE edges represent the real boundary; no new schema. Existing units scale lengths only. Reject nonfinite/outside values atomically; no-op no dirty/history. Product/version/Freeze authority unchanged.
