DXFDrawer 사용 설명서

기존 DXF를 수정하거나 LINE ARC CIRCLE과 V V1 절곡선을 사용해 새로운 판금 도면을 작성하고 저장합니다.

프로그램 개요

Drawing Canvas, 레이어·스냅 설정, Objects 목록, Property Editor와 X Y 단면 절곡 시뮬레이션을 한 화면에서 사용합니다.

빠른 시작

  1. 열기로 기존 DXF를 불러오거나 새로 만들기를 누릅니다.
  2. 작성 도구로 형상을 추가하고 선택 핸들 또는 Property Editor로 수정합니다.
  3. Objects의 경고와 Closed contour를 확인합니다.
  4. 저장을 눌러 DXF 파일을 기록합니다.
