VCutting.Explorer 사용 설명서

폴더에서 DXF 파일을 찾고 정보를 확인한 뒤 VCutting.Viewer 또는 VCutting.Simulator로 여는 파일 탐색 프로그램입니다.

프로그램 개요

왼쪽 폴더 트리, 가운데 DXF 파일 목록, 오른쪽 파일 상세 정보로 구성됩니다. 주소 표시줄과 검색 상자로 원하는 도면을 빠르게 찾을 수 있습니다.

빠른 시작

  1. 왼쪽 폴더 트리 또는 주소 표시줄로 폴더를 엽니다.
  2. 가운데 목록에서 DXF 파일을 선택해 오른쪽 분석 정보를 확인합니다.
  3. 작업도 보기를 눌러 VCutting.Viewer로 열거나 모의 절곡을 눌러 VCutting.Simulator로 엽니다.

기능별 도움말

화면 구성탐색 버튼, 폴더 트리, 파일 목록과 상세 정보파일 찾기주소 이동, 검색, 새로 고침과 최근 폴더Viewer와 Simulator 실행선택한 DXF를 연결 프로그램으로 전달문제 해결폴더 접근, 파일 분석과 실행 파일 찾기
