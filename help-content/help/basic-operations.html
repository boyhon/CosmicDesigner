기본 조작

선택과 속성

  1. Flat Designer 하단의 Select를 선택합니다.
  2. 천공의 몸체나 절개·절곡·외곽 선을 클릭합니다. 겹친 절개와 절곡에서는 절개가 먼저 선택됩니다.
  3. 필요하면 OBJECTS에서 해당 객체 또는 자식 LINE/ARC를 선택합니다.
  4. Selected object의 입력란을 수정하고 다른 입력란으로 이동하여 적용합니다. 읽기 전용 값은 직접 수정할 수 없습니다.

이동·확대

Flat Designer에서 오른쪽 버튼으로 끌면 화면이 이동합니다. 마우스 휠은 포인터 주변을 확대·축소하고, 상단 −/+/Fit 또는 View > Zoom 메뉴도 사용할 수 있습니다. 단면 휠 확대는 화면 중심을 유지합니다. 3D에서는 왼쪽 버튼 드래그로 회전하고 휠로 확대합니다.

수정·삭제·되돌리기

선택한 천공 몸체를 드래그하면 이동하고, 핸들을 드래그하면 크기 또는 꼭짓점을 바꿉니다. 객체 트리나 Flat에 키보드 초점이 있을 때 Delete로 삭제합니다. Material, 외곽 전체, Section Segment 같은 구조 항목은 삭제할 수 없습니다. Edit > Undo/Redo 또는 Ctrl+Z/Ctrl+Y로 되돌립니다. 새 파일을 열거나 만들면 이전 문서의 되돌리기 기록은 초기화됩니다.

주의: 텍스트를 입력 중이면 Delete는 입력란의 문자를 지울 수 있습니다. 삭제할 객체와 키보드 초점을 먼저 확인하세요.

표시 설정

View > Ruler / Grid / Status Bar는 다음 실행에도 유지됩니다. H/W Section의 Dimensions, Bent, Rotation은 문서 저장 상태와 함께 복원됩니다. 파일에 저장된 상태가 우선하며 새 문서·일반 가져오기에는 최근 기본 상태를 사용합니다.
