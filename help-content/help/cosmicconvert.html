CosmicConvert — SVG를 DXF로 변환

CosmicConvert는 SVG의 절단 경로를 mm 단위 DXF로 저장하는 별도 Windows 프로그램입니다. CosmicDesigner의 SVG Import와 별도로 실행합니다. 개발 빌드는 .NET 10 Windows Desktop Runtime이 필요합니다. 개발 빌드의 식별자는 창 제목에서 확인할 수 있습니다.

파일명으로 실행 · Open / Save / Exit · 형상과 단위 · 지원 범위와 제한 · 오류와 종료 코드

파일명으로 실행

CosmicConvert.exe "C:\Drawings\Sample - Apple"

확장자를 제외한 파일 경로 하나를 전달합니다. 예에서는 Sample - Apple.svg를 읽어 Sample - Apple.dxf로 저장하고 종료합니다. 상대 경로는 호출한 프로세스의 현재 폴더 기준입니다. 공백·한글·점이 포함된 이름을 사용할 수 있습니다. 전달한 이름 끝에 .svg와 .dxf를 붙이므로 이미 확장자를 포함한 인수에서도 확장자를 제거하지 않습니다.

인수가 있으면 quiet 모드로 동작하여 창이나 대화상자를 표시하지 않습니다. 기존 DXF는 변환·검증이 성공한 후 교체됩니다. 실패하거나 저장이 취소되면 기존 파일을 보존합니다.

Open / Save / Exit

  1. 인수 없이 CosmicConvert.exe를 실행합니다.
  2. Open에서 SVG를 선택합니다. 읽은 경로를 종횡비를 유지하여 미리보기합니다. 아직 DXF를 생성하지 않습니다. 미리보기는 절단 경로를 선으로 표시하며 색·채움·stroke 폭의 원본 외관을 재현하는 화면은 아닙니다.
  3. Save에서 DXF 저장 위치를 선택합니다. 원본 폴더와 이름을 기본으로 제안합니다. 변환 단계는 화면 아래에 표시됩니다. 처리 중에는 Open과 Save를 사용할 수 없습니다.
  4. 완료하면 저장 경로, 경계선 포함 엔티티 개수, 10 mm 여백·경계선 크기와 곡선 오차 상한을 확인합니다.
  5. Exit로 종료합니다. 처리 중 종료 요청은 보류되고 변환 취소를 요청합니다. 처리가 끝나면 다시 Exit를 선택합니다. Open 읽기 중에도 종료는 완료까지 보류됩니다.

도움말은 실행 파일 옆 CosmicConvert_help.html을 브라우저로 열어 확인할 수 있습니다.

형상과 단위

출력은 LINE, ARC, CIRCLE을 사용합니다. 원과 원호는 가능한 경우 그대로 유지하고, 일반 곡선은 직선과 원호로 근사합니다. 기본 전체 곡선 근사 허용오차는 0.05 mm입니다. 표시되는 값은 계산된 보수적 곡선 오차 상한이며, 모든 가공 작업에 적합한 정밀도를 뜻하지 않습니다.

mm·cm·in·pt·pc·px를 해석하고 px 및 단위 없는 길이는 96 px/in 기준입니다. viewBox만 있으면 그 크기를 px로 해석합니다. 실물 크기와 viewBox, preserveAspectRatio, 중첩 변환을 반영합니다. SVG의 아래 방향 Y축을 DXF의 위 방향 Y축으로 변환하여 YDXF = viewport 높이(mm) − 변환된 Y(mm)로 저장합니다. 회전이나 크기 변경 없이 그림 전체를 이동하여 사각 경계선 좌하단을 (0, 0), 그림 외접 범위 좌하단을 (10, 10) mm로 맞춥니다.

stroke는 중심선으로 처리하고 폭을 이중 윤곽으로 변환하지 않습니다. fill="none"인 닫힌 경로는 원래 경로를 보존합니다. 채움은 비교차 중첩 폐곡선에서 nonzero/evenodd 규칙에 따라 실제 경계를 남깁니다. 열린 경로는 임의로 닫지 않습니다. 저장할 때 변환된 그림의 실제 외접 범위에서 상하좌우 10 mm 떨어진 사각 경계선을 L 레이어의 LINE 4개로 추가합니다. 경계선의 가로·세로 크기는 각각 그림 외접 크기 + 20 mm입니다. 원호와 원의 극점도 반영합니다. SVG viewport 크기는 경계선 크기를 결정하지 않습니다. Open 미리보기는 원본 경로이며 여백·경계선은 Save 변환 시 적용됩니다.

지원 범위와 제한

일부 SVG에는 글자를 경로로 바꾼 도형 옆에 투명한 보조 텍스트가 남아 있습니다. 하위 요소가 없는 text에서 채움과 선이 모두 none 또는 해당 opacity가 0이면 건너뜁니다. 실제로 보이는 글자와 하위 텍스트 요소는 지원하지 않으므로 SVG 제작 도구에서 경로로 변환하세요. 오류의 “text line …”는 해당 텍스트 요소를 확인하라는 뜻입니다.

path의 절대·상대 M/L/H/V/C/S/Q/T/A/Z, 직선·polyline·polygon, 사각형·둥근 사각형, 원·타원, group, translate/scale/rotate/skewX/skewY/matrix, viewBox와 내부 use 참조를 지원합니다.

text·image·stylesheet·CSS geometry·script·filter·mask·clipping·중첩 SVG viewport·symbol viewport·외부 use 참조는 지원하지 않습니다. 영향을 주는 미지원 요소는 오류로 안내합니다. 텍스트는 SVG 제작 도구에서 경로로 바꾸고, 필요한 변환을 요소의 transform에 적용한 뒤 저장하세요. 외부 파일이나 네트워크는 자동으로 불러오지 않습니다.

교차하거나 접촉하는 채움 윤곽은 현재 변환할 수 없습니다. 경로로 정리한 비교차 윤곽을 사용하세요. 매우 가까운 특징이나 교차 stroke 경로는 실제 CAD에서 결과를 확인하세요. 파일·곡선·참조·계산량 제한에 도달하면 형상을 삭제하지 않고 오류로 중단합니다.

CosmicDesigner에서 열기: 변환 파일은 객체 정보도 함께 저장합니다. 같은 SVG 요소의 닫힌 하위 경로는 하나의 Compound Cut으로 복원되어 윤곽 클릭으로 전체 객체를 선택하고 이동·삭제할 수 있습니다. 별도 요소는 별도 객체이며 열린 경로는 Slit으로 유지됩니다. 사각 경계선은 재료 외곽입니다. 원과 최적화된 원호를 유지하며 3D 재료 제거는 닫힌 윤곽과 구멍 관계를 사용합니다. 재료 두께의 초기값은 2 mm입니다.

일반 CAD에서도 L 레이어의 LINE/ARC/CIRCLE과 mm 단위 형상을 사용할 수 있습니다. 객체 정보를 삭제하거나 보존하지 않는 CAD에서 다시 저장하면 CosmicDesigner의 전체 객체 복원이 유지되지 않을 수 있습니다. 이 경우 원본 SVG를 다시 변환하세요. 외부 CAD와 실제 화면의 결과는 작업 전에 확인하세요. 선택 속도 향상은 엔티티 수 감소만으로 보장되지 않습니다.
