새 도면 작성

새로 만들기를 누르고 Grid 간격과 Snap을 설정합니다. 선, 원호, 원은 -L-, V-Line은 -V-, V1-Line은 -V1-에 생성됩니다. 작성 도구에서 시작점을 누른 채 끝점 또는 반경 위치까지 드래그합니다.

  • V-Line과 V1-Line은 수평 또는 수직으로 자동 제한됩니다.
  • 원과 원호는 첫 점이 중심이며 두 번째 점까지의 거리가 반경입니다.
  • 원호는 180도 형상으로 시작하며 이후 시작각과 끝각을 편집할 수 있습니다.

선택과 속성 편집

선택 객체는 주황색 핸들로 표시됩니다. LINE은 끝점과 전체 이동, CIRCLE은 중심과 반경, ARC는 중심·반경·시작각·끝각을 드래그로 편집합니다. Property Editor에서 숫자를 입력한 뒤 Enter를 눌러 정확한 값을 적용합니다.

X Y 단면 시뮬레이션

Canvas의 녹색 X Section과 자홍색 Y Section 점선을 드래그합니다. 해당 단면이 V V1 선을 통과하면 시뮬레이션 패널에 절곡점이 나타납니다. 절곡점을 클릭해 접거나 펼치고 Reset으로 초기화합니다.

Validation과 저장

저장 전 유효하지 않은 좌표, 길이 0 선, 대각 V V1 선, 0 이하 반경, 절단선과 절곡선 중첩을 검사합니다. 오류가 있으면 첫 오류 객체가 선택되고 저장은 중단됩니다. Objects의 경고 표시를 선택해 수정한 뒤 다시 저장합니다.
