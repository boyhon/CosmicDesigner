화면과 파일 관리

화면 구성

영역기능
상단 탐색 도구뒤로, 앞으로, 상위 폴더, 새로 고침, 주소 이동과 현재 폴더 검색
폴더 트리준비된 드라이브와 접근 가능한 일반 폴더를 계층으로 표시
DXF 파일 목록현재 폴더의 *.dxf 이름, 수정일, 유형과 크기 표시
상세 정보선택 파일의 버전, 코드 페이지, 단위, 크기, Entity와 레이어 정보 표시

파일 찾기와 이동

  • 주소 표시줄에 전체 폴더 경로를 입력하고 Enter를 누르면 이동합니다.
  • 검색 상자는 현재 폴더의 DXF 파일명을 대소문자 구분 없이 필터링합니다.
  • 프로그램을 정상 종료하면 마지막 폴더가 사용자 설정에 저장되어 다음 실행 때 다시 열립니다.
  • 목록을 더블 클릭하면 Windows의 기본 연결 프로그램으로 DXF를 엽니다.

DXFViewer와 DXFSimulator 실행

파일을 선택한 뒤 작업도 보기는 같은 설치 폴더의 DXFViewer.exe, 모의 절곡은 DXFSimulator.exe를 실행하고 선택한 파일 경로를 전달합니다.

두 실행 파일은 DXFExplorer.exe와 같은 폴더에 있어야 합니다.
