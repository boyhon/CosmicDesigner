V/V1 절곡 만들기와 이동

전개도에서 만들기

  1. Flat Designer 하단에서 V(적색) 또는 V1(청색)를 선택합니다.
  2. 재료 내부의 절곡 위치에서 오른쪽 또는 아래쪽으로 드래그합니다.
  3. 점선 방향과 위치를 확인하고 놓습니다. 짧은 클릭이나 왼쪽·위쪽 드래그는 생성하지 않습니다.
  4. Select에서 절곡선을 클릭하고 선에 수직으로 끌어 위치를 이동합니다. 재료 끝과 너무 가까운 위치는 제한됩니다.
드래그단면 축V / V1 방향
오른쪽 → 수평 절곡선HLeft / Right
아래쪽 → 수직 절곡선WUp / Down

단면에서 만들기

Bent Mode가 꺼진 H/W Section의 재료 몸체를 클릭해 절곡을 추가할 수도 있습니다. W에서는 몸체 위/아래, H에서는 왼쪽/오른쪽을 클릭해 방향을 선택합니다. 치수 입력란이나 실제 빈 구간에서는 생성하지 않습니다.

속성

OBJECTS의 V Objects/V1 Objects 또는 Flat 선을 선택합니다. Direction, X Position 또는 Y Position, Sequence를 수정합니다. Bend Angle, V-Cut Angle, V-Cut Depth, Residual은 계산 결과로 표시됩니다. Sequence는 절곡 순서이며 3D 결과에 영향을 줄 수 있습니다.

검토

두께를 바꾸면 절곡 관련 값과 단면·3D가 다시 계산됩니다. 저장 전 H/W Bent Mode와 3D에서 방향·순서를 확인하세요. Esc는 진행 중인 Flat 절곡 도구를 취소합니다.
