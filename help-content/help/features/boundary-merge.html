버전: Development

경계 천공을 외곽 홈으로 통합

사용 조건

외곽과 만나는 Rectangle, Triangle, Parallelogram, Semicircle, QuarterCircle 천공을 외곽의 열린 홈으로 바꿀 수 있습니다. 결과가 하나의 닫힌 재료 경계로 유지되어야 합니다. 일반 내부 천공, 점만 닿는 경우, 재료가 여러 조각으로 나뉘는 경우에는 통합할 수 없습니다.

  1. 지원 천공을 생성하거나 이동해 외곽과 접촉시킵니다.
  2. Select에서 선택합니다. 통합 가능한 후보는 주황색으로 표시됩니다.
  3. 천공 위에서 오른쪽 버튼을 눌러 Outer Contour로 통합을 선택합니다.
  4. Cut Objects의 천공이 사라지고 Outer Contour가 홈을 포함하는지 확인합니다.
  5. 단면·3D를 확인하고 저장합니다. Ctrl+Z로 통합 전 천공을 복구할 수 있습니다.

단순 접촉만으로 자동 통합하지 않습니다. 주황색 후보도 실행 전에는 편집 가능한 천공입니다. 외곽에서 떼면 일반 선택 상태로 돌아갑니다. 사선·Fillet 원호를 포함한 외곽도 지원하며 기존 원호는 필요한 범위만 남깁니다.

반원은 지름 직선, 4분원은 반지름 직선이 외곽 LINE과 양의 길이로 겹쳐야 합니다. 통합 후에는 정확한 원호 홈으로 연결됩니다. Circle/일반 Slit을 이 명령의 대상으로 가정하지 마세요.
