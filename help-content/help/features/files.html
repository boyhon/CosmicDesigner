DXF 열기·가져오기·저장

기존 설계 열기

  1. File > Open... 또는 Ctrl+O를 누릅니다.
  2. DXF 파일을 선택합니다. CosmicDesigner에서 저장한 파일이면 설계·단위·단면 보기 상태를 복원합니다.
  3. Material의 크기와 두께, 외곽·천공·절곡·절개를 확인합니다.

File > Recent에는 성공적으로 열거나 저장한 파일이 표시됩니다. 기본 개수는 10이며 Settings에서 1~50개로 변경할 수 있습니다. 없어진 파일은 안내 후 목록에서 제거됩니다.

일반 DXF 가져오기

별도 Import 메뉴 대신 Open을 사용합니다. 설계 정보가 없는 파일에서는 “DXF 자동 가져오기” 확인창이 열립니다.

  1. 원본의 사본을 준비하고 File > Open...으로 엽니다.
  2. 자동 가져오기 설명을 읽고 OK를 선택합니다. Cancel은 가져오기를 취소합니다.
  3. L 레이어의 가장 큰 닫힌 LINE 형상을 외곽으로, 다른 L 형상을 천공으로 가져옵니다. 닫힌 LINE 외곽이 없으면 L 범위의 사각형을 대신 사용하고 경고합니다.
  4. 수평·수직 V/V1 LINE은 절곡이 됩니다. 사선 절곡과 지원되지 않는 엔티티는 제외 경고를 확인합니다.
  5. 단위·두께·형상을 확인하고 Save As...로 새 파일에 저장합니다.

주의: 일반 DXF는 센티미터 표시($INSUNITS=5)를 제외한 입력을 밀리미터로 취급하여 환산합니다. 미터 등 다른 단위의 입력은 사전에 확인·변환하세요. 가져온 두께는 0.2 cm 상당이고 새 문서 기본 단위로 환산합니다. 일반 DXF의 열린 L 선은 새 Slit처럼 자동 복원된다고 가정하지 마세요.

저장

File > Save 또는 Ctrl+S로 현재 파일을 저장합니다. 경로가 없는 새 문서와 일반 가져오기 문서는 Save As 대화상자로 넘어갑니다. File > Save As...는 다른 이름으로 저장합니다. 별도 Export 메뉴는 없으며 DXF 저장이 교환 파일 작성입니다. 파일에는 현재 단위와 설계 정보, L 절단 및 V/V1 절곡 형상이 포함됩니다.

미저장 확인

새로 만들기·열기·Recent·종료·창 닫기에서 변경 사항 저장을 묻습니다. Yes는 저장 후 진행, No는 변경을 버리고 진행, Cancel은 현재 문서를 유지합니다. 저장 대화상자를 취소하거나 저장이 실패하면 현재 문서를 유지합니다.
