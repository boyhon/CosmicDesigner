버전: Development

천공 만들기와 편집

목적과 위치

Flat Designer 하단 Hole 도구로 재료에서 제거할 영역을 만듭니다. 버튼 위에 포인터를 두면 도형명이 표시됩니다. 현재 버튼은 Circle, Ellipse, Semicircle, QuarterCircle, Triangle, Rectangle, Diamond, Parallelogram, Regular Polygon, Regular Star입니다.

생성

  1. 원하는 Hole 버튼을 선택합니다.
  2. 재료 위 기준점에서 왼쪽 버튼을 누르고 원하는 크기까지 끕니다. 점선 미리보기를 확인합니다.
  3. 버튼을 놓으면 천공 하나가 생성되고 Select로 돌아갑니다. 짧은 클릭은 생성하지 않습니다.
도형기준점과 드래그
Circle시작·끝점 범위를 바탕으로 원형 크기를 정합니다.
Triangle시작 Y에 밑변, 끝 Y에 꼭짓점. 아래로 끌면 역삼각형, 위로 끌면 바로 선 삼각형입니다.
Rectangle / Diamond / Parallelogram시작점과 끝점의 범위로 크기를 정합니다.
Semicircle첫 점은 지름 중심입니다. 위·아래·왼쪽·오른쪽 드래그 방향으로 볼록하며 이동 거리가 반지름입니다. 대각선은 큰 이동 축, 동률은 세로를 사용합니다.
QuarterCircle첫 점은 원호 중심입니다. X/Y 드래그 방향으로 사분면을 정하며 두 축 이동량 중 작은 값이 반지름입니다. 축 하나로만 끌면 생성하지 않습니다.

기울어진 타원 만들기

Circle 바로 옆의 가로 타원 윤곽 버튼(Ellipse / 타원)을 선택합니다. 재료에서 장축의 한쪽 끝을 누르고 다른 끝까지 드래그하세요. 수평·수직·사선 모두 드래그 방향으로 기울어지며 처음 장축과 단축의 비율은 2:1입니다. 점선 미리보기를 확인하고 버튼을 놓으면 타원 한 개가 생성됩니다. 재료 경계 근처에서는 방향과 비율을 유지하여 작아집니다. 재료 가장자리만 따라 끌어 폭이 없어지거나 너무 짧게 끌면 생성되지 않습니다.

타원 속성 입력

타원을 선택하면 Selected object에 중심 X/Y, 장축 길이, 단축 길이, 회전각과 단축/장축 비율이 표시됩니다. 장축과 단축은 반지름이 아닌 전체 길이이며 문서 단위를 사용합니다. 회전각은 오른쪽 방향을 0도로 하고 반시계 방향으로 증가합니다. 같은 타원의 방향은 180도 주기로 표시됩니다.

장축 또는 단축을 바꾸면 중심과 회전각은 유지됩니다. 회전각을 바꾸면 중심과 두 축 길이는 유지됩니다. 장축은 단축 이상, 단축은 0.1 이상이어야 합니다. 재료 밖으로 나가는 크기·위치·회전은 적용되지 않으며 원래 값으로 돌아갑니다. 단축/장축 비율은 읽기 전용입니다.

Select에서 몸체로 이동하거나 외접 사각형 핸들로 크기를 편집할 수도 있습니다. 핸들로 한쪽 방향만 늘리면 축 비율과 회전각이 함께 바뀔 수 있습니다. 저장·재열기 및 Undo/Redo 후에도 타원 속성과 형상은 유지됩니다. 객체 트리에서는 정상 타원을 한 객체로 선택합니다.

이동과 크기

Select에서 몸체를 끌어 이동합니다. 삼각형은 세 꼭짓점을 각각 끌어 모양을 바꿀 수 있습니다. 다른 지원 도형은 모서리·변 핸들로 크기를 바꿉니다. 원형 도형은 원호 비율과 방향을 유지합니다. 재료 범위에 맞게 제한됩니다.

천공 몸체를 이동할 때 중심이 인접 평행 외곽선·절곡선 사이 중앙에 가까우면 빨간 점선과 중심 십자가 나타납니다. 이는 위치 안내이며 자동 흡착하지 않습니다. 크기 편집이나 이동 종료 후 사라집니다.

정확한 속성 입력

대상Selected object
CircleRadius R로 크기 수정. Center X/Y는 위치입니다.
TriangleLower-left X/Y는 외접 사각형 좌하단입니다. Width/Height는 해당 기준점과 편집 모양을 유지하여 축별 크기를 바꿉니다.
Semicircle / QuarterCircleCenter X/Y는 실제 원호 중심, Radius R은 반지름입니다. 중심·방향을 유지하여 반지름을 수정합니다.
Rectangle / Diamond / ParallelogramCenter X/Y, Width/Height로 위치와 크기를 수정합니다.

주의: 입력란에 표시된 단위를 확인하세요. 일부 기존 속성 라벨에는 cm가 남아 있습니다. 단위 변경 후에는 Material 및 Document Units를 함께 확인하세요. 양수가 아닌 값, 지나치게 작은 값, 재료를 벗어나는 원호 반지름은 거부될 수 있습니다.

예제

300 × 300 cm 기본 재료 내부에서 Rectangle을 드래그 생성한 뒤 Select에서 몸체를 이동합니다. 전체를 삭제하려면 Cut Objects의 부모 항목을 선택하고 Delete를 누릅니다. Undo로 복구하고 Save As로 저장할 수 있습니다.

겹친 내부 천공 통합

재료 내부에서 천공끼리 겹치면 해당 천공을 선택했을 때 선택 표시와 함께 통합되는 천공의 윤곽이 주황색으로 바뀝니다. 원 두 개 사이에 사각형을 겹치게 놓은 경우처럼 다른 천공을 통해 연결된 천공도 모두 포함됩니다.

  1. Select에서 겹친 천공 하나를 선택합니다.
  2. 선택한 천공 위에서 마우스 오른쪽 버튼을 누릅니다.
  3. Merge overlapping cuts / 겹친 천공 통합을 선택합니다.
  4. 겹친 경계가 사라지고 하나의 Merged Cut / 통합 천공과 내부 윤곽으로 바뀌는지 확인합니다. 떨어진 천공과 외곽선은 유지됩니다.

단순히 겹치게 배치하는 것만으로 자동 통합하지 않습니다. 점으로만 접하는 도형은 통합하지 않습니다. 변을 공유하거나 포함된 천공은 통합할 수 있습니다. 외곽선에 닿은 천공은 외곽 홈 통합을 사용하세요.

통합 천공은 몸체를 끌거나 중심 X/Y로 이동합니다. 직선만 있으면 폭과 높이를 각각 바꿀 수 있습니다. 원호가 포함되면 폭·높이는 읽기 전용이며 Uniform scale (%) / 동일 비율 크기 조정 (%)로 같은 비율로 확대·축소합니다. 핸들 편집도 원호 비율을 유지합니다. Undo 한 번으로 통합 전 모든 천공을 복원하고 Redo로 다시 통합할 수 있습니다. 저장 후 다시 열어도 통합 형상은 유지됩니다.

고리 형태로 통합하면 가운데 남은 재료를 보존합니다. 닫힌 윤곽 수가 여러 개인 통합 천공은 모서리 Fillet을 적용할 수 없습니다.

정다각형 만들기

Hole 도구의 육각형 윤곽 아이콘(Regular Polygon / 정다각형)을 선택합니다. Sides / 변 개수의 기본값은 6이며 3~512의 정수를 입력할 수 있습니다.

  1. 재료 위에서 외접원의 중심을 클릭합니다.
  2. 마우스를 움직여 미리보기의 크기와 방향을 확인합니다. 중심에서 포인터까지의 거리가 외접원 반지름입니다. 미리보기 중 변 개수를 바꿀 수도 있습니다.
  3. 첫 꼭짓점 위치를 클릭하면 정다각형 하나가 생성되고 Select로 돌아갑니다. 중심과 같은 점이나 재료를 벗어나는 크기는 적용되지 않습니다.

Esc 또는 마우스 오른쪽 버튼으로 취소합니다. 다른 도구를 선택해도 미완성 정다각형은 생성하지 않습니다.

정다각형 속성

한 변 또는 몸체를 클릭하면 객체 전체가 선택됩니다. Selected object에서 중심 X/Y, 변 개수, 외접원 반지름과 회전각을 수정합니다. 반지름은 중심에서 꼭짓점까지의 거리이며 현재 문서 단위를 사용합니다. 회전각 0도는 첫 꼭짓점이 오른쪽(+X)을 향하고 반시계 방향으로 증가하며 0~360도 범위로 정리됩니다. 한 속성만 바꾸면 다른 속성은 유지됩니다.

몸체를 끌면 중심만 이동합니다. 크기는 반지름 입력으로 변경합니다. 정다각형은 개별 변·꼭짓점을 편집하지 않으며 Delete는 전체를 삭제합니다. 한 번의 편집은 Undo 한 번으로 되돌립니다. 천공의 레이어는 기존 Hole과 같은 L입니다.

겹친 천공 통합과 외곽 홈 통합을 사용할 수 있습니다. 통합하거나 모서리에 Fillet을 적용하면 일반 통합 천공으로 바뀌며 정다각형 고유 속성 대신 통합 형상 속성을 사용합니다.

DXF에는 꼭짓점을 중복하지 않은 닫힌 LWPOLYLINE으로 저장합니다. CosmicDesigner의 저장 파일을 다시 열면 정다각형 속성도 유지됩니다. 일반 DXF로 가져온 Polyline은 일반 윤곽으로 취급합니다.

정다각별 만들기

정다각형 바로 옆의 교차 별 아이콘(Regular Star / 정다각별)을 선택합니다. 기본값은 꼭짓점 5개, 연결 간격 2입니다. Sides / 변 개수는 별의 꼭짓점 수이며 5~512의 정수를 사용합니다. Step / 연결 간격은 꼭짓점을 몇 칸씩 건너 연결할지 정합니다. 2 이상, (꼭짓점 수−1)/2 이하의 정수를 입력하세요.

  1. 꼭짓점 수와 연결 간격을 입력합니다.
  2. 재료 안에서 중심을 클릭합니다.
  3. 마우스를 움직여 반지름과 방향을 정하고 외곽 프로필의 미리보기를 확인합니다.
  4. 첫 꼭짓점을 클릭하면 하나의 정다각별이 생성됩니다. Esc/오른쪽 클릭은 취소합니다.
모양꼭짓점 수연결 간격
오각별52
육각별 (삼각형 두 개)62
7각별72 또는 3
8각별82 (사각형 두 개) 또는 3

정다각별 속성과 저장

별 선분을 선택하면 전체 객체가 선택됩니다. 중심 X/Y, 꼭짓점 수, 연결 간격, 외접원 반지름과 회전각을 수정할 수 있습니다. 회전각은 첫 꼭짓점의 +X 방향을 0도로 하고 반시계 방향으로 증가합니다. 몸체를 끌면 중심만 이동하고 크기는 반지름으로 변경합니다. 여러 폐곡선도 하나의 객체이므로 Delete/Undo는 전체에 적용됩니다.

천공의 외곽 프로필만 표시하고 저장합니다. 내부에서 교차하던 대각선은 절삭 경로에서 제거됩니다. 정다각별의 내부는 중앙과 여러 윤곽이 겹친 부분까지 모두 천공되어 비어 있습니다. Flat과 3D에 동일하게 반영됩니다. 모서리 Fillet과 외곽 홈 통합은 정다각별에 직접 적용할 수 없습니다. 내부 통합은 유효한 닫힌 경계가 만들어지는 경우에만 적용됩니다.

DXF에는 정다각별의 외곽 프로필 하나가 닫힌 LWPOLYLINE으로 저장됩니다. 천공 내부를 지나는 선분은 포함하지 않습니다. CosmicDesigner 저장 파일을 다시 열면 하나의 별과 고유 속성이 복원됩니다. 일반 DXF로 가져오면 일반 윤곽으로 취급됩니다.

직사각형 회전

Rectangle을 선택하면 중심 X/Y, 도형 기준 폭·높이, 회전각을 입력할 수 있습니다. 회전각 0도는 수평이며 중심을 기준으로 반시계 방향으로 증가합니다. 예를 들어 30도 또는 45도로 기울일 수 있습니다. 폭·높이는 회전된 도형 자체의 변 길이이므로 화면의 수평·수직 경계 상자 크기와 다를 수 있습니다.

몸체를 끌면 각도를 유지하며 이동합니다. 기울어진 직사각형의 크기는 속성의 폭·높이로 변경합니다. 0도에서는 기존 마우스 크기 핸들을 사용할 수 있습니다. 모든 꼭짓점이 재료 안에 있어야 하며 부적합 입력은 적용하지 않습니다. 회전각은 0~360도 범위로 정리되고 단위 변경은 각도를 유지합니다. 저장 파일에는 실제 회전된 네 변이 기록됩니다. Fillet 또는 천공 통합 후에는 일반 통합 천공으로 바뀝니다.

천공 복제

선택한 천공을 Ctrl+C, Ctrl+V로 복제할 수 있습니다. 전체 천공과 속성을 유지합니다. 복사·붙여넣기 절차를 참조하세요.
