재료 두께와 문서 단위

두께

좌측 Material의 Thickness D 또는 Material을 선택한 속성에서 양수 두께를 입력합니다. 두께 변경 확인창의 설명을 읽고 OK를 누릅니다. 절곡 깊이·잔여 두께·치수·3D가 갱신됩니다. Cancel은 이전 값을 유지합니다. Flat W/H는 직접 입력하는 대신 Section 길이로 조절합니다.

단위

  1. Edit > Document Units...를 엽니다.
  2. 새 단위 mm / cm / m를 선택합니다.
  3. 아래 두 방식 중 원하는 것을 선택하고 예제 환산값을 확인합니다.
  4. 변경을 누르고 Material, 천공·절개·단면을 확인합니다. 취소는 변경하지 않습니다.
방식예: 300 cm → mm
실제 크기를 유지하고 모든 숫자 환산3000 mm. 제작 크기는 같습니다.
숫자 값을 유지하고 도형 크기 변경300 mm. 실제 크기가 작아집니다.

주의: 설계의 실제 크기를 보존하려면 첫 번째 방식을 선택하세요. 일부 기존 속성/치수 툴팁은 cm로 표시될 수 있으므로 현재 Document Units와 Material 표시를 함께 확인하세요.

문서 단위는 저장·재열기 및 Undo/Redo에 포함됩니다. Settings의 New Document 기본 단위는 새 문서용이며 현재 문서 단위 변경과 다릅니다.
