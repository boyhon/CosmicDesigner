버전: Development

3D 결과 확인

조작

  1. 3D Preview에서 왼쪽 버튼을 누르고 끌어 시점을 회전합니다.
  2. 휠로 확대·축소합니다.
  3. Fit / Reset으로 기본 방향과 화면 맞춤으로 돌아갑니다.
  4. Semi Transparent를 켜거나 끄고 앞뒤 면과 절단 경계를 확인합니다.

색상과 형상

흰 배경에 회색 재료면을 표시합니다. 외곽과 천공 경계는 검정, V 절곡은 적색, V1은 청색입니다. 내부 메시 분할선은 표시하지 않습니다. 외곽 홈·천공은 면이 제거된 공간이고 Slit은 면적 제거 없이 절단 선으로 표시됩니다.

Fillet 및 원형 천공은 작은 직선 구간으로 표시되며 확대 시 다각형처럼 보일 수 있습니다. DXF와 Flat의 원호 형상은 유지됩니다. 두께와 절곡 순서 변경 후 결과를 다시 확인하세요.

복합 절곡 확인

홈으로 분리된 날개와 연결부는 연결부 힌지를 기준으로 접힌 상태를 보여줍니다. 연속 교차 절곡에서 힌지가 일직선이 아닌 경우 기존 표시 방식으로 처리됩니다. 3D는 형상 확인용이며 충돌·제작 가능성 자동 검증을 제공한다고 가정하지 마세요.
