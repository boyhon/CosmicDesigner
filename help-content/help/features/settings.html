환경 설정

Edit > Settings... 또는 Ctrl+,를 선택합니다. 입력 후 OK는 저장·적용하고 Cancel은 적용하지 않습니다. Restore Defaults는 대화상자의 값을 초기 기본값으로 돌리며 OK를 눌러야 반영됩니다.

탭입력값·범위와 효과
General기본 열기·저장 폴더, Recent 파일 개수 1~50. 기본 Recent는 10.
EditingZoom 단계 1~100%, 선택 허용 거리 2~30 px, 핸들 반지름 3~20 px.
Ruler & Grid가로/세로 Ruler 및 Grid 간격. Auto 또는 현재 표시 단위의 양수. 축소 시 너무 촘촘한 표시는 생략합니다.
3D Preview반투명 Opacity 20~240, 불투명 Opacity 20~255, 외곽선 굵기 배율 0.25~4, 새 문서 Semi Transparent 기본값.
New Document기본 단위 mm/cm/m와 양수 폭·높이·두께. 변경 후 File > New로 적용합니다.

표시 옵션과 구분

Ruler/Grid/Status Bar의 표시 여부와 H/W 단면 보기·회전은 View에서 조절합니다. 간격과 새 문서 기본값은 Settings에서 조절합니다. 설정은 Windows 사용자별로 저장되어 다음 실행에도 유지됩니다.

입력 오류

“설정 값의 범위를 확인하세요”가 나오면 각 탭의 숫자 범위를 확인합니다. Ruler/Grid는 Auto 또는 양수여야 합니다. 소수 입력은 Windows의 숫자 표시 형식을 사용합니다.

표시 언어

Edit > Settings의 General에서 Display language를 English 또는 한국어로 선택합니다. 한국어 화면에서는 편집 > 설정 > 일반 > 표시 언어입니다. 선택 즉시 화면 문구가 바뀌고, OK(확인)를 누르면 다음 실행에도 유지됩니다. Cancel(취소)은 이전 언어로 돌아갑니다. 문서 단위와 숫자 입력 방식은 표시 언어와 별개입니다. Windows 파일 대화상자와 시스템 오류 문구는 운영체제 언어를 따릅니다.

사용자 번역 변경과 새 언어

설치 폴더의 Languages/en.json과 ko.json에서 키를 확인한 뒤, %LOCALAPPDATA%\CosmicDesigner\Languages에 사용자 파일을 저장합니다. 설치 파일을 직접 수정할 필요가 없습니다. UTF-8 JSON 예:

{
  "code": "ko",
  "name": "한국어",
  "strings": { "ui.0197": "내 파일(_F)" }
}

ko.json을 저장한 뒤 표시 언어를 다시 선택해 적용합니다. 이 사용자 파일을 삭제하고 언어를 다시 선택하면 기본 번역으로 돌아갑니다. 사용자 번역 파일은 설치 업데이트로 덮어쓰지 않습니다. 새 언어는 예를 들어 fr.json에 code: "fr", 언어 이름과 번역 키를 넣고 설정 창을 다시 열어 선택합니다. 동적 문구의 {0}, {1:0.###} 같은 형식 인자는 유지하세요. 누락된 번역은 영어로 표시되고 잘못된 파일·항목은 안전한 기본값을 사용합니다. 설정의 Language resource diagnostics(언어 리소스 진단)에서 오류를 확인할 수 있습니다.

새 사용자 기본 문서 단위는 mm이며 기본 판재는 3000 × 3000 mm, 두께 2 mm입니다. 기존 300 × 300 cm, 두께 0.2 cm와 실제 크기가 같습니다. 기존 사용자 설정과 저장 문서의 단위는 유지됩니다. 설정의 기본값 복원은 새 문서 기본값을 mm로 되돌리며 열린 문서의 크기는 변경하지 않습니다.
