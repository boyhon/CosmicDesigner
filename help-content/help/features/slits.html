직선·원호·연결선 절개

천공과의 차이

Slit은 열린 절단 경로입니다. L 레이어 선을 추가하지만 재료 면적을 제거하는 구멍으로 만들지 않습니다. Flat Designer 하단 Slit 버튼에서 작성합니다.

버튼클릭 순서
직선 절개시작점 → 끝점의 두 클릭
원호 절개시작점 → 통과점 → 끝점의 세 클릭. 세 점이 일직선이면 유효한 원호가 되지 않습니다.
연결선 절개연속으로 꼭짓점 클릭 → Enter로 완료. 최소 두 점 필요.
  1. Slit 도구를 선택하고 재료 범위에서 점을 클릭합니다.
  2. 점선 미리보기를 확인합니다. 서로 너무 가까운 클릭은 무시됩니다.
  3. 직선·원호는 필요한 점이 완성되면, 연결선은 Enter를 누르면 생성되고 Select로 돌아갑니다.
  4. 작성 중 취소하려면 Esc를 누릅니다.

선택과 저장

Select에서 실제 경로를 클릭하면 전체 경로가 금색으로 선택됩니다. OBJECTS > Slit Objects에서도 선택할 수 있습니다. Selected object에서는 구간·좌표·원호 중심·반지름을 확인합니다. 이 속성은 읽기 전용이며 직접 이동·Resize 입력은 제공하지 않습니다. 다시 작성하려면 선택 후 Delete하고 Undo/Redo를 이용합니다.

CosmicDesigner DXF로 저장·재열기할 때 절개가 유지됩니다. 단위 변경과 되돌리기도 지원합니다. 3D에서는 접힌 재료 위 절단 선으로 표시됩니다.
