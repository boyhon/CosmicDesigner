설치 및 시작

실행

배포받은 프로그램 폴더의 CosmicDesigner.exe를 실행합니다. 실행 파일과 종속 파일, help 폴더를 함께 보관하세요. 개별 EXE만 다른 폴더에 복사하지 마세요.

설치 파일 CosmicDesignerSetup.exe의 버전은 1.20.29-rc1입니다. CosmicDesigner 설치 패키지를 사용한다면 시작 메뉴의 CosmicDesigner에서 실행합니다. 새 설치의 기본 경로는 C:\Program Files\CosmicDesigner입니다. 설치 경로는 설치 과정에서 지정할 수 있습니다. 기존 설치를 업데이트하면 기존 경로를 사용합니다. 선택형 바탕 화면 바로가기와 설치 완료 후 실행은 CosmicDesigner를 엽니다.

첫 문서

초기 기본값은 폭 300 cm, 높이 300 cm, 두께 0.2 cm입니다. 사용자가 설정을 바꾸면 새 문서에 해당 값이 적용됩니다. 좌측 Material의 단위와 Thickness D를 먼저 확인하세요.

  1. Edit > Settings의 New Document에서 기본 단위·폭·높이·두께를 설정하고 OK를 누릅니다.
  2. File > New로 새 기본값의 문서를 만듭니다.
  3. H/W Section의 치수를 수정하거나 Flat Designer 도구로 형상을 작성합니다.
  4. File > Save As...로 사용자 작업 폴더에 DXF를 저장합니다.

작업 파일 위치

저장 대화상자에서 위치를 직접 선택합니다. 설치 폴더 대신 쓰기 가능한 사용자 폴더를 사용하세요. General 설정에서 기본 열기·저장 폴더를 지정할 수 있습니다. 환경 설정과 Recent 목록은 Windows 사용자별로 유지됩니다.

도움말 열기

Help > User Manual을 선택합니다. 프로그램 없이도 help/index.html을 Edge 등 브라우저에서 직접 열 수 있습니다. 인터넷 연결이나 웹 서버가 필요하지 않습니다.
