CosmicDesigner 사용자 매뉴얼

이 도움말은 VCutting 패키지에 포함된 CosmicDesigner 프로그램의 사용 방법을 설명합니다.

판재의 전개 형상과 천공, 절개, 절곡을 설계하고 단면과 3D 결과를 함께 확인합니다.

프로그램 소개

CosmicDesigner는 판금 도면을 작성·수정하는 사용자를 위한 Windows 프로그램입니다. 하나의 재료 외곽을 바탕으로 L 절단 형상과 V/V1 절곡선을 작성하고 DXF 파일로 저장합니다. Flat Designer에서 전개도를, H/W Section Designer에서 선택 위치의 단면을, 3D Preview에서 접힌 모양을 확인할 수 있습니다.

주요 작업

  • 새 판재 또는 기존 DXF로 시작하기
  • 원·반원·4분원·삼각형·사각형·다이아몬드·평행사변형 천공
  • 직선·원호·연결선 절개와 V/V1 절곡 작성
  • 외곽 편집, 모서리 Fillet, 경계 천공을 홈으로 통합
  • 치수·두께·단위 수정, Undo/Redo, DXF 저장과 재열기

파일 형식

작업 파일은 DXF입니다. CosmicDesigner에서 저장한 DXF는 설계 상태도 포함합니다. 일반 ASCII DXF는 지원되는 LINE/CIRCLE/ARC와 L/V/V1 형상을 가져옵니다. 바이너리 DXF와 지원되지 않는 형식은 사용할 수 없습니다. 별도의 CDF 저장 메뉴는 없습니다.

권장 순서

시작 → 단위·두께 확인 → 단면 치수 설정 → 천공·절개·절곡 작성 → 단면·3D 확인 → DXF 저장 → 재열어 확인.
