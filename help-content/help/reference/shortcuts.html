입력기능·조건
Ctrl+N / Ctrl+O / Ctrl+S새 문서 / 열기 / 저장.
Ctrl+Z / Ctrl+YUndo / Redo.
Ctrl+,Settings.
Delete객체 트리 또는 Flat 초점에서 선택 객체 삭제. 입력란에서는 문자 삭제에 주의.
EnterPolyline 절개 완료. 단면 치수 입력 중에는 값 적용을 위해 다음 입력란으로 이동.
Esc진행 중 Slit 또는 Flat V/V1 작성 취소. 일반적인 모든 대화상자/편집 취소로 간주하지 마세요.
Flat 휠 / 오른쪽 드래그포인터 주변 Zoom / Pan. 통합 후보의 우클릭은 통합 메뉴를 엽니다.
Section 휠중심 유지 확대·축소.
3D 왼쪽 드래그 / 휠시점 회전 / 확대·축소.
브라우저 Ctrl+F / Ctrl+P현재 도움말 페이지 검색 / 인쇄.

F1이나 Ctrl+Shift+S는 프로그램 도움말·다른 이름 저장 단축키로 등록되어 있지 않습니다. 해당 메뉴를 사용하세요.
