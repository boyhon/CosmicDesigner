화면 구성

이름·위치목적과 사용 시점
상단 File / Edit / View / Help파일 작업, 편집·설정, 표시 옵션과 도움말
좌측 상단 OBJECTSMaterial 아래 외곽 LINE/ARC, V/V1, Section Segments, Cut, Slit, Micro Joints를 선택합니다.
좌측 하단 PROPERTIESMaterial의 Flat W/H와 Thickness D, Selected object의 선택 객체 속성을 확인·수정합니다.
가운데 Flat Designer재료 전개도와 검정 L, 적색 V, 청색 V1 형상을 작성·선택합니다. 윗줄은 Ruler/Grid/Zoom/Fit, 아랫줄은 Select/Hole/Slit/V/V1/Fillet입니다.
오른쪽 위 H Section DesignerFlat의 H 선택선(X 위치)에 해당하는 높이 방향 단면입니다. Dimensions/Bent Mode/↻ 버튼을 사용합니다.
가운데 아래 W Section DesignerFlat의 W 선택선(Y 위치)에 해당하는 폭 방향 단면입니다. 치수와 절곡을 확인합니다.
오른쪽 아래 3D Preview접힌 형상을 회전·확대합니다. Semi Transparent와 Fit / Reset을 사용합니다.
하단 Status Bar명령 결과·선택 상태와 Flat 포인터 좌표를 확인합니다. View > Status Bar로 표시를 바꿉니다.
영역 사이 분할선드래그하여 화면 영역 크기를 조절합니다.

표시 읽기

제목은 Untitled - VCutting 또는 파일명입니다. 앞의 *는 저장되지 않은 변경이 있다는 뜻입니다. 천공 부위는 흰색, 선택한 형상은 금색, 외곽 통합 후보는 주황색입니다. 3D의 외곽·천공 경계는 검정, 절곡은 적색/청색입니다.
