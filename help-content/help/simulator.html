화면 구성

영역기능
단면 정보파일, X 단면 위치, 범위, Segment와 Hinge 수, 선택 절곡과 이력
Top View상부 도면과 이동 가능한 X 단면선, 선택 가능한 V V1 가공선
Side View현재 단면의 펼침 또는 절곡 후 측면 형상

단면 선택

Top View의 단면선을 좌우로 드래그하면 X 위치가 도면 범위 안에서 바뀝니다. 새 단면으로 이동하면 해당 위치의 L 형상과 V V1 교차점을 다시 계산하고 절곡 상태는 펼침 상태로 시작합니다.

절곡 적용

  1. 현재 단면과 교차하는 V 또는 V1 선을 클릭합니다.
  2. 선택 정보에서 Entity, Y 위치, 방향과 각도를 확인합니다.
  3. Side View와 절곡 이력에서 적용 순서를 확인합니다.

-V-는 V 방향, -V1-은 V1 방향으로 기본 90도 절곡됩니다. 현재 단면과 교차하지 않는 선은 시뮬레이션 대상이 아닙니다.

상단 명령

  • 화면 맞춤: Top View를 전체 도면에 맞춥니다.
  • 단면 중앙: 단면선을 도면 중앙 X로 되돌리고 절곡을 초기화합니다.
  • 실행 취소: 마지막 절곡 한 단계를 취소합니다.
  • 절곡 초기화: 현재 단면의 모든 절곡 이력을 지웁니다.
