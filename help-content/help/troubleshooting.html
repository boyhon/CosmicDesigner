문제 해결

DXFExplorer

증상조치
폴더에 접근할 수 없음권한이 있는 폴더를 선택하고 시스템 또는 숨김 폴더인지 확인합니다.
Viewer 또는 Simulator를 찾지 못함네 실행 파일이 같은 설치 폴더에 있는지 확인하고 재설치합니다.
분석할 수 없음파일이 텍스트 DXF인지, 읽기 권한이 있는지 확인합니다.

DXFViewer

  • 도면이 비어 보이면 모든 레이어 표시와 화면 맞춤을 실행합니다.
  • ARC 위치가 예상과 다르면 DXF 명령 정보에서 중심 좌표, 반경, 시작각과 끝각을 확인합니다.
  • 지원되지 않은 Entity 집계를 확인합니다.

DXFSimulator

  • 절곡점이 없으면 단면선이 V 또는 V1 선과 교차하도록 이동합니다.
  • 선택한 선이 현재 단면과 교차하지 않으면 다른 X 위치를 선택합니다.
  • 결과를 처음부터 보려면 절곡 초기화를 누릅니다.

DXFDrawer

  • 객체가 보이지 않으면 Layer Visibility와 맞춤을 확인합니다.
  • 원하는 좌표로 이동하지 않으면 Grid Snap과 Endpoint Snap을 확인합니다.
  • 저장되지 않으면 Objects의 경고 객체와 Validation 메시지를 수정합니다.

설치와 Help

  • 관리자 권한 요청은 Program Files 설치를 위한 정상 동작입니다.
  • 파일 사용 중이면 제품군 네 프로그램을 모두 종료합니다.
  • Help가 열리지 않으면 실행 파일 옆의 대응 _help.html과 help 폴더를 확인하고 재설치합니다.
