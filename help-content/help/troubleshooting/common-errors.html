문제 해결

증상원인과 해결 방법
파일이 열리지 않음 / Binary DXFASCII DXF인지 확인합니다. 바이너리는 지원하지 않습니다. 원본 도구에서 ASCII로 다시 저장합니다.
L layer에 가져올 절단 형상이 없습니다일반 DXF에 지원 L 형상이 없습니다. L 또는 -L- 레이어에 지원 LINE/CIRCLE/ARC가 있는지 확인합니다.
사각 외곽으로 가져옴닫힌 LINE 외곽을 찾지 못했습니다. 원본의 외곽 연결과 엔티티 종류를 점검하고 대체 결과를 확인합니다.
일부 형상·절곡 누락미지원 엔티티, 수평/수직이 아닌 절곡 LINE은 제외됩니다. 가져오기 경고를 읽고 원본을 정리합니다.
가져온 크기가 다름일반 가져오기는 cm 이외 입력을 mm로 취급합니다. 원본 단위와 현재 단위를 확인하고 실제 크기를 비교합니다.
Recent 파일을 찾을 수 없음이동·삭제된 파일은 목록에서 제거됩니다. Open으로 새 위치의 파일을 엽니다.
설정 값의 범위를 확인하세요Settings 각 탭 범위를 확인합니다. Ruler/Grid는 Auto 또는 양수입니다.
Fillet 반지름을 적용할 수 없음유효한 볼록 LINE–LINE 모서리인지 확인하고 반지름을 줄입니다. 평행/퇴화 모서리는 대상이 아닙니다.
원호 반지름 또는 치수 변경 거부양수·최소 길이·재료 경계를 확인합니다. 부적합 입력은 이전 형상을 유지합니다.
천공이 생기지 않음Hole 버튼 선택과 재료 범위, 충분한 드래그를 확인합니다. 반원 방향, 4분원 두 축 이동을 확인합니다.
절개가 완성되지 않음Polyline은 최소 두 점 후 Enter, Arc는 서로 일직선이 아닌 세 점입니다. 재료 범위를 확인하고 Esc로 취소해 다시 작성합니다.
통합 메뉴가 없음지원 형상과 양의 길이 경계 접촉을 확인합니다. 내부·점 접촉·여러 재료 조각이 되는 경우 통합할 수 없습니다.
선택 항목을 삭제할 수 없음Material/Contour/Section Segment는 구조 항목입니다. 삭제 가능한 자식 형상을 선택합니다. 최소 외곽 삭제는 거부됩니다.
저장 실패파일이 읽기 전용인지, 폴더 쓰기 권한이 있는지 확인합니다. Save As로 다른 사용자 폴더에 저장합니다. 현재 문서는 유지됩니다.
도면이 화면 밖에 있음Flat의 Fit 또는 View > Zoom > Fit to Window, 3D의 Fit / Reset을 사용합니다.
단면이 끊어져 보임홈을 통과한 검사선이면 실제 빈 구간입니다. H/W 점선을 다른 위치로 옮겨 비교합니다.
얇은 Bent 단면이 잘 안 보임Bent는 실제 두께 축척입니다. 휠로 확대하고 Material Thickness D를 확인합니다.
도움말 파일을 찾을 수 없음EXE 옆 help 폴더를 확인합니다. 배포 파일 전체를 복원하거나 새 패키지로 재설치합니다.
도움말을 열 수 없음Windows의 HTML 기본 브라우저 연결을 확인합니다. help/index.html을 Edge에서 직접 엽니다.

문제가 계속되면 원본 사본, 재현 순서, 화면에 표시된 안내 문구와 사용한 프로그램 버전을 함께 기록하세요.
