레이어와 범례

레이어 체크를 끄면 해당 형상만 숨깁니다. 전체 표시는 모든 레이어와 전체 작업 범위를 다시 표시합니다. 기본 판금 레이어는 -L- 절단, -V- 정방향 절곡, -V1- 반대방향 절곡입니다.

Entity 표시

현재 기하 표시의 중심 대상은 LINE, ARC, CIRCLE입니다. 원호는 DXF의 중심, 반경, 시작각과 끝각을 사용해 그립니다. 지원하지 않는 종류는 오른쪽 분석 결과에 집계될 수 있습니다.

확대 축소 이동

  • 화면 맞춤: 전체 형상이 중앙 영역에 들어오도록 맞춥니다.
  • 확대 축소: 상단 버튼 또는 마우스 휠을 사용합니다.
  • 이동: 도면 영역을 드래그해 화면을 이동합니다.

로그와 DXF 명령 정보

로그는 Header, Layer, Entity 파싱과 Bounds 계산 상태를 보여 줍니다. DXF 명령 정보는 줄번호, 원문 값, 그룹 코드의 해설을 나란히 표시하므로 잘못된 파일을 진단할 때 사용할 수 있습니다.
