사전 조건

CosmicDesigner에서 저장한 DXF를 준비합니다. 중요한 작업은 먼저 사본을 만듭니다.

  1. File > Open... 또는 Recent로 설계를 엽니다.
  2. OBJECTS 또는 Flat에서 객체를 선택하고 속성·핸들·단면 치수로 수정합니다.
  3. 두께 변경은 확인창을 읽고, 단위 변경은 실제 크기 유지 여부를 확인합니다.
  4. Undo/Redo로 변경을 검토합니다.
  5. 단면과 3D를 검사합니다.
  6. 원본 갱신은 Ctrl+S, 사본 저장은 Save As...를 선택합니다.
  7. 닫을 때 저장 확인창이 나오면 Yes/No/Cancel의 의미를 확인합니다.

결과

변경된 설계 정보와 제조 형상의 DXF입니다. 저장 실패·취소 시 현재 문서가 유지되므로 다른 쓰기 가능한 위치로 다시 저장하세요.

타원 치수 수정

타원 전체를 선택하고 장축 길이·단축 길이·회전각을 입력하세요. 다른 속성은 유지되며 범위를 벗어나는 입력은 적용되지 않습니다. 타원 속성 입력을 참고하세요.

통합 천공 수정

겹친 내부 천공을 통합한 뒤 한 객체로 이동·크기 편집·삭제할 수 있습니다. 원호가 포함되면 동일 비율로 크기를 조정하세요. Undo 한 번으로 통합 전 객체 전체를 복원합니다. DXF를 저장한 뒤 재열어 통합 형상과 남은 재료를 확인하세요.

정다각형 수정과 저장

정다각형 전체를 선택하고 중심·변 개수·반지름·회전각을 수정합니다. 몸체 이동은 크기와 방향을 유지합니다. DXF 저장 후 다시 열면 고유 속성이 유지됩니다. 정다각형 속성을 참고하세요.

도형 복사 및 붙여넣기

  1. Flat Designer 또는 객체 트리에서 복사할 천공이나 절개를 선택합니다.
  2. Ctrl+C 또는 Edit > Copy(복사)를 선택합니다.
  3. Ctrl+V 또는 Edit > Paste(붙여넣기)를 선택합니다. 복사본이 선택되며 드래그로 옮길 수 있습니다.

반복 붙여넣기는 오른쪽·아래로 10mm씩 이동합니다. 재료 경계에서는 위치를 조정하며, 재료보다 큰 도형은 붙여넣지 않습니다. Undo/Redo는 붙여넣기 한 번씩 적용됩니다. 회전각, 곡선, 천공에 연결된 Micro Joint를 유지합니다.

천공의 LINE/ARC 자식을 선택하면 천공 전체를 복사합니다. Outer Contour의 LINE/ARC는 독립된 절개로 복사하여 원래 외곽을 유지합니다. 재료 전체·단면·절곡·Micro Joint 단독 복사는 지원하지 않습니다.

다른 문서 또는 CosmicDesigner 창에도 붙여넣을 수 있습니다. 문서 단위가 달라도 실제 크기를 유지합니다. 텍스트 입력란에서는 Ctrl+C/V가 텍스트 복사·붙여넣기로 동작합니다. 다른 앱의 텍스트나 그림은 도형으로 붙여넣지 않습니다. 가져온 DXF의 닫힌 윤곽은 편집 가능한 천공으로, 열린 선·원호는 절개로 복사합니다.
