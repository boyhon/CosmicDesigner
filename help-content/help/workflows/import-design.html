업무: 외부 DXF·SVG로 설계 시작

사전 조건

ASCII DXF의 사본과 원본 단위, L/V/V1 제조 레이어를 확인합니다. 지원하지 않는 곡선은 외부 도구에서 지원 형상으로 정리해야 합니다.

  1. File > Open...에서 원본 사본을 선택합니다.
  2. 자동 가져오기 창에서 OK를 누릅니다.
  3. 경고에 외곽 사각 대체·사선 절곡·지원되지 않는 엔티티가 있는지 확인합니다.
  4. Material 크기가 의도와 같은지 확인합니다. 필요하면 Document Units의 두 방식 차이를 확인하여 변경합니다.
  5. 두께와 절곡 방향·순서를 확인하고 천공/외곽을 검토합니다.
  6. Save As...에서 새 파일명을 사용합니다.
  7. 재열어 설계가 복원되는지 확인합니다.

주의: 열렸다는 사실만으로 원본의 모든 엔티티가 보존되었다고 판단하지 마세요. 일반 가져오기 경고와 실제 형상을 반드시 비교하세요.

SVG 벡터 도형 가져오기

  1. File > Import SVG를 선택합니다.
  2. 가져올 SVG의 표시 크기, 도형 개수와 경고를 확인합니다.
  3. 가져온 천공과 절개를 선택하여 속성·위치를 확인합니다.
  4. 다른 이름으로 DXF를 저장하고 절삭 전에 원본과 비교합니다.

path, rect(둥근 모서리 포함), circle, ellipse, line, polyline, polygon, 그룹의 이동·회전·배율·기울기와 문서 내부 use 참조를 지원합니다. 베지어·타원 곡선은 명목 0.01mm 근사값의 LINE으로 변환합니다. 배율이 균일한 circle은 CIRCLE을 유지합니다. 복합 경로의 채움 규칙과 재료 섬을 보존하며 불필요한 내부 교차선은 남기지 않습니다.

색·선 두께는 절삭 윤곽으로 변환하지 않습니다. 텍스트는 원본 편집기에서 경로로 변환하세요. 이미지, CSS 스타일시트·CSS로 지정된 좌표/변환, clip/mask/filter, 중첩 SVG 캔버스·symbol 뷰포트, 외부 참조는 지원하지 않습니다. %·em 등 상대 길이는 절대 길이로 바꾸세요. 스크립트나 외부 자료는 실행·로드하지 않습니다.

캔버스 밖 도형은 가져오기를 거부합니다. 크기 8MB, 표시 도형 500개, 변환 선분 2000개의 제한을 초과하면 도형을 나누어 가져오세요. 가져오기는 새 문서이며 현재 문서에 추가하는 방식은 아닙니다.
