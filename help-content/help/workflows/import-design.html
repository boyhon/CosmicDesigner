업무: 외부 DXF로 설계 시작

사전 조건

ASCII DXF의 사본과 원본 단위, L/V/V1 제조 레이어를 확인합니다. 지원하지 않는 곡선은 외부 도구에서 지원 형상으로 정리해야 합니다.

  1. File > Open...에서 원본 사본을 선택합니다.
  2. 자동 가져오기 창에서 OK를 누릅니다.
  3. 경고에 외곽 사각 대체·사선 절곡·지원되지 않는 엔티티가 있는지 확인합니다.
  4. Material 크기가 의도와 같은지 확인합니다. 필요하면 Document Units의 두 방식 차이를 확인하여 변경합니다.
  5. 두께와 절곡 방향·순서를 확인하고 천공/외곽을 검토합니다.
  6. Save As...에서 새 파일명을 사용합니다.
  7. 재열어 설계가 복원되는지 확인합니다.

주의: 열렸다는 사실만으로 원본의 모든 엔티티가 보존되었다고 판단하지 마세요. 일반 가져오기 경고와 실제 형상을 반드시 비교하세요.
