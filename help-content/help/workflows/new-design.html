목적과 사전 조건

새 전개도를 만들고 DXF로 저장합니다. 설치 또는 배포 폴더에서 CosmicDesigner를 실행하고 필요한 실제 치수를 준비합니다.

  1. Edit > Settings > New Document에서 기본 단위·폭·높이·두께를 확인합니다.
  2. File > New를 누릅니다. 미저장 문서가 있으면 저장 여부를 선택합니다.
  3. Material 단위·두께를 확인하고 H/W Section의 길이로 크기를 조정합니다.
  4. Hole/Slit 및 V/V1 도구로 형상을 작성합니다.
  5. H/W 점선을 필요한 위치로 옮겨 단면을 확인하고 Bent Mode 및 3D에서 방향을 검토합니다.
  6. File > Save As...로 작업 폴더에 DXF를 저장합니다.
  7. 다시 열어 단위·형상·절곡·단면 보기 상태를 확인합니다.

결과

설계 정보와 제조 형상을 포함한 DXF 작업 파일입니다. 새로 만들기는 기존 문서의 Undo 기록을 초기화합니다.

타원 천공 추가

Hole의 Circle 바로 옆 타원 버튼을 선택하고 장축 한쪽 끝에서 다른 끝까지 드래그합니다. 사선으로 끌면 기울어진 타원이 생깁니다. 타원 생성·편집 절차를 참고하세요.
