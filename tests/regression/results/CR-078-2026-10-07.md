## 3. RegularPolygon 모델
기존 CutOperation을 재사용해 논리적 Shape/EntityType=RegularPolygon, CenterX/Y, Sides, Radius, Rotation, L Layer, Closed=true를 제공한다. 기본6, 정수3..512로 제한: 기존 교점/mesh 연산의 비용을 제한하면서 수백 개 변을 지원한다. Geometry의 LINE들은 기존 윤곽/렌더링용 파생 캐시이며 독립 선택 객체가 아니다. Radius/Rotation은 기존 DXF JSON metadata와 history snapshot에 optional 필드로 보존하고 읽을 때 원래 파라미터로 꼭짓점을 다시 생성한다. 기존 Polygon/Pentagon/Hexagon 데이터는 변경하지 않는다.

## 4. 꼭짓점 계산
RegularPolygonGeometry.Vertices 단일 원본: theta=Rotation+i×360/N; X=CX+R×cos(theta), Y=CY+R×sin(theta). Degree를 radian으로 변환한다. 첫 꼭짓점은+X기준, CCW 양수, Rotation0..360 정규화. Preview/생성/속성/파생 윤곽/DXF가 공유한다. 화면에는 기존 FlatViewport의 Y 변환만 적용한다.

## 5. Drawing UI
기존 청록 윤곽 스타일의 육각형 아이콘, English/한국어 tooltip와 접근성 이름 및 Sides 입력6. 중심을 클릭하고 버튼을 누르지 않은 상태로 포인터를 움직이면 점선 미리보기; 첫 꼭짓점 클릭으로 반지름/방향 확정, 한 객체 생성 후 Select 복귀. 변 개수 변경은 미리보기에 반영한다. ESC/우클릭/다른 도구로 취소, 문서 전환 시 미완성 중심을 초기화한다. Invalid/재료 밖 값은 생성 없이 안내한다. Radius property로 크기를 편집하며 변형 핸들/개별 vertex edit는 제공하지 않는다.

## 6. Property Panel / 선택 / History
Type, Layer L, 중심X/Y, 변 개수, 외접원 반지름(문서단위), 회전각. 한 값의 변경은 다른 파라미터를 유지해 전체 꼭짓점을 재생성한다. 유한/양수/정수 범위/재료 포함 검사 후 변경과 한 Undo 기록을 수행한다. Invalid/no-op 값은 상태를 바꾸지 않는다. 모든 변과 몸체에서 전체 객체를 선택한다. 몸체 이동은 중심만 변경; Delete 전체 및 Create/Move/속성/Delete Undo·Redo 지원. 단위 physical conversion은 중심/반지름/파생 윤곽을 함께 변환한다.

## 7. DXF Export / Import / Contour
정다각형은 닫힌 LWPOLYLINE 하나: AcDbEntity/AcDbPolyline, group90=N, group70=1, layerL, N개의 unique ordered vertices, 마지막 점 중복 없음. 기존 파일 units/문화권/metadata marker 유지. 자체 저장파일 Load는 정다각형 파라미터 복원. 일반 default-OCS 직선 LWPOLYLINE은 기존 generic LINE geometry/Imported Contour로 읽으며 정다각형으로 추정하지 않는다. Bulge/비기본 OCS/잘못된 vertex count는 unsupported로 보고한다. 기존 contour/inner union/outer subtraction에 파생 꼭짓점을 전달; 통합과 Fillet 후에는 Compound로 전환한다.
표준 근거: Autodesk LWPOLYLINE DXF reference, https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/GUID-748FC305-F3F2-4F74-825A-61F04D757A50.htm .
