## Subtract 구현
같은 BFS collection과 analytic boundary pipeline을 공유한다. occupancy는 Any(others contain point) && !selected contains point이므로 정확히 U − S다. Tolerance1e-6, side offset max(1e-7,span*1e-8), 기존 overlap area threshold와 WPF tolerance를 그대로 사용한다.

Positive signed-area loop 각각을 별도 Compound Cut로 만들며 negative loop는 이를 포함하는 가장 작은 outer에 hole로 붙인다. 중첩 island도 별도 positive loop로 유지된다. synthetic 연결선 없음. 빈 경계는 정상 성공이며 모든 참여 원본을 제거하고 결과/선택/속성 패널을 비운다. 실패 또는 겹침 없음은 변경 없이 반환한다. 기존 nonmanifold 폐합 실패 정책 유지.

첫 결과는 selected ID/Sequence/Kind/ParentContourId/Sides를 상속하고 추가 결과는 충돌 없는 H IDs를 갖는다. 모든 결과는 L layer. selected의 배열 위치에서 결과를 삽입하고 독립 원본 순서는 유지한다. 여러 결과 중 첫 객체 선택은 기존 단일 선택 UI 정책에 따른다. 삭제 대상의 MicroJoint 정책은 기존 Merge와 동일하며 별도 재배치 정책을 추가하지 않았다.

한 번의 snapshot 기록으로 geometry/원본 순서/속성이 Undo되고 Redo된다. optional HistorySelectionId로 cutter 선택과 첫 결과 선택 복원; empty Redo는 선택 없음. 선택 ID는 런타임 history용이며 DXF schema는 변경하지 않았다.
